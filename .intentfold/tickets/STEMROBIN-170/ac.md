# 可执行验收

## AC1

从上票已经出现的图形缺陷逐项对照正式 authoring/review 的新增说明；记录已有规则为何不重复、临时扩展代码为何不迁入。只修改现有图形段，不引入具体课号、答案或题数规则。

## AC2

若采用只补说明路线，则不新增机械校验、不改变任何脚本的合法输入或输出。用相对记录 base 的 Git 路径差验证技能脚本与应用代码无变化；运行 skill-creator quick_validate 检查技能入口有效。

## AC3

确认相对 base 的资源目录、schema、依赖、应用和技能脚本 diff 为空；不执行内容发布或数据库写操作。运行 engineering 的机械检查。说明变更无 UI 或渲染行为变更，不为本票额外创建作答记录。
