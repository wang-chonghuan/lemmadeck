# 实现路线

正式 choice 校验器已经拒绝重复文本、数值/表达式/集合等价选项及过期审核证据；authoring 已规定现场求解、完整条件、具体干扰项计算和逐小问反馈，不再重复这些规则。

正式 graph-options 只支持既有图形模型；上票多图框架、闭端点和数轴箭头的缺陷属于临时扩展，不能直接搬入稳定工具。用户已确认只补说明，不扩展工具。

1. 在现有 authoring 的图形段补充：图选项名称按 options 当前显示顺序，不由稳定 id 推断；区分真实定义域边界与绘图窗口，避免虚假有限上界；线型不改变端点包含性；组合图使用能完整显示所需端点的共同框架；数轴射线保留方向箭头。
2. 在现有 review 的图审核项补充对应的实际像素观察点，不增加审核轮次，不改审核哈希或发布合同。
3. 技能说明之外不改产品文件。以修改路径、技能校验、上票实证对照和工程机械检查验证，不运行 prepare/finalize/publish，不写共享内容库。

上述路线不跨 Charter 的依赖、schema、UI token、环境或数据修改红线。用户已授权验证后直接合并关闭本票，不部署。
