# 可执行验收

## 1. 失败留档

用真实 FigureSpec 渲染一个存在标注碰撞的图，确认渲染报告 fail。
调用审查 CLI 请求 fail，要求退出0并写出 review.status=fail。
独立计算并核对 source、spec、render、outputs 的 SHA-256，验证记录绑定当前文件。

## 2. 禁止假通过

同一失败渲染请求 pass 必须非零，且无可用通过记录。
再对缺失/未知状态、错图、失效来源/规格/输出分别运行 CLI，均要求非零。
把失败审查交给实际内容审查验证器，必须被拒绝，不以自写字符串检查替代发布门禁。

## 3. 正常流程

用正常真实渲染请求 pass，CLI退出0，生成当前哈希绑定的 pass 记录。
记录应能通过实际内容审查验证器。
运行工程 Charter 指定的机械检查和本修改的聚焦检查。
本修复是命令行证据流程，命令调用与产物/发布验证是权威验收面，不新增无关网站流程。
