# 实现路线

现有教材页只投影原题的数学输入和坐标控件，未消费 choice widget。
原题、答案和交互不是完全相同的覆盖范围：278的函数式没有独立判分空。
练习 JSON 可容纳独立题组，无须改表；现有选择题 UI 样式可以复用。

1. 新增项目技能、结构化产物合同、prepare/finalize/publish 工具。
   prepare 解析目录与课号，收集原题、答案、图及来源哈希；主模型负责拆小问与出题。
2. 样本生成后检查覆盖、数值、等价选项、干扰项与来源；用实际问题修技能，再产出三课。
3. 服务端独立投影、按稳定选项 ID 判分，记录到现有内容作答事件，不混入原题错题本。
4. 教材页追加选择题选项卡，复用现有样式和图渲染，隔离课程及产物版本的作答状态。
5. 运行内容与浏览器验收，保留样本迭代证据，按 review 模式提交并交付预览。

红线查找：不改 Charter/设计 token、依赖、数据库结构；不发送答案键；
内容写库由项目技能共享 content-db；只读现有数据，测试只用测试用户；
只更新三课选择题，不部署，不修改 main 或其 resources/ 未跟踪文件。

后续授权扩展：第19课作为新样本。保存技能Version1、独立生成41题后诊断，
收紧分类及系数的完整选项、整集合目标、表格列条件抽取与源图记录；
Version2独立重生成27题。补充集合数学等价验证和错选反馈公式渲染。
保持原题、原答案、原图、依赖和设计token不变；验收通过后保留预览，不合并或关闭。

再次授权扩展：第20课「线性函数的图象」。生成54题与28张图，
补充仿射图象、有限和整数定义域、读图复用及固定外缘刻度；
独立审核修正两处干扰项理由，浏览器实测修复SVG点击被内部焦点抢占的问题。
最终范围为第16至20课，共166题。用户查看第20课后明确批准合并并关闭本工单，
不包含网站部署。
