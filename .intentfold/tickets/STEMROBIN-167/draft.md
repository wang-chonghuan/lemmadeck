# 已讨论的路线

用户先要求思考方案，随后明确启动一个 story，把技能、生成、按实际结果优化、
再次生成及选择题 UI 放在同一工单。沿用这次讨论，不重新采访已确定的问题。

阅读原题与现代图、求解原题，然后按实际小问生成平行单选。
先在第16课跑通完整链路，再用17、18课暴露应用题、区间与选图的边界。
界面保留原题顺序，增加平行选择题入口。
用户看过第16课后明确要求：整课题目同一页展开，连续编号，每题独立提交与反馈；
来源关系只留产物和数据库，不向学生显示原题号、小问标签或来源说明。
用户随后要求：单选点击选项即提交，不设独立提交按钮；仅多选需要确认提交。
本版仍只支持单选，方向键浏览选项，空格或回车激活；失败后可重新点选，提交中防重复。
用户最终确定标签“课文｜习题｜书写题”：选择题放第二项“习题”，完整教材题放第三项“书写题”。
书写题只展示题面与图表，移除输入、作图和提交控件，不在线判分；已有题号定位保留。
该课没有选择题数据时不显示空的“习题”页签，只保留课文和书写题。
本轮不新增参考答案展示、不修改教材内容或已有作答数据。
不使用退休的中性课程树或语言 overlay；不以选择图象声称完成作图。

外部前提：Plane 验证成功；三课现代版、答案、交互和现代图均存在。
内容库连接在开发前只读验证；新题通过发布器追加到对应课程，原题不替换。
合并、关闭、网站部署未获本次授权，使用 review finish。
