## 1. 油膜估算粒子大小

源题：已知体积为 1 毫米^3 的一滴石油放在水面上，其扩展的面积不能大于 3 米^2。根据这些数据，试估算石油粒子的大小。

题给：`V = 1 mm^3 = 10^-9 m^3`，`S <= 3 m^2`。

先仅由体积和面积得到平均膜厚：

```text
h = V/S
h >= V/(3 m^2) = (1/3) x 10^-9 m
  = 3.33... x 10^-10 m = 0.333... nm
```

这里首先是膜厚的下界，不是无条件的精确分子直径。只有进一步采用“油均匀铺成单分子层、没有显著损失或溶入水中、膜厚可代表粒子沿厚度方向的特征尺寸”的模型，才能写 `d ~ h`。再把 3 m^2 当作可达到的最大铺展面积，才有教材式估算 `d ~ 3.3 x 10^-10 m`，数量级为 `10^-10 m`。

若实际铺展面积小于3，不能仍写严格等号；若不是单分子层，厚度界限也不能直接变成单粒子大小界限。石油是混合物，估计的是典型尺寸而非精确统一球形直径。

缺项：单分子层模型、最大面积是否可达到、损失可忽略的假设。无需查表常数。

能力：单位的三次方换算、`V = Sh`、不等式方向、数量级估算、模型适用条件。

## 2. 氢和氮的分子量

源题：试确定氢和氮的分子量。

按普通单质分子 H2、N2，且“分子量”指相对分子质量：

```text
M_r(H2) = 2 A_r(H)
M_r(N2) = 2 A_r(N)
```

不能把相对分子质量写成有单位的克或 kg/mol。若定义段要求摩尔质量，则另为 `mu_H2 = 2 mu_H(atom)`、`mu_N2 = 2 mu_N(atom)`；若要求一个分子的质量，则为 `m_1 = mu/N_A`，这三者不能互换。

缺项：分子量的定义、H2/N2组成模型及 `A_r(H)`、`A_r(N)` 的表值与精度。当前不借题5反推题2的答案，也不代入未提供的原子质量表。

能力：识别双原子分子、相对质量加和、区分相对分子质量/摩尔质量/单分子质量。

## 3. 1克水的物质的量

源题：1 克水包含的物质的量是多少（摩尔）？

题给质量：`m = 1 g = 10^-3 kg`。按纯 H2O：

```text
nu = m/mu_H2O = (10^-3 kg)/mu_H2O
mu_H2O = 2 mu_H(atom) + mu_O(atom)
```

所得单位为 mol。若后续表中给出的水摩尔质量用 g/mol，应直接用 `1 g / mu_H2O`，不能把克质量与千克每摩尔混算。题目问摩尔数，不需再乘 `N_A`。

缺项：水的摩尔质量，或H/O原子摩尔质量及 H2O 组成模型。无需密度、气体摩尔体积或 `N_A` 数值。

能力：质量与物质的量换算、化学式确定摩尔质量、单位一致性。

## 4. 10克氧的分子数

源题：10 克氧中的分子数等于多少？

题给：`m = 10 g = 0.010 kg`。按普通分子氧 O2：

```text
nu = (0.010 kg)/mu_O2
N_molecules = nu N_A = ((0.010 kg)/mu_O2) N_A
mu_O2 = 2 mu_O(atom)
```

不额外乘2；乘2得到的是 O 原子数而非 O2 分子数。也不能按单个O原子的摩尔质量直接算分子数。不需要气体密度、温度、压强或理想气体摩尔体积，因为题目给的是质量而非气体体积。

缺项：O2模型、氧的摩尔质量或相应原子质量表，以及 `N_A` 数值和精度。

能力：辨认计数实体、`nu = m/mu` 与 `N = nu N_A` 联用、质量单位换算。

## 5. 一个氮分子的质量

源题：氮的摩尔质量等于 0.028 千克/摩尔，氮分子的质量等于多少？

题给的氮摩尔质量直接对应题目所指分子实体，不需要另行查氮的相对原子质量：

```text
mu_N = 0.028 kg/mol
m_1 = mu_N/N_A = (0.028 kg/mol)/N_A
```

单位检查：`(kg/mol)/(mol^-1) = kg`。这里是除以 `N_A`，不是乘；不把1 mol物质的质量当作一个分子的质量。

缺项：仅 `N_A` 数值及教材采用的精度。题给 `0.028` 不改为其他表值。当前符号解完整，数值留待常数明确。

能力：宏观摩尔质量与微观单粒子质量转换、量纲检查。

## 6. 干净平滑的铅块为何能粘住

源题：如果把两个切口平滑而干净的铅块在一起挤压，为什么它们可以粘住？

独立解释：平滑、干净的接触面减少凹凸、污染或氧化层造成的间隔；挤压使较软的铅发生局部形变，让相邻表面的粒子在较多区域接近到原子间相互作用显著的距离。在合适的近距离处，两块铅之间可以形成金属结合，从而粘住。中学层次可表述为“相邻粒子进入相互吸引能显著起作用的距离”。

不能解释成远距离分子引力很强、所有距离都只有吸引力、挤压产生黏液、必须先熔化或原子核彼此黏住。原子间过近时也有排斥；平滑、干净和受压是使有效接触形成的条件，不是可以省略的装饰措辞。

模型：固体由粒子组成，相邻表面能在受压后形成充分近接触。原子间吸引/排斥的适用距离及金属结合知识不是 seed 提供的定义段，属于待确认的概念前提。无需查数值表。

能力：用微观相互作用解释宏观现象，联系表面条件和有效接触，区别吸引与排斥而非只背一句“分子间有引力”。

## 7. 1立方米铜中的原子数

源题：试确定 1 米^3 铜中的原子数目。铜的摩尔质量 mu=0.0635 千克/摩尔，铜的密度 rho=9000 千克/米^3。

题给值直接使用，不换成常见密度表中的其他铜密度：

```text
V = 1 m^3
m = rho V = (9000 kg/m^3)(1 m^3) = 9000 kg
nu = m/mu = (9000 kg)/(0.0635 kg/mol)
   = 18000000/127 mol
   = 1.4173228346... x 10^5 mol
N_atoms = (rho V/mu) N_A
        = (18000000/127 mol) N_A
```

铜的摩尔质量对应铜原子实体；不按双原子铜分子再乘或除2。所求 `N_atoms` 是数量，不是最后停在摩尔数。

缺项：`N_A` 数值及最终有效数字。密度、体积和摩尔质量均已给，不需另查铜常数。

能力：`m = rho V`、`nu = m/mu`、`N = nu N_A` 三步串联，区分原子数和摩尔数，使用给定而非擅换表值。

## 8. 10^22个金刚石原子的体积

源题：金刚石的密度是 3500 千克/米^3。10^22 个金刚石原子占有多大体积？

按金刚石由碳原子组成，`mu_C` 为碳原子的摩尔质量：

```text
N_C = 10^22
rho = 3500 kg/m^3
nu_C = N_C/N_A
m = nu_C mu_C = (N_C/N_A) mu_C
V = m/rho = (10^22 mu_C)/(3500 N_A)
```

用 `mu_C` 的 kg/mol 与 `N_A` 的 mol^-1 得到 `V` 的 m^3。金刚石为碳的晶体，不因其结构不同而改用一个“金刚石分子”的摩尔质量，也不把 `10^22` 理解成摩尔数。若最终要求 cm^3，应在得到 m^3 后乘 `10^6` 转换，不能直接换密度单位而漏掉换算。

缺项：碳原子组成模型、`mu_C` 或碳相对原子质量表，以及 `N_A` 数值和精度。密度3500已给；当前不自行代入碳的未提供表值。

能力：辨认晶格计数实体，从粒子数反推摩尔数、质量和体积，量纲及立方单位换算。
