# 74. 三棱镜中的光路

在光学仪器中，常常要利用由玻璃或其它透明材料制成的三棱镜。这样的棱镜是研究光的颜色的仪器的最重要部件。它应用在望远镜、潜望镜和许多其它装置中。

图160所示的是平面玻璃棱镜的与侧棱垂直的截面。光线在棱镜中折射两次：在交界面$OA$和$OB$上。两个交界面之间的角$\varphi$叫做**棱镜的折射角**。光线的偏向角$\theta$取决于棱镜的折射角$\varphi$、棱镜材料的折射率$n$及入射角$\alpha$。
