# （承上页）

用简单的实验能很容易观察到全反射现象。我们把杯子灌上水，并举到略高于眼睛的位置。由下面穿过杯壁观察水面时，由于光的全反射，水面看来光灿如银。

在所谓的纤维光学中，利用全反射沿着透明、柔韧的纤维束来传递光和图像，就是光导。光导是圆柱形的玻璃纤维束，它的外面覆盖着一层折射率比纤维束小的透明材料。由于多次全反射，光可以向任何路径（直线或弯线）传播。很多纤维束聚集成一个辫带。这样，沿着纤维束中的每一根纤维传播着某一个像元（图159）。纤维束辫带可以用于医学中研究内部器官（接入一般的灯泡会引起不需要的发热）。
