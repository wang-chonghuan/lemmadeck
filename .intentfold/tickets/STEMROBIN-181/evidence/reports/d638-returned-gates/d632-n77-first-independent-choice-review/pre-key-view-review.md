## Visible fidelity, redundancy and leakage

1. Refraction: the learner must distinguish sine law from surface-angle cosine,
   reversed indices and replacing sine by angle. Normal reference, transmission
   existence and isotropic ordinary media are explicit. Coplanarity is repeated
   in all options; the distinguishing task is the exact general angular law.
   The product form handles i = r = 0 without pretending a 0/0 quotient is an
   index. No unique incidence plane is claimed at that degenerate position.

2. Index: c, v1, v2 and the ordered n21 reference are defined, but the ratios
   themselves must be determined. Vacuum-reference, inversion and treating
   relative index as an absolute index are distinct erroneous operations.
   There is no isolated numerical cell or answer copied into the stem.

3. Critical angle: the supplied high-to-low condition restricts a meaningful
   critical angle rather than supplying it. The options require both the sine
   ratio and the ordering of transmission/critical limit/TIR. This uses Snell's
   law but is a new threshold judgment, not a duplicate answer to question 1.

4. Thin lens: all choices concern relative thickness, but compare different
   scales. Comparing to curvature radii and imaging distances preserves the
   thin-lens geometrical distinction, not an absolute-smallness definition.

5. Principal focus: actual outgoing convergence and backward-extension
   convergence are separately selectable. Center/focus confusion differs from
   confusing a finite-distance image with a focus. The stem does not reveal
   either correct transformation. Focal behavior necessarily overlaps the
   parallel-ray portion of question 7, but question 7 additionally tests center
   and incoming-focal rays; neither entire source task is duplicated.

6. Formula: the prompt supplies the sign convention needed to interpret its
   quantities, not the formula or the virtual-object definition. Statements
   test the signed formula, magnitude substitution, negative unknowns and
   converging-input virtual object. The sign convention also appears in the
   magnification question as necessary notation; it does not disclose this key.

7. Construction rays: the visible prompt explicitly restricts to a converging
   lens. It tests three ray transformations, not production of a drawing.
   The original source does not specify a diverging-lens drawing or an object
   position; the converging-only scope and lost self-generation need to be
   checked against the author's declared coverage. C is a truthful conditional
   statement about a ray actually incident through the left focus. It does
   not say such a source-to-lens segment exists for every real object. For an
   object inside F, only that line's backward extension reaches the left focus;
   C must not be expanded into a universal physical construction instruction.

8. Magnification: H is object size and h is image size in this draft, the
   opposite letter convention from the reviewer's illustrative source solution,
   but the stem explicitly defines both. The required ratio is h/H.
   Recognizing image/object, unsigned rather than signed magnitude, and linear
   rather than area ratio preserves the source's conceptual distinctions.

All eight visible questions have native single/multiple response units.
Choosing statements loses spontaneous verbal/formula production. This is a
concrete capacity loss, not automatically an essential task omission.
Each distractor has a different mathematical operation; their similar formatting
does not supply an answer. Standard concept dependencies between refraction and
critical angle, and focus and construction rays, are not cross-question answer
instructions. No source numbers, internal derivations or mappings are visible.

## Independent complete option checks: identical in ZH and EN

Refraction-law: true set {B}.
A: cosine corresponds to using the surface reference, contrary to the stem.
For n1 = 1, n2 = 1.5, i = 30 degrees, r = arcsin(1/3), cosine sides differ.
B: n1 sin(i) = n2 sin(r) and coplanarity give the general ordinary-media law.
C: interchanging n1/n2 predicts the opposite bend and fails the same example.
D: replacing sine by angle is only a small-angle approximation. Here r is about
0.339837 rad, so 1.5r is about 0.509755, not i = 0.523599 rad.
Coincident equality of other formulas at normal incidence or n1 = n2 does not
make them generally applicable laws.

Index-reference: true set {D}.
A: uses v/c for absolute indices and reverses both relative physical ratios.
B: absolute definitions are right but relative medium order is inverted.
C: erases the medium-1 reference; n1 = 1.5, n2 = 2 gives n21 = 4/3, not 2.
D: dividing c/v2 by c/v1 gives n2/n1 = v1/v2.

Critical-angle: true set {A}.
A: setting r = 90 degrees in Snell's law gives sin(ic) = n2/n1; larger
incidence has no propagating transmitted ray.
B: n1/n2 > 1 makes this arcsine not a real incidence angle.
C: reverses the threshold: normal incidence transmits, not TIR.
D: uses the complementary angle; n2/n1 = 1/2 gives 60 rather than 30 degrees.
At the isolated ratio 1/sqrt(2), arcsine and arccosine coincide, but D is not
the formula for arbitrary media satisfying the prompt's condition.

Thin-lens-definition: true set {C}.
A: comparing macroscopic thickness to wavelength is not the geometric
thin-lens criterion, and omits relevant geometry.
B: small thickness/diameter alone does not control curvature or imaging scales.
C: the relevant thickness/radius and thickness/distance ratios are negligible,
permitting a single-plane approximation.
D: permitting thickness comparable to curvature radii invalidates the claimed
universal combination even if the imaging distances are large.

Principal-focus: true set {A,D}.
A: paraxial axial-parallel rays actually meet at outgoing real focus.
B: an off-axis parallel ray refracts toward/away from focus, not the center.
C: F = 10 and d = 30 give f = 15, not the focus at 10.
D: a diverging lens's outgoing rays have backward extensions meeting at the
incident-side virtual focus; actual rays do not converge there.

Signed-lens-formula: true set {A,C,E}.
A: signed 1/d + 1/f = 1/F includes real/virtual quantities in the given model.
B: F = 10, d = 5 give f = -10; magnitude-only LHS = 0.3, RHS = 0.1.
C: 1/f = 1/F - 1/d keeps f signed; the preceding example returns f = -10
despite a positive coefficient of the reciprocal unknown.
D: an actual emitter on a side does not define incident converging rays; side
alone does not make it virtual. For illumination from that emitter, the
incident/outgoing labels would be set by its actual ray direction.
E: extrapolated incident convergence is exactly the virtual-object definition.

Construction-rays: true set {A,C,D}.
A: a nonaxial parallel ray emerges through the outgoing real focus.
B: such a ray changes slope toward focus, so parallel-to-parallel is not the
general transformation. The on-axis limiting ray does not rescue the rule.
C: an incoming ray passing through the object focus emerges parallel. With
lens at x = 0, incident focus (-F,0) and lens height y0, incident slope y0/F
is changed by -y0/F to zero. The supporting-line distinction noted above
limits availability, not the truth of the explicitly stated conditional rule.
D: a ray through optical center has y0 = 0, so its slope change is zero in
this thin-lens/equal-medium approximation.
E: an off-axis central ray stays straight and does not necessarily pass through
the axis focus; "always" is false.

Size-magnification: true set {B}.
A: reverses the seed's image/object ratio; image twice object requires 2, not 1/2.
B: h/H = |f|/|d| is the nonnegative linear-size ratio; orientation is separate.
C: signed -f/d can encode inverted orientation, but is not the seed's
nonnegative size ratio. With d = 30, f = 60 it gives -2 instead of +2.
D: squaring produces the area factor for similar images, not the linear factor;
with h/H = 2 it gives 4 instead of 2.
