# 79. 眼睛　眼镜

眼睛　人的眼睛差不多是球形的（图 184）. 它的直径大约是 $2.5$ 厘米，外面包有一层白色的保护壳层（膜）——巩膜 $1$.巩膜前边的透明部分 $2$ 叫做角膜. 在眼睛结构图中可以看到在角膜后边某距离上是用特殊物质染成某种颜色的虹膜 $3$.角膜和虹膜之间是前房液 $4$. 虹膜里有一小孔 $5$，叫做瞳孔.根据入射光的强度不同，瞳孔直径反射性变化的范围大约在$2$—$8$ 毫米之间. 这个过程类似于照相机的光圈变化. 在瞳孔的后面是晶状体 $6$——象透镜似的透明的一层物体. 特殊
