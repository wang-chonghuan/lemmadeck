# 光的色散

先把物质和它的状态固定，并考虑各处性质相同、各个方向性质相同的普通透明材料。
在这种简单模型中，只改变光束的入射角，不会改变材料对同一种颜色的光的**折射率**。
但是换一种颜色，折射率就可能不同，牛顿发现并研究了这种差别。

牛顿改进望远镜时，注意到物镜形成的像带着彩色边缘，物镜就是望远镜前端用来形成像的透镜。
这些彩边让他很感兴趣，他开始仔细研究不同颜色的光。
牛顿的墓志铭称赞他开创性地研究了光线的多样性，以及由此产生的不同颜色的特点。

墓志铭还说，这样的发现是当时人们没有预料到的。
不过，在牛顿之前，人们已经看见透镜形成的像带有虹彩，也看见通过棱镜观察的物体有虹彩边缘。
光束穿过棱镜后也会出现彩色边缘，这些旧观察提出了一个需要实验弄清的问题。

牛顿的基本实验很简单，他让太阳光穿过护窗板上的一个小孔，形成一束细光，进入黑暗的房间。
这束光射入玻璃棱镜后发生折射，在对面的墙上形成伸长的虹彩光斑，原书用图 196 表示这个实验。
许多世纪以来，人们习惯把彩虹分成七种基本颜色，牛顿也沿用了七种颜色的分法。

原书按紫、靛、蓝、绿、黄、橙黄、红的顺序列出这些颜色。
牛顿把这条七色光带叫作**光谱**。
这些名称帮助我们描述光带，实际的太阳光谱中相邻颜色是逐渐过渡的，并不是只有几条彼此隔开的颜色。

牛顿用红玻璃挡住小孔时，墙上只出现红色光斑。
换成蓝玻璃时，墙上出现蓝色光斑，其他颜色的玻璃也可以这样比较。
这些观察说明，过去认为棱镜把光染上颜色的猜想不对。

在这里的普通玻璃实验中，棱镜不是制造新的颜色，而是把原来混在一起的不同颜色分开，原书对此保留了引用“彩图 I”。
白光不是只有一种颜色，它可以分解出许多不同颜色的光。
这些光一起进入我们的眼睛时，共同使我们产生白光的感觉。

原书再用一块相对第一块转动了 $180^\circ$ 的棱镜，并在合适的摆放条件下，让光谱中的全部光束重新会合。
这样又能得到白光，原书把这一步与“彩图 II”相联系，关键是让全部颜色重新混合，不是只转动棱镜就一定成功。

如果选出足够单一的绿色光，再让它通过普通玻璃棱镜，它仍是绿色，不会因为折射变成另一种颜色。
这里的“足够单一”很重要，如果选出的绿色光仍含有相近的颜色，棱镜还可能把这些细小差别进一步分开。

牛顿在《光学》中说明，不同颜色的光受到折射的程度不同，也就是玻璃对不同颜色有不同的折射率。
在原书讨论的普通玻璃和可见光范围内，紫光的折射率最大，红光最小，这说的是玻璃通常表现出来的情况。
**折射率随光的颜色改变的关系叫作色散**，不能把刚才的红紫顺序当成所有材料在所有颜色范围内都必须遵守的规则。

为了更清楚地区分颜色，牛顿又改进了观察光谱的实验。
圆孔形成的不同颜色的圆形光斑会有一部分互相遮盖，原书在这里再次引用图 196。

他用明亮光源照亮的狭缝代替圆孔，再在缝后放一个透镜，让狭缝在屏幕上形成白色的窄条纹像。
在光路上放入棱镜后，这个狭缝的像就展开为光谱，原书用图 197 表示这种安排。

在刚才讨论的玻璃中，红光折射率较小、折射较小，它在玻璃中的传播速度最大，而紫光的传播速度最小。
这里说的传播速度，是光波中相同振动阶段向前推进的速度，叫作相速度，颜色不同，这个速度可以不同。
折射率与这种速度有关，所以普通玻璃能让不同颜色受到不同程度的折射，把白光分开。

在真空中，不同颜色的光以相同的速度传播，不能把玻璃中的快慢顺序搬到真空中。
原书用罗默观察木星的卫星 $1$ 来说明这一点，它设想如果这些颜色在真空中快慢不同，卫星刚离开影子时会偏红，快进入影子前会偏紫，但没有观察到这种现象。
这是原书保留的历史解释，没有看见这种色彩变化可以作为相关观察，却不能单凭它当作对各种颜色真空光速的精确测量。

知道白光含有多种颜色，就能理解纸、草和树叶为什么有不同颜色，这里只讨论普通的不发光、也不把入射光转换成另一种颜色的物体。
白光照到白纸上时，各种颜色都能被反射，反射后的颜色比例大致保持，因此纸看起来是白色的。
在纸上涂一层红色，并不是涂层创造了新的红光，而是它改变了哪些入射光能够返回我们的眼睛。

原书把这说成只反射红光、吸收其余颜色，在实际的普通红色涂层中，更准确的说法是主要反射红光，并吸收较多的其他颜色。
太阳光照到草和树叶上时，它们主要反射绿光，并吸收较多的其他颜色，所以我们看见绿色。
原书用“只反射绿色”简化这个过程，不是说真实的叶片完全不反射任何其他颜色。

原书接着考虑只让红光通过的理想红玻璃，用它来观察草。
草反射的绿光很难通过这种玻璃，能到达眼睛的光就很少，所以草几乎呈黑色，这里的“几乎”也保留了实际颜色并不完全单一的余地。
