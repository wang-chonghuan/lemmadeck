# **124. 磁通量**

为了精确地、定量地表述法拉第电磁感应定律，需要引入一个新的量——**磁通量**.

现在，我们讨论一个放在匀强磁场中的平面闭合导线(回路)，回路的面积等于 $S$. 平面回路的法线 $\vec{n}$ 与磁感应强度 $\vec{B}$的夹角为 $\alpha$ (图 283). **磁感应强度****的大小跟面积 $S$ 和 $\vec{B}$ 与 $\vec{n}$ 的夹角 $\alpha$****的余弦的乘积，叫做通过面积 $S$ 的****磁通量 $\Phi$**：$\Phi=BS\cos\alpha$.　(12-1)

![图 283](../../figures/fig-283.svg)

*图　283*

乘积 $B\cos\alpha=B_n$ 是磁感应强度在平面回路法线上的投影. 因此，$\Phi=B_nS$.　(12-2)

磁感应强度 $\vec{B}$ 表征空间中每一点的磁场. 磁通量不仅与$\vec{B}$ 有关，而且与回路面积和回路相对于磁力线的取向有关.

可以把磁通量解释为穿过面积 $S$ 的磁力线的数目. 如果规定穿过垂直于矢量 $\vec{B}$ 的单位面积的磁力线数目等于矢量的大小 $B$，则磁通量就等于穿过面积 $S$ 的磁力线的数目.
