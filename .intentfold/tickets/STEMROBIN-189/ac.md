# STEMROBIN-189 验收

要求以 Plane 当前工单及用户原指令为准。

1. 暂停：六个当前聊天的完成暂停回执、最新紧凑 idle 快照和定时器 PAUSED 读回；保留现有检查点，不发送恢复消息。
2. 接收：对支持的执行回执包装运行工具；真实失败、字段冲突、缺失双流和漂移哈希均拒绝。不得重新执行生产命令。
3. 增量装订：临时真实页对象装订两次，文件字节、mtime 和附属文件不变；修改一课后其余课仍不变，原结构/数学校验继续执行。
4. 来源复用：同次多课调用仅读取一次页集并重建一次权威来源；新调用能发现改变的来源和错误绑定，无持久陈旧缓存。
5. 图片复用：当前有效 PASS 与未变来源/规格/输出保留；漂移与失败证据仍拒绝。技能场景核对新增或受影响数学、选项和显示仍需一次实质独立复核。
6. 交付：聚焦回归和项目机械检查一次；提交到本修复分支并普通 push，核对远端 commit。不合并、不部署、不写共享数据库，六组及监控保持暂停。
