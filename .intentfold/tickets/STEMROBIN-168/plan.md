# 实施路线

## 代码事实

- `catalog.tsx` 的学科、册、章已使用原生 `details/summary`；课节有子节点时，标题却包含会调用 `onNavigate` 的课程链接。
- 叶子课程和子课题按各自的发布状态显示链接或不可操作的文字。手机的 `onNavigate` 会收起目录抽屉。
- 部分课节既有自己的课程卡又有补充子课题；用户明确要求所有可折叠项禁止跳转，因此也移除这类标题的链接，不改其课程记录和阅读顺序。

## 顺序

1. 沿用 `LessonRow` 的原生折叠结构，把分支标题改成普通文字，保留现有类名及可用性外观，不增加点击处理器。
2. 叶子渲染路径保持不变；实现后增加针对分支无链接、叶子可用性及导航回调的测试。
3. 在真实课程目录执行票据验收，检查不同层级、不同点击区域、键盘及手机抽屉；运行 Charter 指定的机械检查并交付预览。

## 边界

路线不涉及数据库写入、依赖变更、受治理 token 文件或生产操作。只修改目录组件与其行为测试。无待定产品决策；详见 `grill.md`。
