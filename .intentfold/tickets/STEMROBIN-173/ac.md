# Acceptance Evidence

## AC 1: Current Artifacts

Derive generated choice packages and exclusive choice assets from current artifact
paths and their references. Count them before deletion without backing up their
contents. After deletion, repeat the inventory and require zero former packages
or exclusive assets. Inspect controllable scratch copies and remove matching
former generated content. Preserve the rewritten skill, source textbooks, lessons,
written exercises and their answers. Git history and provider-managed backups or
logs are not represented as erased.

## AC 2: Active Database

Use the existing content DB helper. In one transaction permanently remove every
old choice deck and clear all learner answer, practice, quiz, recitation and
mistake records, as explicitly requested after filing. Require zero rows in those
activity tables and zero remaining choice decks. Compare the lesson-content hash
excluding the removed choice key to prove original content is unchanged.
Do not log student answers, export question contents or create a backup.

## AC 3: Product And Checks

Run the local app on the recorded ticket port. A ticket-scoped headed browser
check at the Charter's desktop and mobile viewports must show no former choice
questions while the lesson text and written exercises remain readable. Use the
test learner, without creating or modifying learner records. Run the existing
mechanical-defence commands once after implementation. Record the actual deletion
counts and any limits without claiming unavailable evidence.
