# 实现路线

现有 p2c 已要求 book，choice 的实际留存入口却在临时脚本中默认 6p；
现代定稿直接写入既有 0444 文件；范围备料脚本延后检查退出码。
成功命令的混合标准输出并不是一个 JSON 文档。原四个工作树仍有有效
草稿和独立审查，不能整体合并，也不能用新内容覆盖首次失败证据。

1. 在既有课文工具中收敛必要的生产辅助入口：明确仓库、书册、课程和
   输出身份；保留选择题时验证已批准快照与正确课程，禁止静默覆盖。
   备料首失败停止，日志与机器结果分开，历史混合输出用结构化解码。
2. 最小修改工作输出写入与技能流程：证据只读、工作副本可写；明确技术
   恢复与实质修改不同；收取已有子结果后接续，直接人类暂停优先。
   证据引用既有来源和哈希，不复制运行时或整本 PDF。
3. 精确迁入 n104/n105 所需原课、来源、批准模板、答案和题组，复用批准
   字节恢复归属及定稿。另修 source464 受影响转写，并定位未检查部分、
   source461/463 技术误停、混合输出候选、B 未收取成果和 A/科学真实缺口。
4. 补一次受影响内容独立复核；离线桌面/手机显示（不写共享 DB）；
   项目机械检查一次。review 交付，不关闭、不合并、不部署、不恢复工人。

原暂停工作树仅作为只读取证来源。恢复只写本工单工作树；不添加
基础设施、依赖、schema、计量系统或全局重新审查。
