# 为你决定

1. 问题：应原地修四个暂停工作树，还是独立迁入？
   建议：独立修复工作树，只迁入必要产物。
   理由与决定（本 agent）：工单明确保留原始证据且不合并生产分支；
   四组现状已读取，B/C/D idle，A 未加载且图片限额失败，不恢复任何会话。

2. 问题：技术失败后的恢复是否重置内容/图片额度或赋予科学批准？
   建议：不重置，只纠正执行失败归因，从失败阶段继续。
   理由与决定（本 agent）：工单明确区分可逆工具错误与真实内容失败；
   复用已通过快照，保留首次失败及真实预算。

3. 问题：不允许写 DB，如何验证恢复内容显示？
   建议：使用既有离线课程渲染和 choice HTML，隔离 headless 双视口检查。
   理由与决定（本 agent）：DB 禁写及后台浏览器是明确约束；需要证明
   可读显示，不允许为了验收先发布。没有应用 UI 或 schema 改动。

4. 问题：找不到 A 原稿或科学批准时如何交付？
   建议：逐项保留准确局部缺口，不重写原稿、不制造勘误或批准。
   理由与决定（本 agent）：工单验收允许基于证据的准确未恢复结论，
   其他可恢复工作继续，不能把局部不确定外推到整组。
