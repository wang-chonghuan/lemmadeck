# Plan

## Existing surface

- 课程页 loader 已一次取得课文与全部习题，但屏幕视图只渲染当前标签页。
- 仓库保留的 `getLessonPdf` 从数据库读取预存 PDF，不符合本工单的浏览器生成约束，不复用该数据路径。
- `lesson.pdf` 中英文文案、Lucide `Download` 图标和 `.sr-icontool` 页头按钮样式来自原有 PDF 下载界面，可以直接复用。
- 当前没有课程打印样式或同时包含课文与习题的打印 DOM。

## Route

1. 在课程页页头恢复 PDF 下载图标按钮，点击后调用浏览器打印流程。
2. 复用现有课文和习题渲染器增加一份仅打印时显示的整课文档；习题打印版本不挂载答案输入、判分或本地作答状态。
3. 增加打印媒体样式：隐藏应用壳、标签页、导航和交互控件，设置适合 A4 的内容宽度、分页边界及图表缩放。
4. 在设计文档记录稳定的课程打印规则，不改颜色、字号或其他 token。
5. 用工单级 Playwright 脚本验证下载入口、`window.print` 调用、整课打印内容和浏览器生成 PDF 的布局；最后运行项目机械验证。
