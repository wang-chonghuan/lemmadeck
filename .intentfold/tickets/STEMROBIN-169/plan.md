# 实现路线

已有 choice.mjs 完成备料、来源绑定、数学判据、审核校验和发布。界面和判分复用已经交付的版本，不产生新的 UI、schema、状态机或模型提示设计。

1. 从教材索引派生第二章集合。读取共享内容库，保存原内容、已有题集及文件的哈希快照，仅对缺失集合备料。
2. 主模型逐题求解、拆分语义目标、编写干扰项；图题使用原图或既有 FigureSpec 渲染。首次新图类型先做真实样本。
3. 按技能进行独立语义审核，修正实际发现；只对缺失题集 finalize / publish，发布前再次拒绝覆盖已有内容。
4. 以快照和本地桌面/手机浏览器确认覆盖及保留。记录本工单的墙钟时间与实际 token_count 计数差；缓存、推理是输入/输出子集，不重复累加。

产物写入各课 choices 文件和 choice-figures；临时取证在本票 tmp；统计留在本票 metrics.json。原题、课文、答案、原图不改。没有额外模型 API 消费。
