# 可执行验收

## AC1
从 TOC 派生本章全部含教材题的课，验证每份题集 coverage 全部原题、语义审核通过且 DB revision 匹配。浏览器逐课打开习题，断言全部题目连续呈现、无加载或错误残留。

## AC2
比较起始快照：已有选择题完整 JSON、revision 和持久文件哈希完全不变。所有课原课文及去除 choices 后的教材题 JSON 哈希不变。

## AC3
按 operations 指定桌面与手机视口检查新题、全部图表加载及文字容器无溢出。用测试用户 2 点击单选、等待判分，检查无提交按钮和原有书写题无输入；只清理本检查产生的事件。

## AC4
统计列出新增和跳过课、本次 UTC 起止/耗时，主会话与独立审核会话的可核实 token 计数差。输入含缓存，输出含推理，不重复相加；记录计量截止点和不可得部分。
