## Five Questions

1. Power describes how quickly mechanical work is done: work per unit time.
It is not force, total work, motion speed or stored energy.

2. Average power over a nonzero time interval is N=A/t, with work and time
in compatible units. This chapter's constant-power examples also use the
same quotient. Do not assume arbitrary instantaneous power is constant.

3. SI power unit is watt,W;1W=1J/s. J is work, N is force, J*s is not power.

4. Source engineering units are kW,MW and horsepower:
1kW=1000W;1MW=1000000W;source1horsepower=736W.
Preserve the stated source convention instead of silently substituting
a different imperial/metric horsepower conversion.

5. For constant engine power N over time t, A=N*t. If power varies, the
same multiplication requires average power over that interval. Convert
minutes/hours to seconds when N is in watts and A is in joules.
