## s27：自然界和工程技术中的摩擦

### s27 / g1 / 1

原题：在人和动物的生活中，摩擦具有什么意义？

独立推导：行走的推进阶段，脚向后蹬地；脚和地面不相对滑动时，地面对脚的静摩擦可向前作用，提供推进并避免脚打滑。人用手从侧面夹住物体、物体静止时，手与物体间适当的静摩擦可阻止它向下滑落。另一方面，相对滑动会带来阻碍、发热和磨损，因此摩擦的作用不能一律说成有益或有害。

完整源解：摩擦帮助人和动物行走、立足而不打滑，也帮助人抓握物品；鞋底与冰面间摩擦过小时容易打滑，撒沙可改善课文所述情形的防滑条件。摩擦还会造成例如鞋底磨损、皮肤擦伤等不利影响。因此应按具体用途利用或增大有益摩擦，减小有害摩擦。

尺度及开放性：这是意义说明，不规定唯一生活例子。不要把静摩擦全称为滑动摩擦，也不把“没有脚底摩擦难以正常蹬地行走”扩大成“没有摩擦时任何物体都不可能运动”。抓握的例子限定侧面夹持，不声称从下方托住物体也只能依靠摩擦。保留 `ungraded`。

### s27 / g1 / 2

原题：摩擦对于交通运输具有什么意义？

独立推导：驱动车轮在地面上正常滚动、不打滑时，与地面的静摩擦可提供车辆所需的牵引力。制动时，制动部件之间的摩擦阻碍车轮转动，而轮胎与路面间的作用使车辆减速；轮胎未滑动时接触处仍可为静摩擦，抱死滑行时则出现滑动摩擦。轴和轴承等部位的摩擦又产生能量损耗、发热和磨损，应予减小。

完整源解：有益摩擦使车辆能起步、获得牵引并制动，还能防止轮胎打滑。图78中的胎面花纹以及课文所述冰雪路况使用的防滑链，都是利用较好的路面附着条件。交通工具内部转动和滑动部件的有害摩擦应通过润滑、适当轴承等方式减小，以减少损耗、发热和磨损。应增加需要的附着与制动作用，而不是把车上所有摩擦一概减小或增大。

尺度及开放性：不说“轮胎摩擦永远向前”，也不说“摩擦只会阻碍车辆前进”。区分驱动、制动和内部损耗，允许其他合理交通实例；轮胎和路面并不是每次都在发生相对滑动。保留 `ungraded`。

### s27 / g1 / 3

原题：你知道哪些减小摩擦的方法？

独立推导：依据 raw 课文，改善配合表面并加润滑剂，可减小轴等接触部位的滑动摩擦。把主要的滑动接触改为滚动体承载，可利用相同负荷下滚动阻力通常较小的课堂比较。方法必须针对需要减小的摩擦部位，而不能用于需要附着的轮胎或抓握部位。

完整源解：可把机器的配合接触面做得适当光滑，在接触面之间加入润滑剂；可用滚珠、滚柱轴承等装置，以滚动代替主要的滑动接触。课文中的滑动轴承还采用合适的轴瓦材料和润滑，使轴能较顺畅地转动并减少磨损。这些办法用于减小有害摩擦，不是把所有摩擦消除。

尺度及开放性：不需要摩擦系数或精确减小倍数，也不宣称抛光对任何材料和接触情况都必然减摩。课文的 `1/20～1/30` 是使用滚动轴承替代滑动轴承的工程举例尺度，不是所有装置必达的精确比例；本题未要求计算或背出该范围。开放例举允许合理的其他减摩方法，但此源解不扩编题目。保留 `ungraded`。

### s27 / g1 / 4

原题：在机器中使用轴承的目的是什么？

独立推导：机器中的轴需要被支承和定位，同时能相对轴承架转动。若直接以不合适的接触承受运动，摩擦、发热和磨损较大。滑动轴承以适当轴瓦及润滑改善接触，滚动轴承以滚动体改变主要的相对运动方式。

完整源解：轴承用于支承转轴并使其能较顺畅地转动，减小轴与支承处的有害摩擦，从而减少能量损耗、发热和磨损。滑动轴承通过合适的配合材料及润滑减摩；滚珠或滚柱轴承主要用滚动代替滑动。

尺度及开放性：轴承不是消除所有摩擦，也不是使轴完全不受支承作用。题目问目的，答支承与减小有害摩擦并说明后果即可，不强制唯一措辞，不另造计算小问。保留 `ungraded`。

### s27 / g1 / 5

原题：滑动轴承和滚珠轴承的构造各是怎样的？

独立推导：图79和其图注给出滑动轴承的轴承架1、轴瓦2、轴3及加油孔4。轴瓦装在轴承架中，包围与轴接触的配合部位；轴在轴瓦内转动，接触处有相对滑动并需要润滑。图80左图给出内圈、外圈及它们之间的球形滚动体；课文给出两圈的固定关系。

完整源解：滑动轴承由轴承架及其中的轴瓦等组成，轴装在轴瓦内。轴承架支承轴瓦，轴转动时沿轴瓦接触面滑动，并可经加油孔加入润滑剂。图79的编号对应为1轴承架、2轴瓦、3轴、4加油孔。课文说明轴瓦可用青铜、铸铁或钢等材料，并在内表面敷特殊材料，常用巴氏合金，同时润滑。

滚珠轴承有内圈、外圈及两圈之间的钢制滚珠：内圈装在轴上，外圈固定在轴承架内，轴带动内圈转动时，滚珠在圈之间滚动，以减小主要滑动接触带来的摩擦。图80右图是把球形滚动体改为圆柱形滚动体的滚柱轴承，不混称为滚珠轴承。

尺度及开放性：完整回答应包含两类结构和相对运动区别，但无需逐字复述材料清单。原图没有要求学生填图号或编号，编号在此是读图证据而非自动判分槽；不从原图猜制造尺寸，也不把未清楚提供的保持架等结构当作图中已见事实。保留 `ungraded`。

## s28：分子间的相互作用力

本课采用近距离分子相互作用的定性模型：“分子引力”是本课所说的分子间吸引作用，不把它解释为砝码与地球之间的重力。引力和斥力可以同时存在，讨论的是两者大小与合力；没有引入精确作用力函数或可由图中读出的数值。

### s28 / g1 / 1

原题：举出一个克服分子引力的例子。

独立推导：把线拉断，需要让断裂处原本连在一起的物质分离。外力所做的拉断作用克服了使这些部分保持结合的分子间吸引；这不是把单个分子拉得更重或把单个分子劈开。

完整源解：例如用力把一根线拉断，外力克服断裂处许多分子之间的吸引，使线的两部分分离。折断木棍、打碎冰等也可作为课文范围内的合理例子。图81中的悬挂砝码是对线施加拉伸作用的源例，但图中并没有画出线已断裂。

尺度及开放性：题目只要一个合理例子及其物理含义；不是必须回答某一种材料或给出250牛顿。课文举例的约250牛顿针对指定横截面丝线的宏观断裂，不是单个分子作用力，也不是每根线都具有同一个拉断阈值。保留 `ungraded`。

### s28 / g1 / 2

原题：为什么组成物体的分子不能彼此“紧紧地”靠在一起？

独立推导：在平衡距离处，引力与斥力大小相等；继续缩短距离时，斥力增长得更快并超过引力，合力使分子相互推开。因此要继续压近就需要克服越来越强的短程斥力。

完整源解：分子间既有引力，也有斥力。距离太小时，斥力增大得很快并超过引力，产生把分子推开的合力，阻止它们任意紧靠或相互重合；所以物体中的分子不是被引力拉到零间距而堆在一起。

尺度及开放性：不能说只有引力，也不能说分子从不靠近或物体绝对不能压缩。平衡时是两种作用抵消，而不是两种力都消失。图82的圆形轮廓只作示意，不用硬球图像代替分子相互作用解释。保留 `ungraded`。

### s28 / g1 / 3

原题：当分子间的距离逐渐减小时，分子间的引力和斥力是怎样变化的？

独立推导：按本课比较的距离范围，从相距分子自身大小几倍的较远状态开始，引力很小，斥力比引力更小。距离逐渐减小，两种作用都增大，但斥力增大得更快。因而先由引力占优，到两者相等，再到斥力占优；对应图82上、中、下三组。

完整源解：在课文描述的定性范围内，分子距离减小时，引力和斥力都增大，斥力增长得更快。较大距离时引力大于斥力；到平衡距离时，两者大小相等、合力为零；再靠近时，斥力大于引力，合力表现为相互推斥。

尺度及开放性：不要把这个过程改成“引力先消失，斥力才出现”，或“距离减小只有斥力改变”。合力为零不表示引力和斥力各为零。不把课文的近距离定性规律推广成任意尺度的精确函数，也不读箭头像素计算倍数、平衡距离或单位值。保留 `ungraded`。

### s28 / g1 / 4

原题：为什么拉伸钢索的力停止作用后，钢索就收缩？

独立推导：按未断裂且仍处于弹性变形范围的通常前提，钢索受拉时分子间距相对原平衡距离增大。此时分子间引力胜过斥力，产生恢复原来距离的趋势。撤去维持拉伸的外力后，恢复作用使钢索缩短，朝未拉伸时的长度恢复。

完整源解：弹性拉伸使钢索分子间距增大，分子间引力大于斥力，形成使钢索恢复的弹性作用。外部拉伸力撤去后，这种恢复作用使钢索收缩，趋向原来的长度。钢索的弹力来源于其分子间相互作用，不是外力撤去后分子作用也随之消失。

尺度及开放性：raw 题面没有明写“弹性范围”，这里明确记录该常规物理前提，不能把收缩及恢复原长无条件推广到已发生塑性变形或断裂的钢索。也不承诺撤力瞬间已经完全恢复、绝无振动或能量损耗。若未来现代题增加过载、约束或永久变形条件，应只重核这一受影响题及相关解释。保留 `ungraded`。
