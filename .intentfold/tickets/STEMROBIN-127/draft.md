# 已确认的做法

- 这次把 6a 当作现行 S10Y 链路的首批真实试产，不另建生成入口；所有修复都落回
  `ld-s10y-lesson`、`ld-s10y-image` 或 `ld-s10y-answer` 已有职责内。
- 先修目录认领缺口，再生产前两个单元。目录修复要按 TOC 的结构字段认领章末习题和全书
  难题，不能靠标题特判，也不能给它们制造新的回退编号。
- 页面抽取只向后多读闭合第二单元所需的边界页；若边界页出现第三单元开头，忠实完成页级
  转写，但只把前两个完整单元送入现代版和发布器。
- 发布顺序固定为基础课程、答案、交互规格，因为基础课程重发会保留 `answerKey`，但会清掉
  `interaction`。
- 试产遇到缺陷时，只修阻塞这两个单元贯通产品的确定性问题；内容风格改进、其余单元和历史
  兼容层均不顺带处理。

# 已核实的前提

- 源 PDF 共 289 个物理页，无嵌入字体；物理页 7 对应印刷页 1，页码偏移为 6。
- 6a TOC 有 55 个编号单元、5 个章末补充习题条目和 1 个全书难题条目；后六项当前不在
  `topics` 数组内，因此现有 `check_toc()` 不会给它们分配正式卡片 ID。
- 应用目录已经能表达并展示纯练习卡片，当前缺口在装订器的目录索引，不需要 UI 或 schema
  改动。
- 当前数据库没有 `alg6-%` 课程行，仓库也没有 `resources/s10y-lessons/6a/` 产物，不存在
  覆盖已有 6a 内容的问题。
- 书后答案从物理页 278 开始；物理页 286 已进入附录，答案抽取边界可以由该范围确定。

# 明确排除

- 不把章末习题或难题改造成伪编号单元；这样会污染教材原有层级和连续编号语义。
- 不提前批量转写整本书；首批的目的正是用最小完整切片暴露并修复管线问题。
- 不手写数据库行、不绕过技能审计、不把答案写入客户端可见的交互规格。
