## Source 1: All Seven Coordinate Triples

Task: identify every coefficient in the fixed order (i,j,k), including absent
components, the zero vector, negative and irrational coefficients, and a written
expression whose term order differs from coordinate order.

1. i+2j-3k has coefficients (1,2,-3).
2. 8i+k has coefficients (8,0,1).
3. 0.5j-sqrt(2)k has coefficients (0,1/2,-sqrt(2)); retain 0.5 in visible data.
4. 7j has coefficients (0,7,0).
5. i has coefficients (1,0,0).
6. 0 has coefficients (0,0,0), by uniqueness of its expansion.
7. 8k+i has coefficients (1,0,8), regardless of written term order.

Full task solved from blocks 0 and 5. The distinction is ordered coefficients,
not unsigned geometric lengths or the order in which terms are printed.

## Source 2: All Three Sums/Differences

Given a=(-2,3,0), b=(1,-1,5), c=(7,0,4).

1. a+b=(-2+1,3-1,0+5)=(-1,2,5).
2. a-c=(-2-7,3-0,0-4)=(-9,3,-4).
3. a-b+c=(-2-1+7,3-(-1)+0,0-5+4)=(4,4,-1).

Full task solved from blocks 9 and 10. Subtraction changes all components of the
subtrahend; adding c after subtracting b is not subtracting their sum.

## Source 4: Arithmetic Resolved; Original Geometric Task HOLD

Original task: explain whether each of two given vector pairs is collinear,
using the condition in section 20.

For a=(3/7,1/2,-3/4), b=(2/7,1/3,-1/2), solve b=t a:
t=(2/7)/(3/7)=2/3; (2/3)(1/2)=1/3 and
(2/3)(-3/4)=-1/2. Thus b=(2/3)a by block 11 and uniqueness.
Equivalently a=(3/2)b.

For c=(-3/2,6,4/3), d=(9/8,-9/2,-1), solve d=u c:
u=(9/8)/(-3/2)=-3/4; (-3/4)6=-9/2 and
(-3/4)(4/3)=-1. Thus d=(-3/4)c.
Equivalently c=(-4/3)d.

These are exact scalar-multiple identities for nonzero vectors. The original
geometric classification and explanation are not keyed: N42's permitted
definition blocks do not provide section 20's collinearity condition.
HOLD applies to the classification of BOTH pairs, not to the arithmetic.
No recognition item is used to conceal this omission.

## Source 5: Parameter Arithmetic Resolved; Original Task HOLD

Original task: determine all x,y for which a=(x,-2,5) and b=(1,y,-3)
are collinear.

The independently solvable coordinate identity a=t b gives
x=t, -2=t y, 5=-3t. The third equation forces t=-5/3 (nonzero);
then x=-5/3 and y=(-2)/(-5/3)=6/5. Substitution checks all three:
(-5/3)(1,6/5,-3)=(-5/3,-2,5).
The reverse identity b=u a gives u=-3/5 and the same pair.
The scalar-multiple equations have exactly one solution.

What cannot be asserted from the allowed definition set is that this is
necessary and sufficient for the source's geometric predicate "collinear."
That missing link is the same section 20 boundary as source 4.
The complete original all-solutions geometric task is HOLD; no key is issued.

## Source 6: Both Scalar Products

1. For a=(-2,3,1), b=(5,7,-4):
a dot b=(-2)5+3(7)+1(-4)=-10+21-4=7.
2. For c=(1/2,3/5,-5/6), d=(-2/3,5/6,-1/5):
c dot d=-1/3+1/2+1/6=(-2+3+1)/6=1/3.

Full task solved from block 12. In particular the last product is positive;
the scalar product is a single sum, not a componentwise-product vector.

## Source 7: Both Products Resolved; Original Geometric Task HOLD

Original task: determine whether each of two vector pairs is perpendicular.

1. a=(-2,1,3), b=(6,-5,7):
a dot b=-12-5+21=4.
2. c=(6,0,12), d=(-8,13,4):
c dot d=-48+0+48=0.

Both computations are independently settled by block 12. None of these
four vectors is zero, so this is not a zero-vector convention problem.
However N42's allowed definitions give no general perpendicularity criterion
for arbitrary vector pairs. Basis vectors being pairwise perpendicular is not
such a criterion. The original geometric yes/no decisions for BOTH pairs are
HOLD, with no asserted truth set and no substitute dot-product question.
