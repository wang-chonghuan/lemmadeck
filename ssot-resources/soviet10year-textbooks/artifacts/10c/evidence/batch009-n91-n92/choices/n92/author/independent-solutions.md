## Solutions

266. cos40 cos50 = (cos90 + cos(-10))/2
     = (cos90 + cos10)/2. Angles are degrees. The sum, not merely a numerical
     approximation, is the requested response.

267. cos(pi/12) cos(5pi/12)
     = [cos(pi/2) + cos(-pi/3)]/2
     = [cos(pi/2) + cos(pi/3)]/2. Its value is 1/4, but the task asks for a sum.

268. sin(5pi/24) sin(pi/24)
     = [cos(pi/6) - cos(pi/4)]/2.

269. sin110 sin50 = [cos60 - cos160]/2, with degrees.

270. sin(x+pi/4) sin(x-pi/4)
     = [cos(pi/2) - cos2x]/2 = -cos2x/2.

271. sin(alpha+pi/3) sin(alpha-pi/6)
     = [cos(pi/2) - cos(2alpha+pi/6)]/2
     = -cos(2alpha+pi/6)/2.

272. cos(x+beta) cos(x-beta) = [cos2x + cos2beta]/2.

273. sin(x+alpha) sin(x-alpha) = [cos2alpha - cos2x]/2.

274. 4sin30 sin20 sin10 = 2sin20 sin10
     = cos10 - cos30, with degrees.

275. 4cos60 cos20 cos10 = 2cos20 cos10
     = cos30 + cos10, with degrees.

276. 4sin25 cos15 sin5
     = 2(cos20 - cos30)cos15
     = cos35 + cos5 - cos45 - cos15, with degrees.
     An alternative independent ordering starts with sin25 cos15 and gives
     2(sin40+sin10)sin5, producing the same four cosine terms.

277. 8cos1 cos2 cos4 cos8
     = 4(cos3+cos1)cos4 cos8
     = 2(cos7+cos1+cos5+cos3)cos8
     = cos15+cos1+cos9+cos7+cos13+cos3+cos11+cos5
     = cos1+cos3+cos5+cos7+cos9+cos11+cos13+cos15, with degrees.
     Every product has been eliminated. Cosine evenness handles negative angles.

278. 22 degrees 30 minutes = 22.5 degrees; 7 degrees 30 minutes = 7.5 degrees.
     2sin22.5 cos7.5 = sin30 + sin15.
     sin15 = sin(45-30)
           = (sqrt2/2)(sqrt3/2) - (sqrt2/2)(1/2)
           = (sqrt6-sqrt2)/4.
     Hence the complete exact value is (2+sqrt6-sqrt2)/4, without tables.

279. cos45 cos15 = (cos60+cos30)/2 = (1+sqrt3)/4, with degrees.

280. sin52.5 sin7.5 = (cos45-cos60)/2 = (sqrt2-1)/4.
     The degree-minute notation is converted exactly, not treated as decimal
     digits appended to a degree measure.

281. sin(pi/4) sin(pi/12) = [cos(pi/6)-cos(pi/3)]/2
     = (sqrt3-1)/4.

282. cos(pi/12) cos(pi/4) = [cos(pi/3)+cos(pi/6)]/2
     = (1+sqrt3)/4. These angles are the same as 279, in reverse order.

283. 8cos10 cos50 cos70
     = 4(cos60+cos40)cos70
     = 2cos70 + 2(cos110+cos30)
     = 2cos30 = sqrt3, with degrees.
     The cancellation uses cos110 = cos(180-70) = -cos70.

284. 2cos^2 x = 1+cos2x.

285. 2sin^2 2x = 1-cos4x.

286. 2cos^2 x cos2x = (1+cos2x)cos2x
     = cos2x + cos^2 2x
     = 1/2 + cos2x + cos4x/2. No powers or products remain.

287. cos^2 x sin^2 x = (sin2x)^2/4 = (1-cos4x)/8.

288. sin^2 6x = (1-cos12x)/2.

289. cos^2 4x = (1+cos8x)/2.

290. For all real x,
     2sin4x sin2x + cos6x
     = (cos2x-cos6x) + cos6x = cos2x.
     This is a full algebraic identity proof, not a sampled numerical test.

291. For all real x,
     sin^3 x cos^2 x = sinx (sinx cosx)^2
     = sinx sin^2 2x/4
     = sinx(1-cos4x)/8.
     Also sinx cos4x = [sin5x+sin(-3x)]/2
                     = [sin5x-sin3x]/2.
     Substitute to obtain sinx/8 - sin5x/16 + sin3x/16, the entire printed RHS.

292. For all real x,
     sin5x cos3x cos6x = (sin8x+sin2x)cos6x/2
     = [sin14x+sin2x+sin8x+sin(-4x)]/4
     = [sin14x+sin2x+sin8x-sin4x]/4, the entire printed RHS.

293. With degrees,
     4sin20 sin40 sin80
     = 2sin20(cos40-cos120)
     = 2sin20 cos40 + sin20
     = sin60 + sin(-20) + sin20 = sin60.
     Thus the four-factor product is sin^2 60/4 = (3/4)/4 = 3/16.
     The equality holds exactly, without decimal approximation.
