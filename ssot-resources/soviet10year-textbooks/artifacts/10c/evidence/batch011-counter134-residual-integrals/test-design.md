# Independent Design Before Production Patch

Contract: one printed formula row includes its numerator, denominator, nested
roots and paired carrier bounds. Separate full equation/text/fraction rows remain
separate. Geometry does not grant semantic nontext approval.

The NEW test file defines 20 separate expectations without reading old tests or
copying a native bitmap fixture. Rectangles encode owned component roles;
scale/translation tests transform those authored roles, not native imagery.

Positive expectations: paired full-looking small bounds at opposite carrier ends;
96- and 144-unit carrier lengths with 21- and 16-unit widths; two-symbol bounds
including a short minus; mixed carrier lengths; doubled scale and translation;
wide connected 167-by-97 root context retained; a 23-unit supported quotient rule;
fragmented collinear 28/23/14-unit rule pieces with complete numerator/denominator
support.

Negative expectations: missing lower end, detached ends, nonoverlapping bound
columns, wrong vertical offset, a genuine lower full equation row, a genuine upper
text row, two complete equal-width fraction levels, a bound connected to a complete
original source body despite cleanup disconnecting it, unpaired short rules,
vertically disjoint rule pieces, headed arrows, and no paired carrier gating.

No fixture expectation may be changed to match an implementation. Cases run once
after implementation is ready; only failed cases may be repaired/retried. A pass
is synthetic geometry evidence, never source approval.

Proposed narrow production scope: establish paired limit ownership from original
labels only after an existing fraction rule is found; only this proved ownership
activates small supported and collinear broken-rule completion. Preserve every
existing carrier cap, body-overlap check, arrow guard and independent-fraction
level guard. No source pixels, metadata, expectations or exclusion changes.
