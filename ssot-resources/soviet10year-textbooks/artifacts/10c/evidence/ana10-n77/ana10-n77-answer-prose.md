## 本课可用的源数学事实

原图03与源正文的面积比较给出：对 `0<|t|<π/2`，
\[
|\sin t|<|t|<|\tan t|.
\]
单位圆扇形面积为t/2，弦三角形面积为sin(t)/2，切线三角形面积为tan(t)/2；负t由正弦、正切奇性转为绝对值。角均为弧度。

由该不等式和 `|\sin t|≤1`，可得对所有实数t，
\[
|\sin t|\le |t|.
\]
在 `|t|<π/2` 内使用源不等式；其外 `|t|≥π/2>1`，由 `|\sin t|≤1≤|t|` 即得。于是
\[
|\sin x-\sin y|\le|x-y|,\quad
|\cos x-\cos y|\le|x-y|,
\]
分别由和差公式及半角正弦界推出。下面完整证明40/41，不只复述“利用连续性”。

## 40：正弦与余切在所指定各点的连续性

### 正弦在任意 x₀∈R 连续

令h=x−x₀。和差公式给出
\[
\sin x-\sin x_0
=2\cos\frac{x+x_0}{2}\sin\frac{x-x_0}{2}.
\]
因此
\[
|\sin x-\sin x_0|
\le2\left|\sin\frac h2\right|\le|h|.
\]
给任意ε>0，取δ=ε。若 `|x−x₀|<δ`，则 `|sinx−sinx₀|<ε`。这正是连续性定义，所以
\[
\lim_{x\to x_0}\sin x=\sin x_0
\quad\text{对所有 }x_0\in\mathbb R.
\]
证明包括sinx₀=0的点，不除以sinx₀或暗加非零前提。

### 余切在任意 x₀∈D(ctg) 连续

此时 `s=|sinx₀|>0`。利用已证正弦连续性，当 `|h|<s/2` 时
\[
|\sin x|\ge|\sin x_0|-|\sin x-\sin x_0|
>s/2>0,
\]
故x仍属于余切的定义域。再由和差公式，
\[
\cot x-\cot x_0
=\frac{\cos x\sin x_0-\cos x_0\sin x}
{\sin x\sin x_0}
=\frac{\sin(x_0-x)}{\sin x\sin x_0}.
\]
因此
\[
|\cot x-\cot x_0|
\le\frac{|h|}{(s/2)s}
=\frac{2|h|}{s^2}.
\]
给任意ε>0，取
\[
\delta=\min\left\{\frac s2,\frac{\varepsilon s^2}{2}\right\}>0.
\]
`|x−x₀|<δ`便给出 `|cotx−cotx₀|<ε`。所以
\[
\lim_{x\to x_0}\cot x=\cot x_0
\quad\text{对所有 }x_0\notin\{k\pi:k\in\mathbb Z\}.
\]

这不是宣称余切在整个R上连续：kπ处原函数无定义。本题为完整证明题，后续可见标准答案应保留上述论证而非单行“商函数连续”自动键。

## 41：补值函数连续性及完整作图任务

题设原函数为
\[
f(x)=
\begin{cases}
\dfrac{\sin x}{x},&x\ne0,\\
1,&x=0.
\end{cases}
\]
它的定义域是全体实数；0处不是删去的点，也不是沿用未补值的商函数。

### 全实轴连续性的证明

若x₀≠0，由正弦连续、恒等函数连续及分母x₀非零，商函数在x₀连续，即 `lim(x→x₀)f(x)=sinx₀/x₀=f(x₀)`。

对于 `0<|x|<π/2`，sinx与x同号，cosx>0。源预备不等式经除法给出
\[
\cos x<\frac{\sin x}{x}<1.
\]
源已证cosx→1（x→0）；夹逼得
\[
\lim_{x\to0}\frac{\sin x}{x}=1=f(0).
\]
本稿在这里自行证明该极限，不引用下一单元尚待生产的标准答案。

若需要直接ε–δ形式，使用
\[
0<1-f(x)<1-\cos x
=2\sin^2(x/2)\le x^2/2.
\]
给ε>0，取 `δ=min{1,√(2ε)}`。当 `0<|x|<δ`时，`|f(x)−1|<ε`；x=0时差为0。故f在0也连续，综合得到 **f在R上处处连续**。

### 图象的必要结构与实际作图信息

作图任务完整保留，不能因为证明完成就省掉图象。本次仅写答案正文，不新增图服务或图稿；标准作图应按以下信息呈现：

1. `f(−x)=f(x)`，图象关于y轴对称。
2. **实心点(0,1)**；不是空心点，也没有0处竖直渐近线。
3. 全部零点为 `(kπ,0)`，其中k是非零整数；0不是零点。
4. x>0时，每段 `(kπ,(k+1)π)` 内符号为 `(-1)^k`，k≥0；负半轴按偶性反射。中心一瓣在 `(−π,π)` 内为正。
5. x≠0时 `|f(x)|≤1/|x|`，故两侧振荡随|x|增大而衰减，`lim(x→±∞)f(x)=0`，水平渐近线为y=0。0处全局最大值为1，其余点均小于1。

供描点的精确坐标如下，所有正负横坐标成对取同一纵坐标：

| x | f(x) |
|---|---|
| 0 | 1 |
| ±π/2 | 2/π |
| ±π | 0 |
| ±3π/2 | −2/(3π) |
| ±2π | 0 |
| ±5π/2 | 2/(5π) |
| ±3π | 0 |

先描中心实心点与这些零点/中间点，再作中心平滑拱形；两侧按正负交替画递减振幅的波瓣，并以y轴反射。不能把±3π/2、±5π/2误标为精确极值点，它们只是明确可描的点。

### 波瓣极值与中心形状的精确补充

上述连续性证明已独立成立，不依赖导数。为了给完整标准图象的细部，可以在已证基本极限基础上推导导数，而不是借用未读的其他答案：

由 `lim(h→0)sin h/h=1` 和 `|(cosh−1)/h|≤|h|/2→0`，配合加法公式即得 `(sinx)'=cosx`、`(cosx)'=−sinx`。于是x≠0时
\[
f'(x)=\frac{x\cos x-\sin x}{x^2}.
\]
0处由 `|f(h)−1|≤h²/2` 得f′(0)=0，所以中心点为水平切线。

令 `g(x)=xcosx−sinx`。在 `(0,π)`，
\[
g'(x)=-x\sin x<0,\quad g(0)=0,
\]
所以f从(0,1)严格下降至(π,0)。

对每个整数k≥1，在 `(kπ,(k+1)π)`，g′符号固定，且两端g符号相反，故恰有一个零点rₖ。又
\[
k\pi<r_k<k\pi+\pi/2,\qquad \tan r_k=r_k.
\]
每一非中心波瓣恰有一个极值点：
\[
\left(r_k,\frac{(-1)^k}{\sqrt{1+r_k^2}}\right),
\]
负半轴另有关于y轴的对应点。k奇数是负瓣极小，k偶数是正瓣极大；rₖ递增保证波瓣极值的绝对值递减。这确定了图象细部，不用粗略画图猜每瓣是否多出极值。
