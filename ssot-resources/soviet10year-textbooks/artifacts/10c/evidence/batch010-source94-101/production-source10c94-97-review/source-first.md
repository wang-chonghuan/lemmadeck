Printed explanation, retaining the physical line sequence:

对于这个方程，可以利用半角的正切公式，然后再解所得
到的双二次方程。但是已知方程可以比较简单地求解。

方程左边的每一项都是关于变量 $y$ 和 $z$ 的二次单项式，
其中 $y=\sin x,\ z=\cos x$。这就是说，它是关于正弦和余弦的
二次齐次方程。正弦和余弦不可能同时等于零。因此，使这
两个函数当中的一个变成零的自变量的值不是这个方程的
解。所以可以用 $\cos^2x$（或 $\sin^2x$）除方程的两边，从而得到与
方程 (2) 同解的方程：

$3\operatorname{tg}^2x-4\operatorname{tg}x+1=0,$

由此得

$\operatorname{tg}x=1$ 或 $\operatorname{tg}x=\frac{1}{3}.$

于是，

$x=\frac{\pi}{4}+\pi n,\ n\in Z,$

或

$x=\operatorname{arctg}\frac{1}{3}+\pi n,\ n\in Z.$
