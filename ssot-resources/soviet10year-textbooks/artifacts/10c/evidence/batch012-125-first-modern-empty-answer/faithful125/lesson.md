# 125*. 历史知识

含有两个变量的方程的几何解释是由解析几何的创始人笛卡儿（1596—1650）作出的．

莱布尼兹（1646—1716）首次详细地研究了含有多个未知数的线性方程组．$1750$ 年，瑞士数学家克拉梅尔找出了含有$n$ 个变量的线性方程组的解的一般公式．可惜，按照克拉梅尔的作法，这时必须计算 $n!$ 项的和．高斯（1777—1855）提出了解线性方程组比较实际的方法．按照高斯法，一个计算人员工作一天可以解出含有十个变量的方程组，但是要解在测量学上遇到的由几百个线性方程组成的方程组，有时需要几个计算人员工作好几个月．只有电子计算机出现以后，解大量的线性方程组才成为完全能做到的事情．

从本世纪 $30$ 年代创立线性规划起，有力地推动了线性不等式组的研究．

变量的数目比两个多很多的线性规划问题更具有实际意义．为了正确地解决这些问题，理解在“$n$ 维空间”$R^n$ 中含有 $n$ 个变量的线性方程的几何解释是很重要的．

创立线性规划的方法是苏联数学家康托洛维奇所从事的工作的重要部分．
