# 51. 异分母分数的加法和减法

> 第二章　有理数 · §7. 加法和减法

问题. 玛沙用$\frac{3}{10}$小时做数学作业，用$\frac{4}{15}$小时做俄语作业.玛沙做作业用了多少分钟？

为了解这个题，要把$\frac{3}{10}$和$\frac{4}{15}$加起来. 我们已经学会了同分母分数的加法. 因此，为了把$\frac{3}{10}$和$\frac{4}{15}$加起来，必须先通分，比如取60作公分母，然后把通分后的分数加起来：$\frac{3}{10}+\frac{4}{15}=\frac{18}{60}+\frac{16}{60}=\frac{34}{60}$.

因为$\frac{34}{60}$小时=34分钟，所以玛沙做作业用了34分钟.

这样，异分母的两个分数相加，必须先把这些分数通分，如果一个分数的分母是另一个分数分母的倍数，公分母就很好求，只要把较大的分母作公分母就行了，如：$\frac{3}{8}+\frac{1}{4}=\frac{3}{8}+\frac{2}{8}=\frac{5}{8}$.

如果分数的分母彼此不是倍数，最简单的办法就是用它们的乘积作公分母. 分数$\frac{3}{10}$和$\frac{4}{15}$的公分母就是$10\cdot15$. 因此$\frac{3}{10}+\frac{4}{15}=\frac{3\cdot15}{10\cdot15}+\frac{4\cdot10}{10\cdot15}=\frac{3\cdot15+4\cdot10}{10\cdot15}=\frac{5(3\cdot3+4\cdot2)}{10\cdot15}=\frac{3\cdot3+4\cdot2}{30}=\frac{17}{30}$.

一般地说，异分母的两个分数相加，必须：1) 第一个分数的分子和分母同乘以第二个分数的分母；2) 第二个分数的分子和分母同乘以第一个分数的分母；3) 把得到的同分母分数加起来.

例1. 求$\frac{1}{6}-\frac{5}{9}$的值.

把第一个分数的分子和分母都乘以9，第二个分数的分子和分母都乘以6：$\frac{1}{6}-\frac{5}{9}=\frac{1\cdot9}{6\cdot9}-\frac{5\cdot6}{9\cdot6}=\frac{9-30}{6\cdot9}=\frac{-21}{54}=-\frac{21}{54}=-\frac{7}{18}$.

例2. 求$-\frac{1}{3}-\frac{1}{4}$的值：$-\frac{1}{3}-\frac{1}{4}=\frac{-1}{3}+\frac{-1}{4}=\frac{-4}{12}+\frac{-3}{12}=\frac{-7}{12}=-\frac{7}{12}$.

在第55节中将要说明怎样按最小公分母通分，把分数加起来.
