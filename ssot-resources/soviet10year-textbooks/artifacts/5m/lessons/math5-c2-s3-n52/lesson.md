# 52. 分数的补数

> 第二章　有理数 · §7. 加法和减法

![图 159](../../figures/fig-159.svg)

如果从一个整圆中剪下圆的$\frac{2}{5}$（图159），就剩下圆的$\frac{3}{5}$. 圆的$\frac{2}{5}$和圆的$\frac{3}{5}$加在一起构成一个整圆，就是分数$\frac{2}{5}$与$\frac{3}{5}$的和等于1. 分数$\frac{2}{5}$和$\frac{3}{5}$互补成1. 为了求出一个分数的补数，必须从1中减去这个分数，例如：$1-\frac{2}{5}=\frac{5}{5}-\frac{2}{5}=\frac{3}{5}$，　$1-\frac{3}{5}=\frac{5}{5}-\frac{3}{5}=\frac{2}{5}$.
