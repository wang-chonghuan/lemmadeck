# 49. 比例

> 第二章　有理数 · §6. 乘法和除法

一块衣料长5米，另一块长2米. 如果想知道第一块衣料的长度是第二块的多少倍，应该是第一块衣料的长度除以第二块衣料的长度：$5:2=2.5$. 第一块衣料长度是第二块的2.5倍. 这两块衣料也可以用厘米度量. 得$500:200=2.5$.$5\div2$和$500\div200$的商等于同一个数2.5. 因此它们彼此相等：$5:2=500:200$.

5和2的商也可以叫做5与2的比. 两个正数的比表示一个数是另一个数的几倍或者一个数是另一个数的几分之几.

两个比的等式叫做比例.

可以利用字母把比例写成：$a:b=c:d$ 或 $\frac{a}{b}=\frac{c}{d}$.

两种写法读作：“$a$除以$b$等于$c$除以$d$”，或者读作：“$a$比$b$等于$c$比$d$”.

在比例$a:b=c:d$中，$a$和$d$叫做比例的外项，$b$和$c$叫做比例的内项.

比例$3.6:1.2=6.3:2.1$是真的，因为它的左边和右边的值都等于3. 下面我们求这个比例的外项乘积和内项乘积：$3.6\cdot2.1=7.56$；$1.2\cdot6.3=7.56$.

一般地说，如果比例是真的，那么它的外项乘积等于内项乘积. 这个性质叫做比例的基本性质.

设比例$a:b=c:d$是真的. 如果比例左边的值等于$k$，那么它的右边的值也等于$k$：$a:b=k$和$c:d=k$.由此得$a=bk$和$c=dk$.

我们来看比例的外项和内项的乘积：$ad=(bk)d=bkd$；$bc=b(dk)=bkd$.由此可以看出，比例的外项乘积等于内项乘积：如果$a:b=c:d$，那么$ad=bc$.

应用比例可以解很多应用题.

例1. 买2.5公斤黄油用9.5卢布. 买1.7公斤黄油应付多少卢布？

设1.7公斤黄油值$x$卢布. 黄油的单价可以用以下两种方法求出：9.5除以2.5，或者$x$除以1.7. 两种情况应该得出同一个答案. 因而得比例：$9.5:2.5=x:1.7$.

根据比例的基本性质$9.5\cdot1.7=2.5\cdot x$.即　$x=9.5\cdot1.7:2.5$，$x=6.46$.

买1.7公斤黄油应付6.46卢布.

例2. 滑雪队里有80名学生，其中有32名女生，求女生在滑雪队里所占的百分比.

设$p$为女生在滑雪队里所占的百分比. 可用两种方法求出百分之一：80除以100，或者32除以$p$. 得出比例：$80:100=32:p$，或$\frac{80}{100}=\frac{32}{p}$.由此得$p=32\cdot100:80=40$. 就是女生占滑雪队全体成员的40%.
