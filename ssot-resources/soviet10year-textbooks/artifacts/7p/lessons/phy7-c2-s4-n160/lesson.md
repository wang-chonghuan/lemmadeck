# 160. 通电导体在磁场中所受的力　线圈的转动

我们都知道，两个通电导体之间总是以一定的力相互作用着（§ 131）. 对这个现象的解释是，每一个通电导体都受到另一个通电导体电流的磁场的作用.

概括说来，**磁场总是以一定的力作用在位于这个磁场内的一切通电导体上.** 不难通过实验表明这种力的存在. 实验的装置如图 345，*а* 所示.

![图 345](../../figures/fig-345.svg)

*图　345*

在这套装置中，导体 $AB$ 悬在两根与电源相接的柔软导线上，并且被置于蹄形磁铁的两个磁极之间，也就是放在磁铁的磁场中.

当将电路闭合时，导体就要产生运动（图 345，*б*）.

如果将磁铁拿开，那么通电导体并不运动. 这表明是磁场给了通电导体一定的力的作用，才使导体从它的初始位置偏离开.

实验表明，**当电流的方向改变时，导体的运动方向也改****变**，这说明作用在导体上的力的方向也改变了.

如果在实验中（图 345）不改变电流的方向，而是调换磁铁的两个磁极的位置，**也就是改变磁场的方向，那么作用在导****体上的力的方向也变为与原来相反.**

通电导体在磁场中的转动具有重大的实际意义.

图 346 上所示的仪器可以用来实现这种转动. 在这个仪器中，$ABCD$ 是一个装在竖直轴上的矩形轻框架. 框架上配有由几十匝包着绝缘层的导线组成的绕组. 绕组的线端接到金属环 1 上. 一个线端接到其中一个环上，另一个线端接到另一个环上. 这两个环也装在带绕组的框架的轴上. 就是借助于环和小金属片——电刷 2，把框架上的绕组接入电源电路中. 框架放在磁铁的两个磁极 $\mathrm{N}$ 和 $\mathrm{S}$ 之间，也就是被放在磁场中.

![图 346](../../figures/fig-346.svg)

*图 346*

在图 346 上，框架 $ABCD$ 的平面处于与磁铁磁场的磁力线平行的位置. 当电路闭合时，框架将使其绕组平面与磁力线相垂直. 框架的这一个位置叫做**平衡位置**（在图 346 上用虚线表示）.

当绕组中电流的方向改变时，框架就要旋转 $180^\circ$，甚至由于惯性的缘故，还会转得越过平衡位置一些. 为了使框架再一次旋转 $180^\circ$，应当在它由于惯性而已经通过平衡位置时来改变绕组中电流的方向. 这就是说，如果能在必要的时刻（框架每转过 $180^\circ$ 之后）改变绕组中电流的方向，那么只要绕组中保持有电流通过，框架就会在磁场中不停地转动.

有一种专门的装置叫做换向器，可以用来自动改变框架绕组中电流的方向.

最简单的换向器由两个彼此绝缘的半环组成. 它们和框架装在同一个轴上，因此总是和框架一起旋转. 框架绕组的两个线端就分别连在这两个半环上. 通过半环并借助于电刷将绕组接入电源电路. 装有这种换向器的框架如图 347所示.

当半环 $F$ 与电刷 2 接触时，框架绕组中电流的方向是自$D$ 指向 $C$ 的（如图 347 所示）. 框架在这种情况下旋转 $180^\circ$.转过 $180^\circ$ 以后，半环 $E$ 开始接触电刷 2. 现在绕组中的电流方向为从 $A$ 指向 $B$（图 348），也就是绕组中电流的方向变为与原来相反. 因此，框架做新的 $180^\circ$ 转动. 如此继续下去，框架就得以做持续的*转动*.
