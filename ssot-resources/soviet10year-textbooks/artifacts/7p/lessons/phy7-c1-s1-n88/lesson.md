# 88. 辐射

> 热现象 · 热传递和功

让我们通过实验来认识另一种形式的热传递. 拿一个一侧熏黑了的烧瓶（图222），穿过瓶塞将一根弯成直角的、内径较细的玻璃管插入瓶中，并往玻璃管中注入少许带颜色的液体. 这样，若给玻璃管附上刻度，我们就制成了一个**验温器**. 熏黑的烧瓶中的空气稍微受一点热，这个验温器就可以发觉.

![图 222](../../figures/fig-222.svg)

*图 222*

现在让我们把一块加热到高温的金属块放到验温器旁边约一米远的地方，则可以看到验温器中的小液柱将向右移动. 显然是烧瓶中的空气因受热而膨胀了. 验温器中的空气受热这一事实，只能用高温金属块把能量传递给了验温器，并且这部分能量转化为验温器的内能来解释. 在这种情况下能量的传递不会是通过热传导进行的，因为在高温金属块与验温器之间隔着导热性能很差的空气. 也不可能是通过对流进行的，因为验温器并没有放在高温金属块的上方，而是并排地放在它的一侧. 可见，能量从高温金属块传递到验温器是通过一种我们还不知道的新的热传递方式进行的. 这种传热的方式叫做**辐射**.

上述实验中烧瓶所获得的能量就是由高温物体通过辐射传递来的.

**一切高温物体都要用辐射的方式向其它物体传递能量.***用辐射的方式传递能量与其它的热传递的方式的区别在于，**辐射可以在真空中进行*. 太阳能就是通过辐射来传递的.

所有温度较高的物体，如人体、火炉、电灯泡等，不论其温度是很高还是稍高一些，都要向外辐射能量. 不过温度越高的物体用辐射的方式传递出去的能量就越多.

辐射到物体上的能量部分地被这些物体所吸收，转化成为它们的内能，从而使它们的温度升高. 不过在这种情况中，各物体被加热的程度是不同的，这与它们的表面状态有关.

在上述的验温器实验中，若开始时先把烧瓶熏黑的一面朝着高温金属块，然后再把未熏黑的一面转向高温金属块，则在前一种情况中玻璃管中的小液柱向右移动的距离将比后一种情况中移动的距离大. 这表明，具有黑色表面的物体能更多地吸收能量和提高温度. 同样地，表面黑色的物体，通过向外辐射能量而使本身温度降低的速度也比表面光亮的物体快. 例如，把热水盛在一把光亮的水壶中比盛在一把黑色的水壶中要凉得慢一些.

各种物体吸收辐射能的本领不同这一点可以为人们所利用. 例如，气球和机翼都涂成银白色，以避免它们被太阳晒热. 反过来，如果需要利用太阳能，比如要给装在人造地球卫星上的某些仪器的部件加热，就把这些部件涂成黑色.
