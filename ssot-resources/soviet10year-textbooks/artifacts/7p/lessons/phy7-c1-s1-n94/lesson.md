# 94. 燃料的能量 燃料的燃烧值

我们已经知道，分子是由原子组成的. 例如，水分子就是由一个氧原子和两个氢原子组成的. 分子也可以分解为原子. 分子的这种分解在化学上叫分解反应. 要把分子分解为原子，就必须克服组成分子的各原子间的吸引力而做功，也就是说需要消耗能量. 实验表明，在相反的过程中，即当原子结合成分子时则要有能量释放出来.

可以打一个比喻，地球和一切物体之间都存在相互吸引的力. 故当我们把一个物体举高，使它远离地球时，我们就要因做功而消耗能量. 不过反过来，假若一个物体（例如锻锤）落向地球时，它本身就要做功，它的能量就可以被利用.

**燃料**的利用就是以原子结合成分子时要释放出能量这一现象为根据的. 常用的燃料（煤、石油、汽油等）都含有碳. 燃烧时碳原子与空气中所含的氧原子相结合. 每一个碳原子结合两个氧原子（图226）. 这样形成的分子就是二氧化碳气的分子. 在形成的过程中就有能量释放出来.

燃料种类很多，有煤、泥炭、木柴、石油、油页岩、天然气等. 工程师们在对各种发动机做计算时，都必须准确地知道燃烧着的燃料能够释放出多少热量来. 为此，就需要通过实验测出，相同数量的各种不同的燃料在燃烧时能放出多少热量.

1千克某种燃料在充分燃烧时所能释放出来的热量，叫做这种**燃料的燃烧值**.

燃烧值用字母$q$表示，其量度单位为$\frac{\text{焦耳}}{\text{千克}}$，$\frac{\text{千卡}}{\text{千克}}$或$\frac{\text{卡}}{\text{克}}$.

燃料的燃烧值都是使用很复杂的仪器通过实验测定的.

**为了计算任意质量$m$的燃料在完全燃烧时所放出的热量****$Q$.需将被燃烧的燃料的质量乘以该种燃料的燃烧值：**$Q=qm$，式中$q$——燃料的燃烧值.
