# **144. 电功**

> **电功和电功率**

**怎样计算电流的功？**我们已经知道，一段电路两端的电压在数值上等于$1$库仑电量的电荷通过这段电路时所做的功。当通过这段电路的电量不是一库仑，而是几库仑时，所做的功也就增加到几倍。因此，**要求出电流在某段电路上所做的功，应将这段电路上的电压乘以通过这段电路的电量：**

功$=$电压$\times$电量.

把这个结论写成公式的形式则为

$A=Uq$,

式中$A$——功，$U$——电压，$q$——电量.

流经某段电路的电量可以通过测出电流强度及流经的时间而求出：

$q=It$.

应用这一关系，就可以得到在计算时用起来很方便的电功的表示式：

$A=UIt$.

**电流在某段电路上所做的功等于这段电路上的电压与电流强度以及做功时间之积.**

功以焦耳来量度，而电压以伏特、电流强度以安培、时间以秒来量度，所以可以写出：

**$1$焦耳$=1$伏特$\times1$安培$\times1$秒.**

如此说来，测量电功必须用三件仪器：伏特计、安培计和时计。但实践中测量电功用的是一种专门仪器——**电度表**.电度表的构造仿佛是综合了上述的三种仪器。现在，差不多在每一户住宅中都可以看到电度表.

**例题。**如某电动机电路中的电流强度为$5$安培，两接线柱间的电压为$220$伏特，试求电动机在$1$小时内所做的功.已知电动机的效率为$80\%$.
