# **103. 蒸发与凝结**

我们知道，液体的温度也是与分子的运动速度有关的，这一点和固体或气体的情况没有什么两样. 液体分子运动的平均速度越大，液体的温度就越高. 不过个别液体分子的运动速度可以大于平均速度，也可以小于平均速度. 如果某一运动得足够“快”的分子正位于液体的表面处，它就有可能克服邻近各分子的引力而飞出液体之外. 这样从液体表面层飞出来的分子就在液面的上方形成蒸汽. **这种分子由液体中迁移到蒸汽中去的现象叫做*蒸发***.

*蒸发*进行的速度与几方面的因素有关.

1. 若把一小块纸的一处浸些乙醚，另一处浸些水，我们可以看到，乙醚蒸发的速度比水快得多. 可见，**蒸发的速度与液体的种类有关.** 凡是分子间的相互吸引力比较小的液体，蒸发的速度就比较快. 这是因为在这些液体中能有更多的分子挣脱引力的作用飞出液面之外.

2. 由于液体中总是有一些分子运动得比较快，所以**蒸发在任何温度下都可以发生.** 观察证实了这一点. 例如雨后形成的水洼，无论是在夏季炎热的时候，还是在秋季已经很冷的时候都会变干. 只不过在夏季干得很快罢了. 这是因为液体的温度越高，其中运动速度快，从而有可能克服周围分子的引力飞出液面之外的分子数就越多. 因此，**液体的温度越高，它蒸发的速度就越快.**

3. 与分子由液体中向蒸汽中迁移的同时，相反的过程也在进行着. 由于液体上方分子的无规则运动，一部分由液体中脱离出来的分子就又重新返回液体中. 这种**分子由蒸汽中迁移到液体中去的现象叫做*凝结*.**

如果液体的蒸发是在密闭容器中进行的，那么用不了多少时间，由液体中飞出的分子数就会变得与由蒸汽中返回液体里的分子数相等. 因此，在密闭容器中的液体尽管仍在继续蒸发，但其数量却不再变化了（图 232）.

放在开口容器中的液体由于蒸发的缘故是在不断减少的. 这是因为大多数蒸汽分子散逸到空气中去了，不再返回液体. 只有一小部分重新返回到液体中，从而减慢了液体蒸发的速度. 所以**在有风的时候，**由于风把蒸汽分子带走了，**液体蒸发的速度就快.**

4. 若是把同样多的水分别倒入一个开口狭窄和一个开口宽阔的容器中，则可以发现，开口宽阔的容器中的水蒸发得快得多. 例如倒在盘子中的水就比倒在杯子中的水蒸发得快. 展开悬挂起来的床单就比揉成一团的床单晾干得快. 其道理在于液体是由表面蒸发的，所以液体的自由表面越大，在相同的时间内由液体中飞进空气里的分子数就越多. 可见，**液体蒸发的速度还与其表面积的大小有关.**

观察和实验都表明，固体也可以蒸发. 例如冰就可以蒸发. 所以床单在严冬季节也可以晾干. 用固体的蒸发现象就可以解释为什么能够闻到固体的气味.
