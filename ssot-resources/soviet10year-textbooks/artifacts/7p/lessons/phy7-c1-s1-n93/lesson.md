# 93. 物体温度升高时所吸收的热量或温度降低时所放出的热量的计算

我们已经知道了热量究竟与哪些量有关以及用什么做单位来量度热量.

为了计算热量必需知道组成物体的物质的比热，这个物体的质量以及这个物体在开始时的温度和终了时的温度之差.

例如，我们需要计算一个质量为5千克的铁质零件温度升高$600^\circ\mathrm{C}$时所吸收的热量.

铁的比热是$460\frac{\text{焦耳}}{\text{千克}\cdot{}^\circ\mathrm{C}}$，这表明，

要使1千克的铁温度升高$1^\circ\mathrm{C}$所需的热量为460焦耳；

要使5千克的铁温度升高$1^\circ\mathrm{C}$就需5倍的热量，即需460焦耳$\times5=2300$焦耳；

而要使5千克的铁温度升高$600^\circ\mathrm{C}$，则所需的热量又要增大到600倍，即需2300焦耳$\times600=1380000$焦耳的热量.

可见，**要计算使物体温度升高所需要的热量，只需将比****热乘以该物体的质量以及该物体在终了时和开始时的温度****之差.**

这一规律可以用公式表示. 引用符号：$Q$——热量，$c$——物质的比热，$m$——物体的质量，$t_1$——物体的初温度，$t_2$——物体的末温度，则有

$Q=cm(t_2-t_1)$.

**例题1.** 10千克质量的铁锅中装有20千克的水. 当把锅及其中的水的温度从$10^\circ\mathrm{C}$提高到$100^\circ\mathrm{C}$时，需传递给锅多少热量？

锅和水二者是同时被加热的. 在它们之间发生着热交换，所以可以认为它们的温度总是相同的. 于是，不论是锅还是水，温度都升高了相同的度数：$100^\circ\mathrm{C}-10^\circ\mathrm{C}=90^\circ\mathrm{C}$. 但是它们所得到的热量却并不相同，因为它们的质量和比热都是不相同的.

锅所得到的热量为$Q_1=c_1m_1(t_2-t_1)$，$Q_1=460\frac{\text{焦耳}}{\text{千克}\cdot{}^\circ\mathrm{C}}\times10\text{千克}\times90^\circ\mathrm{C}=414000\text{焦耳}\approx400\text{千焦耳}$.

水所得到的热量为$Q_2=c_2m_2(t_2-t_1)$，$Q_2=4200\frac{\text{焦耳}}{\text{千克}\cdot{}^\circ\mathrm{C}}\times20\text{千克}\times90^\circ\mathrm{C}=7560000\text{焦耳}\approx7600\text{千焦耳}$.

于是，对锅及水加热的结果，共传递给它们的热量为$Q=Q_1+Q_2$，$Q=400\text{千焦耳}+7600\text{千焦耳}=8000\text{千焦耳}$.

**例题2.** 把0.8千克温度为$25^\circ\mathrm{C}$的冷水与0.2千克的沸水混合在一起. 经测定，混合后的温度为$40^\circ\mathrm{C}$. 试计算沸水在温度降低的过程中放出了多少热量，以及冷水在温度升高的过程中得到了多少热量. 把这两个热量加以比较.

沸水的温度从$100^\circ\mathrm{C}$降低到$40^\circ\mathrm{C}$，在这个过程中它放出的热量为$Q_1=c_1m_1(t_2-t_1)$，$Q_1=4200\frac{\text{焦耳}}{\text{千克}\cdot{}^\circ\mathrm{C}}\times0.2\text{千克}\times(100-40)^\circ\mathrm{C}=50400\text{焦耳}$.

被注入沸水的冷水的温度从$25^\circ\mathrm{C}$升到$40^\circ\mathrm{C}$，所得到的热量为$Q_2=c_2m_2(t_2-t_1)$，$Q_2=4200\frac{\text{焦耳}}{\text{千克}\cdot{}^\circ\mathrm{C}}\times0.8\text{千克}\times(40-25)^\circ\mathrm{C}=50400\text{焦耳}$.

我们看到，**热水所放出的热量与冷水所吸收的热量是彼****此相等的**. 实验表明，**物体间若发生了热交换，则所有温度升****高了的物体增加的内能，等于所有温度降低了的物体减少的****内能**.

不过，若是在冷、热水混合的实验中，把测量进行得精确些，那么就会发现所放出的能量与所吸收的能量并不完全相等. 原因是在实验过程中，一部分能量传递给了容器及周围的空气. 在实验过程中产生的热量损失越少，则放出的热量与吸收的热量之间的差别就越小.
