# Author Source-First Solutions

## Source 1

本课内能是物体所有分子的热运动动能与分子间相互作用势能的总和；整体动能对应物体作为整体的运动，整体势能对应它与其他物体的相对位置，不能把这些宏观能量再计入本课的分子内能。若物体内部状态保持不变，只改变整体运动或相对位置，并不因此改变内能，虽然整体动能或势能可以改变。内能与机械能可以同时存在，例如教材中在地面上方飞行的飞机可以同时具有内能、整体动能和重力势能。这里的独立性有明确条件，并不是说机械能与内能永远不能通过做功发生转化；若过程改变了内部状态，就不能再套用内部状态不变的条件。整体移动快慢也不是分子相对于物体的热运动快慢。因而完整结论是：在题设内部状态不变时，内能不由整体运动和位置决定，而不是内能与机械能互相排斥或永远不能转化。

Method: 先按分子能量与整体运动、位置两种描述尺度区分能量，再应用内部状态不变的条件，最后检验共存和转化并不与条件独立性矛盾。

Conditions:
- 使用本课分子层面的内能定义。
- 内部状态不变是关于仅改变整体运动、位置时内能不变的必要题设条件。
- 不把整体速度加到分子热运动上，也不把做功导致的内部状态改变排除在物理可能性之外。

## Source 2

在本课给出的锻锤与氢气情境中，锻锤的机械能，即举高后所具有的重力势能，较容易直接利用。让锻锤落下并打到工件上，它便对工件做功；相比之下，要把氢气的分子能量用于做功并不像这一过程那样简单，还受具体条件和利用方式限制。结论不是氢气没有内能，也不是内能在任何情况下都不能用于做功；本课明确指出掌握利用内能做功的方式有重要技术意义。也不能从这个情境推出任何设备、任何条件下机械能都比内能容易利用。原书比较使用质量5吨的锻锤举高3米、重力势能近似140000焦耳，以及同样原书气体状态条件下1米^3氢气所有分子动能总和140000焦耳。这里按原书近似精度保留140000焦耳，不另算成147000焦耳来替换源数据。原书给出的室温氢气单分子代表性动能为0.000000000000000000005焦耳，即5/10^21焦耳；并非每个分子的动能完全相同。气体段没有列齐全部状态条件，其总量不能推广为任意压强、任意室温下同体积氢气的通用值，而且比较的分子动能总和不等于已经给出了内能各项的全部精确数值。能量数量相近本身不保证利用方式或难易程度相同，教材用落锤做功的具体途径解释这一差别。

Method: 保持教材数量级和近似约定，比较给定情境中能量用于做功的具体途径，而不是仅按能量数值排序或作普遍难易断言。

Conditions:
- 比较限于本课锻锤与氢气情境以及较容易直接利用这一措辞。
- 保持5吨、3米、1米^3、140000焦耳与代表性单分子动能的原书约定。
- 不补气体压强或其他缺失状态数据，不创造新计算题。
- 内能可以用于做功，易用程度依条件和方式而定。
