# Author Source-First Solutions

## Source 1

本课认为物体由分子组成，分子不停地运动。一个单独分子的运动是机械运动：它的位置随时间变化，因此可描述它沿怎样的轨迹运动、通过多少路程以及平均速度，并表现它与其他分子的碰撞。图207给出若干单个气体分子放大数百万倍的运动轨迹片段；折线轨迹提醒我们路径可多次改变，但图中没有时间或长度标度，不能只凭它算出具体平均速度或路程数值。对单分子能描述运动，并不等于全体分子的轨迹相同或运动整齐。也不能把某个轨迹片段的端点间直线距离当成该分子实际所走的曲折路程，把圆形标记直接计为所有分子数目，或把物体整体静止误认为其分子停止运动。

Method: 区分单个分子的运动描述与全体分子的总体运动；结合正文列出轨迹、路程、平均速度和碰撞，再明确示意图没有可计算数值的标度。

Conditions:
- 采用本课关于分子持续运动的模型。
- 图207只是高度放大的轨迹片段，不是完整全部分子轨迹或时间标定图。
- 不凭空给出分子速度、轨迹长度或碰撞次数。

## Source 2

分子总体运动复杂，是因为物体含有极多分子，而每个分子又沿复杂轨迹不停运动，并不是所有分子朝一个方向同步运动。它们向四面八方运动，相互碰撞；气体分子还与容器壁碰撞，碰撞使运动速度的方向和可能的大小改变，随后继续运动直到下一次碰撞。把极多条这样不断改变的运动轨迹同时描绘就很困难。原书用1厘米^3气体中大约25000000000000000000，即2.5×10^19个分子的近似数量说明分子数目之多；保留原书单位和数量级，不把近似估计变成所有气体任意状态下的精确常数，也不引入新测量条件或计算题。困难是大量粒子的总体描述，而不是单个分子没有机械运动或完全不可描述。图207只是几个轨迹片段，不能代替所有分子的总体图景。

Method: 将极大分子数目、各自复杂的持续运动和不断发生的分子间/器壁碰撞联系起来说明总体复杂性。

Conditions:
- 容器壁碰撞在正文的气体描述中使用，不推广为所有物态都必须碰撞器壁。
- 碰撞改变速度不等于每次碰撞都增加速率。
- 2.5×10^19及1厘米^3是原书近似说明，非精确普适密度。

## Source 3

本课把分子的无规则运动称为热运动，因为物体的温度与其分子的运动速度有关，物体的热现象能够用内部结构和这种运动来解释。这里关心的是分子的无规则运动和温度的联系，不是物体整体的平移快慢，也不是只有感觉很热或高温时分子才运动。物体整体静止时，分子仍可以不停地无规则运动。对许多分子讨论温度时，运动速度的联系是总体或平均意义，不表示每个分子都同向或同速；本课没有要求计算温度与单分子速度的数值公式。因而完整理由是分子无规则运动与热现象、温度相关，而不是机械运动和热运动相互排斥，或任何宏观物体运动都叫热运动。

Method: 先识别定义对象是分子的无规则运动，再用正文温度与分子运动速度的联系解释名称。

Conditions:
- 不把整体速度等同于分子无规则运动的平均快慢。
- 不要求同温度下所有分子速度相同，也不新增温度-速度定量公式。
- 无规则运动不只发生在高温、肉眼可见或人体感觉热的物体中。

## Source 4

可以举出：一昼夜中的气温变化，一年四季的气温变化，冰融化成水，水冻结成冰，金属熔化以及冷却凝固，水的蒸发，水蒸气凝结形成露。这些都是本课列举的热现象，包含温度变化以及熔化、凝固、蒸发、凝结等物态变化；只凭是否有肉眼可见整体移动或是否温度一定升高，不能概括这些例子。物态变化仍属于热现象，不必人为附加每个过程温度一定改变的条件。若只说小车整体位置变化或把石块举高，而没有描述温度/物态等热变化，该陈述本身只提供宏观机械运动或位置变化的例子，不能靠补入未给出的伴随摩擦、加热等过程把它变成本题热现象例子。举例题开放，以上为多个有效源内例子，不是宣称热现象只有这一有限清单；后续选例只能考查识别，不能声称已验证独立生成例子的能力。

Method: 从正文的温度变化和物态变化两类选出多个实例，保留例子之间的类别差异，同时避免补入描述之外的效应。

Conditions:
- 只判断明确描述的现象，不虚构温度、测量数据或伴随机械耗散。
- 不把热现象缩窄为升温，冻结、凝固、凝结也可入选。
- 不把源例子清单当成封闭的所有热现象集合。
