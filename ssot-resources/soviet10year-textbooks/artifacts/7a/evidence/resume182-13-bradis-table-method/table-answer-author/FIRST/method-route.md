## Lower-Main Plus Correction

本候选统一采用当前现代课文的“较小主表值 + 修正值”路线。
平方表归一化为 `1 <= a < 10`，平方结果再乘 `10^(2k)`；
平方根表归一化为 `1 <= a < 100`，被开方数的指数取偶数，根再乘 `10^k`。
每个修正整数按主表最后一位的单位解释：III 本次为 0.001 或 0.01，IV 为 0.001。
表格读数、对读数的有限小数运算及最后舍入是三个不同阶段，不互相冒充。

当前 n38 prose[12:14] 的示例是先取下方主值再加修正；prose[14] 明确把
8.4372 先舍入为 8.437。n39 prose[8:10]、prose[21] 也使用加修正，
prose[27] 明确平方根的偶数指数归一化。
一般插值规则 `I-linear-correction-and-route` 允许下方加法与上方减法，
并建议优先使用距离较近的一侧；这不意味着两条已舍入路线必定给出同一末位。

专用 III `III-high-fourth-digit` 对第四位 >5 指示下一主值减补数修正。

## Preprocessing And Precision

806.d 明确选择与本课系列一致的“四位有效数字被开方数 -> 查表”约定：
1.0058 -> 1.006；6.83251 -> 6.833；20.156 -> 20.16。
然后分别由 1.000+0.003、2.613+0.001、4.483+0.007 得到 1.003、2.614、4.490。
选择依据是 n38 的明确预处理示例、n39 的四位表分辨率和本次 AUTHOR 指令，
不是 Bradis 的普遍输入截断规则。一般说明 `I-second-excess-digit` 在印刷 88 页
给出第二个 excess 位修正方法；因此不能说所有 >4 位输入一律只能先舍入。
这里不采用扩展修正法，也不声称所得读数是原始被开方数直接准确舍入的值。

一般规则 `G3-G7-earlier-page-context` 是复用的前页文字观察，不是本次重新看图：
加减按最不精确项的小数位；乘除按最少有效数字；平方/根与近似输入的有效位相配；
中间保留一个备用位，最后丢掉。`G8-relative-preprocessing` 和 `G9-k-plus-one`
提供附加精度语境，但不替每道复合算式指定全部舍入阶段。
因此下列中间约定是明确的 AUTHOR 应用，不伪称 source 逐字给出的专题算法。
