# 32. 平方根的近似值

我们知道，对于任何一个有理数来说，数轴上总有一点和它对应. 但是反过来说不对：数轴上并不是每一个点都可以和一个有理数对应. 例如，抛物线$y=x^2$和直线$y=2$的交点的横坐标就是无理数.

每一个实数都和数轴上的一个点对应. 但是，对于实数来说，逆命题也是对的：数轴上每一个点都和某一个实数对应. 因此，可以将实数集映射到数轴上的点集，而且这个映射是可逆的.

![图 44](../../figures/fig-44.svg)

*图44*

在图44里，数轴上指出的点的坐标分别等于$-\sqrt{7}$，$\sqrt{5}$，$\frac{32}{7}$. 在实际应用时，一般都把实数表示成小数，准确到所要求的准确度. 例如，$\frac{32}{7}\approx4.571$（准确到0.001）.

下面我们来讨论求$\sqrt{5}$的小数近似值（准确到任意准确度）的方法.

5可以看作是$\sqrt{5}$的平方：

$5=(\sqrt{5})^2$.

因为

$2^2<5<3^2$，

即　$2^2<(\sqrt{5})^2<3^2$，

所以

$2<\sqrt{5}<3$.

（这里，我们利用了性质：如果$a$和$b$是正数，而且$a^2<b^2$，那么$a<b$.）

我们找到了两个连续的整数，而$\sqrt{5}$在这两个整数之间（图45，а）. 2是$\sqrt{5}$的不足近似值，而3是$\sqrt{5}$的过剩近似值.

将数轴上坐标为2和3的两点间的区间分成10等分，再从这些长度为0.1的区间中挑出包含坐标为$\sqrt{5}$的点的一个.

![图 45](../../figures/fig-45.svg)

*图45*

为此，我们依次将各分点的坐标2.0，2.1，2.2，…，2.9，3.0平方，直到得到大于5的数为止.

![表](../../figures/tbl-p0209-02.svg)

从上表可以看出，

$2.2^2<5<2.3^2$，

即　$2.2^2<(\sqrt{5})^2<2.3^2$.

因此，

$2.2<\sqrt{5}<2.3$.

我们找到了小数点后有一个数字的两个连续的小数，而$\sqrt{5}$在这两个小数之间（图45，б）. 2.2是$\sqrt{5}$的不足近似值，而2.3是$\sqrt{5}$的过剩近似值.

然后再把数轴上坐标为2.2和2.3的两点间的区间分成10等分，再用同样方法从这些长度为0.01的区间中挑出包含坐标为$\sqrt{5}$的点的一个.

从下表可以看出，$2.23^2\leq5<2.24^2$，即 $2.23^2<(\sqrt{5})^2<2.24^2$.

![表](../../figures/tbl-p0210-01.svg)

因此，$2.23<\sqrt{5}<2.24$.

这样一来，我们又找到了小数点后有两个数字的两个连续的小数，而 $\sqrt{5}$ 在这两个小数之间（图45，в）. $2.23$ 是 $\sqrt{5}$ 的不足近似值，而 $2.24$ 是 $\sqrt{5}$ 的过剩近似值.

同样可以找到一个长度为 $0.001$ 且包含坐标为 $\sqrt{5}$ 的点的区间：$2.236<\sqrt{5}<2.237$.

$2.236$ 和 $2.237$ 分别是 $\sqrt{5}$ 的不足和过剩近似值.

这种计算可以继续进行下去. 如果讨论到上面这个不等式为止，那么我们可以取左右两个数的算术平均数作为 $\sqrt{5}$ 的近似值，得：$\sqrt{5}=2.2365\pm0.0005$.
