# 39. 平方根表

在В. М. 伯拉基斯所编的《四位数学用表》里，列出了算术平方根的数值表. 它的编表方法和平方表的编表方法相似.

在平方根表里，给出了从1到100这个区间里各个数的平方根的近似值，并且从1到10每相隔0.001就列出一个数，而由10到100每相隔0.01列出一个数.

现在我们举例说明怎样查表求平方根的近似值.

1. 求$\sqrt{5.6}$的值.

在第一个直行里找出5.6. 在相邻直行里同一横行读出$\sqrt{5.6}$的近似值：$\sqrt{5.6}\approx2.366$.

2. 求$\sqrt{23.5}$的值.

在第一个直行里找出23并且在这同一横行和编号为5的直行的交叉点上读出结果：$\sqrt{23.5}\approx4.848$.

3. 求$\sqrt{45.34}$的值.

在第一个直行里找出45，然后在这一横行和编号为3的直行的交叉点上得出$\sqrt{45.3}$的近似值：$\sqrt{45.3}\approx6.731$.

在修正值表编号为4的直行里的同一横行找到3. 把修正值加到6.731的最后一个数字上，我们得到：$\sqrt{45.34}\approx6.734$.*

我们发现，表里引用的平方根的近似值所具有的绝对误差不超过平方根近似值的写法里最后一个数位半个单位.

例如，2.796是$\sqrt{7.82}$准确到0.001的一半的近似值，就是准确到0.0005. 也就是说，2.796的所有数字都是有效数字.

利用同一个表可以求出小于1或大于100的正数的平方根. 我们来看例子：

4. 求$\sqrt{245}$的值.

245比2.45大100倍，2.45的平方根可通过查表求出.因此，$\sqrt{245}=\sqrt{2.45\times10^2}$.

根据关于积的平方根的定理，得到：$\sqrt{2.45\times10^2}=\sqrt{2.45}\times10$.

* 通过计算修正值以保证在结果里所有四个数字都是有效数字.

查表求出$\sqrt{2.45}$的值：$\sqrt{2.45}\approx1.565$.

那么$\sqrt{245}=\sqrt{2.45}\times10\approx1.565\times10=15.65$.

5. 求$\sqrt{5634}$的值.

我们把5634写成$56.34\times10^2$，那么$\sqrt{56.34\times10^2}=\sqrt{56.34}\times10$.

查表求出$\sqrt{56.3}\approx7.503$. 在修正值表编号为4的直行里找到修正值3，把它加到7.503的最后一个数字上，得到：$\sqrt{56.34}\approx7.506$.

于是，$\sqrt{5634}=10\sqrt{56.34}\approx75.06$.

6. 求$\sqrt{0.235}$的值.

0.235比23.5小100倍. （23.5的平方根可通过查表求出. ）因此$\sqrt{0.235}=\sqrt{23.5\times10^{-2}}$.

因为$\sqrt{23.5\times10^{-2}}=\sqrt{23.5}\times10^{-1}$.

所以$\sqrt{0.235}=\sqrt{23.5}\times10^{-1}\approx4.848\times10^{-1}=0.4848$.

一般地，为了求出小于1或大于100的正数的平方根，应当把这个数写成$a\times10^{2k}$（$1\leq a<100$，$k$是整数），再利用关于积的平方根的定理求得结果.
