# 47. 可化为二次方程的方程

我们学会了解有一个变量的一次方程和二次方程。解有一个变量，高于二次的方程是比较复杂的问题。

在某些情况下，利用分解因式的方法，可以解这种方程。

例如，方程$x^3-9x=0$　　　　　　　　　(1)可以求解，把它的左边分解因式，得：$x(x+3)(x-3)=0$。方程(1)的解集合是$\{0,-3,3\}$。

有时还可以利用另外的方法求解，就是所谓的引进新变量的方法。

现在我们列举用这种方法解方程的例子。

例 1　解方程$(x^2-5x)^2-30(x^2-5x)-216=0$。　　　　　(2)我们发现方程(2)的一个重要特点：在它的左边，两次出现表示式$x^2-5x$(一次是平方，另一次是一次方)。这就有可能引进代换：$x^2-5x=y$。于是方程(2)化为关于新变量$y$的二次方程：$y^2-30y-216=0$。　　　　　　　　　(3)

解方程(3)，得出它和下列语句等价：$y=-6$或$y=36$。

由此得出方程(2)和下列命题相当：$x^2-5x=-6$或$x^2-5x=36$。

方程(2)的解集合是方程$x^2-5x=-6$和$x^2-5x=36$的解集合的并集。

其中第一个方程的根是$2$和$3$，而第二个方程的根是$-4$和$9$。于是，方程(2)的解集合是$\{2,3,-4,9\}$。

我们发现，如果不引进新的变量而把方程左边变形为标准形式的多项式，那么就得到方程$x^4-10x^3-5x^2+150x-216=0$。

如果没有专门的知识，要解这个方程是十分困难的。

例 2　解方程$4x^4-5x^2+1=0$。　　　　　　　　　(4)为了解这个方程，引进代换$x^2=y$。于是，方程(4)化为关于$y$的二次方程：$4y^2-5y+1=0$。解这个方程，得出它和下列语句等价：$y=\frac{1}{4}$　或　$y=1$。

就是说，方程(4)和下列语句等价：$x^2=\frac{1}{4}$　或　$x^2=1$。

于是，$\{-\frac{1}{2},\frac{1}{2}\}$是方程$x^2=\frac{1}{4}$的解集合，$\{-1,1\}$是方程$x^2=1$的解集合。

方程(4)的解集合是这两个集合的并集，就是$\{-\frac{1}{2},\frac{1}{2},-1,1\}$。

上面讨论的方程是四次方程，它们属于$ax^4+bx^2+c=0$ $(a\ne0)$这种形式的方程。这种形式的方程叫做双二次方程。
