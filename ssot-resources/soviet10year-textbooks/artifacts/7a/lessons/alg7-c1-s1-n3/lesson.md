# 3．分母不同的分式的和

> 第一章　有理分式 · §1．有理式的变形

现在提出的问题是：把分式 $\frac ab$ 与 $\frac cd$ 的和表示成一个分式．

应用分式的基本性质，我们可以把这个问题归结为前一小节所研究的同分母分式的加法问题．

为此，把前一个分式的分子与分母同乘以 $d$，而把后一个分式的分子与分母同乘以 $b$，得到：

$\frac ab+\frac cd=\frac{ad}{bd}+\frac{bc}{bd}$．

式 $d$ 叫做分式 $\frac ab$ 的分子与分母的附加因式，式 $b$ 是分式$\frac cd$ 的分子与分母的附加因式．我们已经把分式 $\frac ab$ 与 $\frac cd$ 变形成

同分母的分式 $\frac{ad}{bd}$ 与 $\frac{bc}{bd}$．这时就说，分式 $\frac ab$ 与 $\frac cd$ 已经通分．

现在可以把分式 $\frac ab$ 与 $\frac cd$ 的和表示成一个分式：

$\frac ab+\frac cd=\frac{ad}{bd}+\frac{bc}{bd}=\frac{ad+bc}{bd}$．
