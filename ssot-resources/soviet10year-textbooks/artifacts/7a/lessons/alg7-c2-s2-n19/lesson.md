# 19. 较复杂的不等式解法举例

我们现在来研究怎样解不等式 $(ax+b)(cx+d)>0$，$(ax+b)(cx+d)<0$，$\frac{ax+b}{cx+d}>0$，$\frac{ax+b}{cx+d}<0$；其中 $a$、$b$、$c$、$d$是四个数.

例1 解不等式 $(0.5x-1)(4-x)>0$.

两个因式的积的值为正，当且仅当这两个因式的值同号，即两个因式的值同时为正或同时为负. 这就是说，原不等式是真不等式，必须并且只须变量 $x$ 所取的值满足下列不等式组之一：$\left\{\begin{array}{l}0.5x-1>0,\\4-x>0\end{array}\right.$ 或 $\left\{\begin{array}{l}0.5x-1<0,\\4-x<0.\end{array}\right.$由此得到$\left\{\begin{array}{l}x>2,\\x<4\end{array}\right.$ 或 $\left\{\begin{array}{l}x<2,\\x>4.\end{array}\right.$前一个不等式组的解集合是数区间 $]2,4[$. 后一个不等式组的解集合是空集. 原不等式的解集合是：$]2,4[\cup\varnothing=]2,4[$.答：$]2,4[$.

例2 解不等式 $\frac{2x-3}{5-4x}<0$.

分式的值为负，当且仅当分子和分母的值有不同的符号.这就是说，原不等式是真不等式，必须并且只须变量 $x$ 所取的值满足下列不等式组之一：$\left\{\begin{array}{l}2x-3>0,\\5-4x<0\end{array}\right.$ 或 $\left\{\begin{array}{l}2x-3<0,\\5-4x>0.\end{array}\right.$

解其中的每个不等式组，求得前一个不等式组的解集合是数区间 $]1.5,+\infty[$，后一个不等式组的解集合是数区间$]-\infty,1.25[$. 原不等式的解集合是$]-\infty,1.25[\cup]1.5,+\infty[$.答：$]-\infty,1.25[\cup]1.5,+\infty[$.

例3 解不等式 $\frac{3x-2}{x-2}>3$.

这个不等式容易换成它的同解不等式，并使同解不等式的左边是含有变量的分式，而右边是零. 为此，我们把 $3$ 带上相反的符号移到原不等式的左边，并把所得到的差变形成分式：$\frac{3x-2}{x-2}-3>0$，$\frac{3x-2-3x+6}{x-2}>0$，$\frac{4}{x-2}>0$.

因为这个分式的分子是正数，而不等式 $\frac{4}{x-2}>0$ 以及原不等式与不等式：$x-2>0$同解. 由此得到$x>2$.原不等式的解集合是开的数射线 $]2,+\infty[$.答：$]2,+\infty[$.

例4 解不等式 $\frac{5x-4}{2-x}\geqslant0$.

分式的值非负（为正或者等于零），当且仅当分子非负，而分母为正，或者分子非正，而分母为负. 这就是说，原不等式是真不等式，必须并且只须 $x$ 所取的值满足下列不等式组之一： $\left\{\begin{array}{l}5x-4\geqslant0,\\2-x>0\end{array}\right.$ 或 $\left\{\begin{array}{l}5x-4\leqslant0,\\2-x<0.\end{array}\right.$

解其中每个不等式组，求得前一个不等式组的解集合是数区间 $[0.8,2[$，后一个不等式组的解集合是空集. 原不等式的解集合是 $[0.8,2[\cup\varnothing=[0.8,2[$答：$[0.8,2[$.
