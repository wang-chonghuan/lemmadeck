# 35. 函数 $y=\sqrt{x}$ 和它的图象

我们知道，当 $x>0$ 时根式 $\sqrt{x}$ 有意义，这时 $x$ 的每一非负值对应于根式 $\sqrt{x}$ 唯一的一个值. 因此，用公式 $y=\sqrt{x}$给出的函数的定义域是数射线 $[0,+\infty[$.

为了作这个函数的图象，我们先说明它的一些性质.

如果 $x=0$，那么 $y=0$，因此坐标原点属于函数的图象.当 $x>0$ 时，根式 $\sqrt{x}$ 的值是正的，因此图象在第一象限里.

在这个表里，列出了自变量 $x$ 的一些值以及相应的函数值.对于不是整数的平方的 $x$ 值，相应的函数值计算到小数点后面取两位.

较大的自变量值对应于较大的函数值. 一般地，可以证明，如果 $x_1$ 和 $x_2$ 是非负数，并且 $x_2>x_1$，那么 $\sqrt{x_2}>\sqrt{x_1}$，就是函数 $y=\sqrt{x}$ 在整个定义域里是增函数.

我们用反证法来证明这一事实.

设 $\sqrt{x_2}$ 不大于 $\sqrt{x_1}$，那么有 $\sqrt{x_2}<\sqrt{x_1}$ 或者 $\sqrt{x_2}=\sqrt{x_1}$. 如果$\sqrt{x_2}<\sqrt{x_1}$，因为 $\sqrt{x_2}$ 和 $\sqrt{x_1}$ 是非负数，那么有 $(\sqrt{x_2})^2<(\sqrt{x_1})^2$，即 $x_2<x_1$. 但是这和已知条件矛盾.

如果 $\sqrt{x_2}=\sqrt{x_1}$，那么 $(\sqrt{x_2})^2=(\sqrt{x_1})^2$，即 $x_2=x_1$. 这也和已知条件矛盾.

因此，上面的假设是不可能成立的，所以 $\sqrt{x_2}>\sqrt{x_1}$.

在坐标平面上按照表中所列坐标描点，然后用平滑的曲线连结各点，就得到函数 $y=\sqrt{x}$ 的图象（图54）.

![图54](../../figures/fig-54.svg)

*图 54*

我们要指出，函数 $y=\sqrt{x}$ 具有下列性质：任一直线 $y=a$ $(a>0)$ 和这个函数的图象都相交. 换句话说，任何正数都是这个函数的值. 例如，对于12这个数来说，当 $x=144$ 时，函数的值就等于 $12(12=\sqrt{144})$；对于200这个数来说，当$x=40000$ 时，函数的值就等于 $200(200=\sqrt{40000})$.

函数 $y=\sqrt{x}$ 的值域是数射线 $[0,\ +\infty[$.

因此，函数 $y=\sqrt{x}$ 是集合 $[0,\ +\infty[$ 到它自身上的映射.
