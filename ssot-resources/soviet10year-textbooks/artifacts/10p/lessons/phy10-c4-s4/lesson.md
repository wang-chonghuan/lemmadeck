# 实验作业

> 实验作业

一、利用单摆测定自由落体的加速度

**仪器和材料：**

有一小孔的小球，线，带铁夹和环的台架，秒表，软尺.

**实验步骤：**

1. 把台架安装在桌边上，用铁夹把环固定在台架上端，并用线把小球悬挂在台架上，小球距离地板应该是 $1$—$2$厘米.

2. 把小球向一方推 $5$—$8$ 厘米，然后松开，使摆振动.

3. 计算在时间 $t$ 为 $1$—$1.5$ 分钟内的全振动次数.

4. 用软尺测量摆的长度 $l$.

5. 根据公式计算自由落体的加速度.$g=\frac{4\pi^2 l n^2}{t^2}$

6. 估计误差.

二、研究光的反射定律

**仪器和材料：**

安在灯座上的小灯，蓄电池组，开关，小平面镜，带狭缝的屏，直角尺，量角器，白纸，导线.

**实验步骤：**

1. 通过开关连接灯和电池组组成电路.

2. 在灯的前面放置带狭缝的屏，在屏后面放置一张干净的白纸.

3. 闭合电路并在纸上获得光的明亮的细条纹(光线).

4. 把平面镜竖直放在光路上.

5. 在纸上用铅笔沿镜子画直线. 在小缝处标出光线的始点，在镜子处标出光线的终点. 同时标出反射线上的一个点.

6. 切断电流，取下镜子.

7. 作入射线和反射线，并在光线的入射点上作镜面线的垂直线.

8. 用量角器测量入射角和反射角.

9. 把镜子放在不同位置重复实验几次；得出反射角和入射角间关系的结论.

三、测定玻璃的折射率

**仪器和材料：**

带底座的小灯，蓄电池组，开关，两侧是平行平面的玻璃板，带狭缝的屏，三角板，量角器，白纸，导线.

**实验步骤：**

1. 通过开关连接灯和电池组组成电路.

2. 在灯的前面放置带狭缝的屏，在屏后放置一张白纸.

3. 闭合电路后在纸上获得光的明亮的细条纹(光线).

4. 把玻璃板横放在光路上.

5. 在纸上用铅笔沿着折射面画线，并标出入射线的始点$A$ 和终点 $B$，及光线由玻璃平板射出的点 $C$(图 $278$).

6. 切断电路，取下玻璃板.

7. 作入射线和折射线，并在入射点上作玻璃板的垂直线.

8. 用量角器测量出入射角 $\alpha$和折射角 $\beta$.

9. 根据公式计算折射率$n=\frac{\sin\alpha}{\sin\beta}$

10. 在由其他角度入射时重复实验并比较结果.

四、利用凹面镜获得图像

**仪器和材料：**

凹面镜，画有箭头的纸条.

**实验步骤：**

1. 把纸条紧靠在镜子上，渐渐地把纸条远离镜面，观察箭头虚象大小的变化.

2. 作出上述情况的成像图.

3. 把镜子移到一臂远的距离处，并使眼睛处于镜子的主光轴上.

4. 闭上一只眼，把纸条挂在镜子的主光轴上方，可以看到倒立的实像.

5. 沿着光轴挪动纸条，观察像的大小的变化.

6. 画出物体缩小的、放大的和相等的实像.

五、应用透镜获得实像

**仪器和材料：**

长焦距的会聚透镜，划有毫米格的玻璃，软尺，导杆，背面贴有字母的凹面镜，毛玻璃.

**实验步骤：**

1. 用透镜在毛玻璃上获得处于任意远距离处物体的实像.

2. 测量透镜与毛玻璃间的距离.

可以认为这个距离近似地等于透镜的焦距.

3. 把背面贴有字母的凹面镜安装在距透镜 $2$ 倍焦距处.

4. 在透镜的另一方，安放划有毫米格的玻璃. 沿着导杆安放所有的仪器.

5. 用视差的方法使字母的像与毫米格相合. 为此须使眼睛处于毫米格后的主光轴上，稍向左右上下移动眼睛，观察图像对于毫米格的移动. 在毫米格的某一个位置上，像对于毫米格不移动，这即是说，毫米格与图像准确地重合了.

6. 根据毫米格的刻度，测出字母图像的宽度和高度，同样地也测出字母本身的高度.

7. 利用软尺测出由图像到透镜的距离.

8. 求出物体的线度与相应的像的线度之比，然后求出由透镜到物体的距离与由透镜到像的距离之比. 比较这两个比值，并作出结论.

9. 把字母朝着透镜稍移近些，重复实验.

六、测量会聚透镜的焦距和焦度

**仪器和材料：**

带底座的小灯，蓄电池组，开关，软尺，长焦距的会聚透镜，带狭缝的白色屏，导杆，导线.

**实验步骤：**

1. 通过开关接通灯和电池组组成电路.

2. 把灯放在桌子的一边，屏放在另一边，透镜放在它们之间.

3. 接通灯并沿着导杆移动透镜，直至在屏上获得发亮的灯丝的清晰的像为止.

4. 测出灯至透镜的距离及透镜至屏的距离.

5. 用公式 $F=\frac{fd}{f+d}$ 计算透镜的主焦距和透镜的焦度$D=1/F$.

6. 把灯放在距透镜的任意距离 $d_1$ 上.

7. 已知焦距 $F$，根据公式 $f_1=\frac{d_1F}{d_1-F}$ 计算距离 $f_1$，像应该位于距离 $f_1$ 上.

8. 验证实验中所得到的结果.

9. 把灯放在距透镜 $d_2=2F$ 处，重复实验.

七、组装显微镜模型

**仪器和材料：**

长焦距的会聚透镜，短焦距的会聚透镜，画有毫米格的玻璃，导杆，背面贴有纸做的字母的凹面镜.

**实验步骤：**

1. 沿着导杆把短焦距的会聚透镜（*物镜*）安装在被照得很亮的字母附近，两者间的距离比该透镜的焦距要稍微大一些. 透镜的焦距应是事先已知的.

2. 利用有毫米格的玻璃，用视差的方法（见实验 $5$）找到字母的放大的倒立实像.

3. 沿着导杆，在像后边的某个距离上安装第二个透镜（*目镜*）. 让这个距离等于该透镜的焦距或比焦距稍微小一些（目镜的焦距也应事先已知）.

撤去毫米格玻璃，像用放大镜那样，用目镜来观察字母的放大的像.

八、利用棱镜观察光的色散现象

**仪器和材料：**

投影仪，带有氢、氖或氦的光谱管，高压电感器，蓄电池组，支架，导线（这些仪器对于所有年级来说都是通用的）；有斜边的玻璃板（发给每一个人）.

**实验步骤：**

1. 把玻璃板水平地放在眼睛的前面，透过 $45^\circ$ 角的边观察屏幕上的明亮竖条纹——投影仪所分开的狭缝的像.

2. 分辨所获得的连续光谱的各基本颜色，按观察到的顺序把它们记录下来.

3. 通过 $60^\circ$ 角的边观察条纹，重复实验，记下不同形式的光谱.

4. 透过玻璃板的两个边观察正在发光的光谱管，观察氢、氦或氖的线光谱，记下光谱中最亮的线.

九、观察光的干涉现象

**仪器和材料：**

玻璃板两块.

**实验步骤：**

1. 细心地擦净玻璃板，把两块玻璃板叠放在一起并用手指压紧.

2. 以黑色为背景，在反射光中观察玻璃板（它们的安装应使得在玻璃表面上不形成由于窗户或者白墙造成的鲜明的闪光）.

3. 观察在玻璃板个别接触的地方产生的鲜明的环状或不规则形状的七色条纹.

4. 注意由于用手指挤压的力的变化，所获得的干涉条纹的形状和位置的变化.

5. 试着在透射光中看到干涉图.

十、观察光的衍射现象

**仪器和材料：**

线状白炽灯（全班用一个），游标卡尺.

**实验步骤：**

1. 在游标卡尺的齿之间形成一个 $0.5$ 毫米宽的狭缝.

2. 让狭缝竖直地紧靠眼睛.

3. 穿过狭缝观看灯的竖直放置的发光的线. 在线的两侧有七色条纹（衍射光谱）.

4. 把狭缝的宽度由 $0.55$ 毫米加宽到 $0.8$ 毫米，观察对衍射光谱有何影响①.

① 如果没有游标卡尺，可以利用涂了黑色乳胶层的玻璃胶片，在它上面要事先刻好各种宽度的狭缝.
