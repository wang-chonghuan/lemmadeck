# 103. 光谱中能量的分布

任何一个光源都不会发出**单色光**，即波长严格确定的光.这一点可以用棱镜把光分解为光谱的实验，也可以用干涉和衍射的实验来证明.

光从光源中带出的能量以一定方式按波长分布. 同样也可以说，能量是按频率分布的，因为在波长和频率之间存在着简单的联系：$\lambda\nu=c$

任何一个光源都具有在单位时间内放射出充分的能量的特征. 辐射的能量在波长不同的光波中并不是平均分配的.所以辐射的最重要的特征是在单位时间内放射出的能量按波长和频率来分配.

这个分配可以用实验求出. 为此可以利用棱镜来获得光谱和测定处于宽度为$\Delta\nu$不大的光谱间隔上的光的能量. 在测定时用眼睛来判定能量的分布(即使是近似值)是不行的.眼睛对光具有选择性的灵敏度. 在光谱的**黄绿**光区域内，眼睛具有最大的灵敏度. 最好是利用这种现象：即极黑的物体几乎完全吸收各种波长的光，并且光的能量使物体变热；只要测出物体的温度，就可以根据温度来判断在单位时间内所吸收的能量.

普通的温度计灵敏度太小，不能有效地用于这样的实验.应当用灵敏度更高一些的仪器来测量温度. 可以用九年级物理课本中提到过的电阻辐射测温器. 电阻辐射测温器的金属片应当覆盖一薄层烟炱. 烟炱对任何波长的光几乎都能完全吸收.

电阻辐射测温器的热敏金属片应当放在用棱镜分解弧光灯的光获得的**光谱**的不同位置上(图229). 从$\nu_{\text{红}}$到$\nu_{\text{紫}}$的频率间隔对应于从红光到紫光长为$l$的整个可见光谱长$l$.黑色窄片的宽$\Delta l$则和小间隔$\Delta\nu$相对应. 根据仪器的黑窄片的加热情况来判断频率间隔$\Delta\nu$中的光能量. 把窄片沿光谱移动，我们就会发现，大部分能量都落在光谱的红光部分，而不是象用眼睛所判断的落到黄绿光部分.

根据这些实验的结果可以作出单位时间辐射出的能量和频率的关系曲线. 辐射的能量可以根据窄片的温度求出，而如果用来分解光的仪器有刻度的话，即若已知光谱的某段对应于哪一个频率，那么找出该段频率并不难. 把相应于间隔$\Delta\nu$的中部的频率数值标在横坐标轴上，把仪器窄片在单位时间内吸收的能量$\frac{\Delta E}{\Delta t}$标在纵坐标轴上，我们就可以得到一系列的点，通过这些点可以做出一条平滑的曲线 (图230). 这个曲线给出了电弧的光谱的可见光部分的能量分布. 也可以用类似的方法来研究其它光源的射线.
