# **104. 光谱仪**

为了精确地研究光谱，用那样简单的设备，诸如限制光束的窄缝，棱镜等，已是不够的了. 牛顿设计的用一个棱镜和一个透镜的改进了的装置(图197)，也同样不能完全满足要求.需要能够产生清晰的光谱的仪器，即能把不同波长的波清楚地分开，并且不让(或几乎不让)光谱的各个部分互相覆盖. 这种仪器的名称叫**光谱仪**. 光谱仪的基本部分经常是棱镜或是衍射光栅.

我们来研究棱镜光谱仪的装置. 它的结构简图如图231所示. 要分解的光先射到仪器的叫做准直管的部分. **准直管**是一个管子，其一端是一个有狭缝的屏，另一端有一会聚透镜$L_1$. 狭缝位于透镜的焦平面上. 所以从狭缝入射到透镜的发散光束，从透镜中射出时就以平行光束入射到棱镜$P$.

*图 231*

因为不同频率的光具有不同的折射率，所以从棱镜中出来的平行光束方向上不再重合. 它们射到透镜$L_2$上，在这个透镜的焦平面上放一个屏(毛玻璃或是感光板)；透镜$L_2$把光的平行光束聚焦于屏上，那么屏上出现的将不是缝的一个像，而是一系列的像. 每一个频率(更准确地说，是很窄的光谱的间隔)具有自己相应的像. 所有这些像在一起构成光谱.

上述仪器称为**摄谱仪**. 如果为了可以用肉眼观察到光谱，用目视望远镜代替第二个透镜和屏，那么这个仪器就称为**分光镜**. 棱镜和光谱仪的其它部件不一定非得用玻璃做，也可以用其他透明物质如石英、岩盐等代替玻璃，问题是对于可见光透明的玻璃，能强烈地吸收其它波长的电磁波.
