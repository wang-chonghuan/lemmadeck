# 52. 电磁相互作用如何传递

自然界的基本定律其中包括麦克斯韦发现的电磁各定律，在以下方面是非常有价值的：这些定律包含的内容比它们由之得出的事实要丰富得多。假如每一条定律所包含的内容仅仅是它由之导出的事实，那么自然界有多少现象，就得有多少定律。我们就只会有在自然界观察到的无边无际的一大堆过程，而不会有现代科学，要想预测什么也是完全不可能的。

在根据麦克斯韦电磁场定律得出的无数非常有趣和重要的结论中，有一点是值得特别注意的。这个结论就是：**电磁相****互作用是以有限速度传播的**。

根据超距作用的理论，当相邻电荷从某一位置移动时，作用于电荷上的库仑力就会立刻变化。作用的传递是瞬时的，从相隔着一定的距离的作用观点来看，不可能存在别的情况。要知道，这是一个电荷越过真空直接地“感觉到”另一个电荷的存在。

根据麦克斯韦定律，事情就完全是另一种情况，并且要复杂得多。电荷的移动，改变了它附近的电场。变化的电场在相邻的空间区域产生变化的磁场。变化的磁场反过来又产生变化电场。如此类推。

图103就是这个过程的示意图。具有磁力线$B$的交变磁场产生具有电力线$E$的涡旋电场。这个电场又产生具有磁力线$B_1$的磁场，依此类推。

实际上是新产生的涡旋磁场或电场在该空间中抵消了原有的场，但是占据了空间中的新区域。磁场的磁感应矢量$\vec{B}$和$\vec{B}_1$在空间的同一区域中方向相反，矢量$\vec{E}$和$\vec{E}_1$的情况也是如此。

上述过程都是按第50节讲过的那些确定场的方向的规律进行的。如果交变磁场和交变电场产生的涡旋场$E$和$B$的方向，由同一规则来确定的话，那么就会违反能量守恒定律。此时，在空间一定的区域里产生的磁场就会随时间而增长，同时向所有的方向传播。

电荷的位移就这样引起电磁场的“扰动”，这个扰动的传播占据了周围越来越大的空间，沿途改变着该电荷移动前存在的场。最终这个“扰动”到达第二个电荷，引起作用于第二个电荷的力的改变。但这并不是发生在第一个电荷移动时的那个时刻。麦克斯韦发现了电磁干扰的传播过程的力学原理。这个过程是以虽然很大但仍是有限的速度传播的。

麦克斯韦用纯数学方法证明了这个过程的传播速度等于光在真空中的速度，这就是电磁场新的基本特性，这个特性使场变为可以察觉的现实。
