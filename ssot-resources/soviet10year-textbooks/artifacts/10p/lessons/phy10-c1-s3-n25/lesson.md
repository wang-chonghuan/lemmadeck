# 25. 交流电路中的电感

电路中的电感影响交流电的电流强度. 这可以用一个简单的实验来证明. 我们用电感很大的线圈和白炽灯组成一个电路（图 40）. 利用双刀双掷开关可以把这电路接到直流电源上或交流电源上. 实验时应使直流电压和交流电压的有效值相等. 实验表明，在直流电压下灯泡发光比较亮些. 因此在我们研究的电路中，交流电的电流强度的有效值小于直流电的电流强度.

这一点可以用自感现象来说明. 在九年级时你们已经知道，把线圈接入直流电源时，电路中的电流强度是逐渐增大的.在电流强度增大时，产生的涡旋电场阻碍电子运动，只是在经过一段时间后，电流强度才达到最大值. 如果电压很快地变化，那么电流强度就来不及达到与这个电压瞬时值对应的电流值，因此交流电的电流强度的最大值（它的振幅）受电路中的电感 $L$ 的限制. 并且电感越大，振幅越小.

我们来求接有纯电阻可以忽略不计的线圈的电路中的电流强度（图 41）. 为此，我们先求出电路里的自感电动势与线圈上的电压之间的关系.

如果线圈的电阻等于零，那么在任何时刻，导线内部电场的电场强度也应当等于零. 否则，根据欧姆定律，电流强度就会无限大. 电场强度等于零之所以可能，是因为交变磁场激发的涡旋电场的电场强度 $\vec{E}_i$ 在每一点上都和库仑场的电场强度 $\vec{E}_k$ 的绝对值相等，而方向相反，这个库仑场是由分布在电源接线柱和电路导线上的电荷在导体中形成的.

从等式 $\vec{E}_i=-\vec{E}_k$ 中可得出，**移动单位正电荷涡旋场做的****功（也就是自感电动势 $e_i$）与库仑场做的功大小相等而方向相****反.** 考虑到库仑场做的功等于线圈两端的电压，可以写出：$e_i=-u$

当电流强度按照简谐规律变化时，$i=I_м\cos\omega t$

自感电动势等于$e_i=-Li'=L\omega I_м\sin\omega t$ （2.29）

因为 $u=-e_i$，则线圈两端的电压可以这样求出：$u=-L\omega I_м\sin\omega t=L\omega I_м\cos\left(\omega t+\frac{\pi}{2}\right)$ $=U_м\cos\left(\omega t+\frac{\pi}{2}\right)$ （2.30）

其中 $U_м=L\omega I_м$ 是电压振幅的大小.

因此，**线圈上电压的振荡比电流强度振荡超前** $\frac{\pi}{2}$. 或者也可以这样说，**电流强度振荡比电压振荡滞后** $\frac{\pi}{2}$.

当线圈上的电压达到最大值时，电流强度等于零（图 42）.

当电压变为零时，电流强度的绝对值达到最大值.

在线圈里电流强度的振幅等于$I_м=\frac{U_м}{\omega L}$ （2.31）

如果引入符号$\omega L=X_L$ （2.32）用有效值代替电流强度和电压的振幅，则可得$I=\frac{U}{X_L}$ （2.33）

**■ $X_L$ 即角频率和自感系数的乘积叫做感抗.**

根据公式（2.33），电流强度的有效值与电压的有效值和感抗间的关系与直流电路中的欧姆定律类似.

**感抗与频率有关**. 稳恒电流一般“不能察觉”线圈的电感.在 $\omega=0$ 时，**感抗 $X_L=0$**. 电压变化越快，自感电动势就越大，**电流的振幅就越小**.
