# 124.　玻尔理论的困难　量子力学

玻尔理论的最大成绩在于对氢原子的运用，使建立氢原子光谱的定量理论成为可能。

但是在玻尔概念的基础上企图建立氦后面的氢原子的定量理论没有成功。对于氦原子和更复杂一些的原子，玻尔理论只能作一些定性的（虽然是极重要的）结论。

这并不奇怪。玻尔理论是不彻底的，有内在的矛盾。一方面，如我们所看到的，在建立氢原子理论时用的是牛顿力学的一般原理及众所周知的库仑定律；另一方面，引用了与牛顿力学和麦克斯韦电动力学没有丝毫联系的量子假设。量子概念引入物理学中，要求根本地改造力学和电动力学。这个改造在本世纪二十年代末实现了，当时建立了新的物理学理论：量子力学和量子电动力学。

玻尔的假设终于被证实是完全正确的。但是它们已经不作为假设出现，而是作为这些理论的基本原则的结果而出现；玻尔的量子化规则是近似的结果，远非总是能应用的。

关于玻尔所说的在原子中电子在确定的轨道上运动的概念是十分有条件的。事实上原子中电子的运动与行星沿轨道的运动极少有共同点。如果处于最低能级的氢原子能有较长的曝光时间拍摄下来，则我们可以看到的将是在离核一定距离上具有最大密度的云状物。可以把这个距离看作是轨道半径的粗略近似。这个距离恰好与玻尔半径一致（11.8）。原子的照片完全不像太阳系常见的画面，而是比较象给一只对着灯乱撞的蝴蝶照相时照下来的轮廓模糊的斑点①。现在利用量子力学可以回答涉及到原子的电子云的属性和结构的任何问题，但是定量的理论是极其复杂的，所以我们不打算涉及它，在《无机化学》课程中有关于原子的电子云的性质的描写。

①　这里应当注意到，在比较长的时间的曝光下才能得到画面的平均相似物。电子的运动无论如何不能和蝴蝶的飞舞等同，如同与任何其它宏观物体的运动不能等同一样。
