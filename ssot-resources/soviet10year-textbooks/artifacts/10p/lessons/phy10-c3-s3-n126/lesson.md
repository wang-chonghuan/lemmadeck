# 126.　原子核与基本粒子

> 第十二章　原子核物理

我们已经不止一次地提到过原子核和基本粒子。 整个原子物理学就是以研究各种原子核和电子的相互作用为课题的。

一开始并没有区分成**核物理学**和**基本粒子物理学。** 在研究核过程时，物理学遇到了基本粒子的五花八门的世界。 把基本粒子物理学划分成一个独立的研究领域还是不太久以前的事，大约是在 1950 年。 现在我们有两个独立的物理学部分，其中一个研究原子核的结构和变化，另一个研究基本粒子的本质、特性和相互转变。 但是在所研究的问题和所采用的研究方法方面，它们都有许多共同点。

大部分时间我们将用于研究核物理学的基本问题，只是在最后我们才简要地讲述基本粒子的性质。 但是首先介绍用以使原子核和基本粒子物理学的产生和发展成为可能的那些设备。 这些设备是用来记录和研究原子核与基本粒子的碰撞和相互转化的。 正是这些设备提供了微观世界事件的必要情报。
