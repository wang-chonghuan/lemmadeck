# **82. 光的折射定律的推导**

光线的概念是几何光学的基本概念. 确定光线的方向的各定律，即光在均匀媒质中直线传播的定律、反射定律和折射定律是用实验的方法发现的.

光的反射和折射定律理论上也首先是利用惠更斯的光的波动说导出的. 惠更斯把光看作是在一种假想的充满了整个宇宙空间的媒质——以太中传播的弹性波.

惠更斯原理在以机械波为题的第四章中已经讲过了，它正是对于光波最初的阐述.

这个原理，象波运动的其它各定律一样，对于任何波都是正确的，而与波的性质无关.

在第 $47$ 节中导出了机械波的反射定律，但是因为所有的论断都能丝毫不差地正确地用于光波，所以可以认为光的反射定律在理论上是被证明了的.

现在我们来研究光从一种媒质进入另一种媒质时的折射. 设光的平面波入射到两种媒质（如空气和水）的界面上（图 195）. 波面 $AC$ 垂直于光射线 $A_1A$ 和 $B_1B$. 在第二种媒质里做中心在两种媒质的交界面上的所有次波的切面，就可以得到折射波的波面. 光线$A_1A$ 首先到达表面 $MN$. 如果在第一种媒质中的光速等于 $v_1$，那么光线 $B_1B$ 到达面 $MN$ 经过的时间为$\Delta t=\frac{|CB|}{v_1}$

所以，当次波在 $B$ 点刚刚开始激发的时刻，由点 $A$ 发出的波已经是一个球面，其半径为$|AD|=v_2\cdot\Delta t$

其中 $v_2$ 是光在第二种媒质中的速度.

如果从点 $B$ 作与中心在点 $A$ 的球面相切的直线，我们就得到折射波的波面 $DB$. 显然光线的入射角 $\alpha$ 等于 $\triangle ABC$ 中的 $\angle CAB$（两个角的两边互相垂直）. 所以$|CB|=v_1\cdot\Delta t=|AB|\sin\alpha$ （7.1）

折射角 $\beta$ 等于 $\triangle ABD$ 中的 $\angle ABD$. 所以$|AD|=v_2\cdot\Delta t=|AB|\sin\beta$ （7.2）

用（7.2）除（7.1），我们得到折射定律$\frac{\sin\alpha}{\sin\beta}=\frac{v_1}{v_2}=n$ （7.3）

其中 $n$ 是与入射角无关的常量，如大家知道的，它叫做**相对折****射率**. 用这种方法，根据惠更斯原理不仅能得出折射定律，而且利用它也揭示出相对折射率的物理意义：折射率就是光在其界面上发生折射的两种媒质中光速之比.$n=\frac{v_1}{v_2}$ （7.4）

此外，如果折射角 $\beta$ 小于入射角 $\alpha$，则根据（7.3）在第二种媒质中光速就小于第一种媒质中的光速. 在水和其它透明媒质中测量光速的实验精确地证实了这一点.

利用公式（7.4）用第一种和第二种媒质的**绝对折射率** $n_1$和 $n_2$ 可以表示出相对折射率 $n$. 事实上，因为$n_1=\frac{c}{v_1}$ 和 $n_2=\frac{c}{v_2}$，

所以$n=\frac{v_1}{v_2}=\frac{n_2}{n_1}$ （7.5）
