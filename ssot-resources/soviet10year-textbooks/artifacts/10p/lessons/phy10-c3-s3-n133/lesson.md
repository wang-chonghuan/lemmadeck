# 133. 位移定则

只是在发现了同位素以后才成功地分析了元素的一连串放射性变化. 这些变化遵循所谓的**位移规则**，此规则是由索基首先表述的：**当发生$\alpha$衰变时原子核失去正电荷$2e$，它的****质量减少了将近$4$个相对原子量单位. 结果，元素在周期表中****就向前移两个格子.** 这一点可以象征性地写出如下：${}^M_Z\mathrm{X}\longrightarrow{}^{M-4}_{Z-2}\mathrm{Y}+{}^4_2\mathrm{He}$

在这里就像在化学里那样，元素用普通采用的符号表示，核电荷用指数形式写在符号的左下方，原子量以指数形式写在符号左上方. 例如氢的一般同位素用符号${}^1_1\mathrm{H}$表示，氘用${}^2_1\mathrm{H}$表示. 作为氦原子核的$\alpha$粒子可以写成${}^4_2\mathrm{He}$，等等.

在$\beta$衰变时从核中飞出一个电子. 结果核电荷增加了$1$，而质量几乎保持不变.${}^M_Z\mathrm{X}\longrightarrow{}^M_{Z+1}\mathrm{Y}+{}^0_{-1}e$

这里${}^0_{-1}e$指的是电子，其上的指数“$0$”表示它的质量与相对原子量的单位相比是极小的. **在$\beta$衰变后，元素向周期表后方****移一个格子.** $\gamma$射线并不伴随电荷的变化，核的质量变化也微乎其微.

**位移规则表明**，在放射性衰变时总电荷保持不变，并且核的相对原子量也近似保持不变.

放射性衰变时产生的新核通常同样也具有放射性.
