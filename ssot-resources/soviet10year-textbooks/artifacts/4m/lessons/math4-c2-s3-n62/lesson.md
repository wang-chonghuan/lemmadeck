# 62. 小数乘法的特殊情况

常常需要用10，100，1000等数去乘小数。用这些数乘小数的方法归结为把小数点的位置向右移。

现在做小数4.576乘以10，首先用10乘4576，得到$45\,760$。然后在自右向左三位处点上小数点，向左移三位这正是乘数4.576的小数的位数。

我们得到：$4.576\cdot10=45.760=45.76$。

现在比较一下乘数4.576和积45.76。如果把乘数的小数点向右移一位，就可以从乘数得到积。

这个数要乘以100，我们可以在4576后面添两个0，然后把小数点点在三位处。

得到：$4.576\cdot100=457.600=457.6$

如果把乘数的小数点向右移一位就可以从乘数4.576得到积457.6。因此，任何数乘以10，100，1000等等数都是很容易的。

小数乘以10，100，1000等数时，只要把这个小数的小数点位置向右移1位、2位、3位等即可。

例1. 0.124124乘以10000。10000这个数中含4个0，所以可把0.124124的小数点向右移四位。得到：$0.124124\cdot10000=1241.24$。

例2. 3.7乘以100。应当把3.7这个数的小数点向右移二位。但它在小数点后面只有一个数字。所以需要在这个数的右面添一个0：$3.7=3.70$。得到$3.7\cdot100=3.70\cdot100=370$。

当小数乘以0.1，0.01，0.001等数时，应当把小数点的位置向左移动1位、2位、3位等等.

例3. 26.4乘以0.1：$26.4\cdot0.1=2.64$.

例4. 3.7乘以0.01：$3.7\cdot0.01=003.7\cdot0.01=0.037$.
