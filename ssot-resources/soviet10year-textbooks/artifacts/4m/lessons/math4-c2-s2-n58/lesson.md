# 58. 小数的加法

> §9. 加法和减法

问题1. 做一件大衣用料子3.14米，做一套西服用料子2.83米。做大衣和西服共用了多少米料子？

为了解这个题，需要把3.14和2.83加起来：

$3.14+2.83=3\frac{14}{100}+2\frac{83}{100}=5\frac{97}{100}=5.97$。

这个题也可以用另一种方法来解：把长度用米和厘米表示：

$3.14$米$+2.83$米$=3$米$14$厘米$+2$米$83$厘米$=5$米$97$厘米$=5.97$米。

问题2. 一南瓜重6.4公斤，另一南瓜重5.28公斤。这两个南瓜共重多少？

由于$6.4=6.40$，而$6.40+5.28=11.68$，所以两个南瓜共重11.68公斤。

小数加法也和自然数加法一样，可以方便地写成“竖式”：

$\phantom{+}3.14\qquad\phantom{+}6.40$ $\underline{+\ 2.83}\qquad\underline{+\ 5.28}$ $\phantom{+}5.97\qquad11.68$

两个小数相加，需要：1）使各加数的小数点后的位数相等；2）各加数小数点对齐；3）和自然数的加法一样作加法；4）相加以后，在和的对着加数小数点的位置上点上小数点。
