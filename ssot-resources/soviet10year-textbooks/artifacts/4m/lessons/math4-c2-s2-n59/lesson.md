# 59. 小数的减法

问题. 钳工学徒每月工资71.35卢布。定级以后每月工资114.8卢布。他的月工资增加了多少？

为了解这个题，需要从114.8中减去71.35：

$114.8-71.35=114.80-71.35=114\frac{80}{100}-71\frac{35}{100}=43\frac{45}{100}=43.45$。

每个月的工资增加了43.45卢布。小数的减法也可以方便地写成“竖式”：

$\phantom{-}114.80$ $\underline{-\ \phantom{1}71.35}$ $\phantom{-1}43.45$

一小数减去另一小数，需要：1）使被减数和减数的小数点后面位数相等；2）把减数写在被减数下面并使它们的小数点对齐；3）和自然数的减法一样做减法；4）相减以后，在差的对着被减数和减数小数点的位置上点上小数点。
