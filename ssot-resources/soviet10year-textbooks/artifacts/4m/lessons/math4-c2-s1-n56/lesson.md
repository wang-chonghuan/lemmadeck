# 56. 角的度量

我们把一直角分成90等份，就得到90个合同的角（图215）。每一个小角等于直角的$\frac{1}{90}$。一个直角的九十分之一叫做一度，并把它作为度量角的单位。

![图 215](../../figures/fig-215.svg)

一个直角的$\frac{1}{90}$叫做一度。

*图215*

如果角$MOP$包含40度，那么就说角$MOP$的大小等于40度，写作：$\widehat{MOP}=40^{\circ}$。

“$^{\circ}$”是角的度量单位——度的符号。应当分清楚$\angle MOP$和$\widehat{MOP}$这两种写法。第一种写法读作“角$MOP$”，而第二种写法读作“角$MOP$的大小”。

直角的大小等于$90^{\circ}$，而平角的大小等于$180^{\circ}$。任何锐角都小于$90^{\circ}$，而任何钝角都大于$90^{\circ}$小于$180^{\circ}$。如果角$ABC$是锐角，而角$KED$是钝角，那么下列不等式就是真的：$\widehat{ABC}<90^{\circ}$，$90^{\circ}<\widehat{KED}<180^{\circ}$。
