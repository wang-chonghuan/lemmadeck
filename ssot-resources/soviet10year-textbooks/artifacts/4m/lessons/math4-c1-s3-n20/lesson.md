# 20. 不等式

> 第一章　自然数和分数 · §3. 方程和不等式

问题。在天秤左面的盘子里（图82）有$n$包各3公斤的物品，在右面的盘子里是共重18公斤的法码。如果右面盘子里的质量超过左面，那么左面盘子里可以有几包物品？

![图 82](../../figures/fig-82.svg)

*图82*

左面盘子里的货物共重$3\cdot n$公斤。它小于18公斤，因为右面盘子的质量超过左面：$3\cdot n<18$

如果用5代替不等式$3\cdot n<18$中的变量，就得到真的不等式$3\cdot5<18$。数5叫做不等式$3\cdot n<18$的解。它是问题的答案中的一个。“解”在这里表示数，而不是为获得答案所要完成的运算。如果用10代替$n$，就会得到假不等式$3\cdot10<18$。10不是不等式$3\cdot n<18$的解。也就是说左面盘子里可以是5包物品，而不能是10包。

使不等式为真的变量的值叫做不等式的解。

例如，$\frac13$是不等式$x<1$的一个解，因为不等式$\frac13<1$是真的。

解不等式就是求它的解的集合。

不等式$3\cdot n<18$的自然数解的集合由1，2，3，4和5组成。
