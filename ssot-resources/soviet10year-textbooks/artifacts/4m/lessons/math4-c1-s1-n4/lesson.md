# 4. 刻度

> 第一章　自然数和分数 · §1. 数和集合

图10的尺上有刻线，它把尺分成许多部分，或分度。每一分度的长等于1厘米。尺上的全部分度组成刻度。用这种刻度可以量出线段的长。线段$AB$的长为6厘米。

![图 10](../../figures/fig-10.svg)

*图 10*

有各种各样的尺度。图11所示的是其中的一种。这是一种室内温度计。它的刻度由55个分度组成。每一个分度表示摄氏1度。这个温度计上表示的是$21^\circ\mathrm{C}$。

![图 11](../../figures/fig-11.svg)

在刻度上注上数字使用起来就更方便。在尺上，每一条刻线的旁边都写上了数字（参看图10），而在温度计上是每10个分度，即在长刻线旁边注上了数字（参看图11）。
