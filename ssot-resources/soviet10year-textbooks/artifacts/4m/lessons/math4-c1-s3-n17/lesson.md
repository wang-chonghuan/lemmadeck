# 17. 数式

> 第一章　自然数和分数 · §3. 方程和不等式

解应用题时，有时只要列出运算式，然后再计算。得到的运算式叫做数式。

问题。为了整修院子，先拉来了5车砂子，后来又拉了7车。每车装3吨。一共拉了多少吨砂子？

第一次拉了$3\cdot5$吨砂子，第二次拉了$3\cdot7$吨砂子。一共拉了$3\cdot5+3\cdot7$吨砂子。

为了解这个题，我们列出了数式$3\cdot5+3\cdot7$。完成其中的运算就得到36，36叫做这个数式的值。数式的值给出了问题的答案：一共拉了36吨砂子。

两个数式可能有相同的值。例如：$3\cdot5=15$和$3\cdot2+9=15$。

在这种情况下，写成：$3\cdot5=3\cdot2+9$。

两个数式也可能有不同的值。例如：$70:2=35$和$8\cdot9=72$。

因为$35<72$，所以写成：$70:2$ $<8\cdot9$或$8\cdot9>70:2$。

为了算出数式的值，要用大家知道的运算顺序法则。例如，在数式$14+696:(86-28)$中，先减，后除，最后加。得到的结果是26。计算顺序可以从图72中清楚地看出。
