## 168

Task: decide whether each masked pair has a fixed comparison and determine it
without assuming that separate stars stand for equal digits.

- a) 72*** is between 72000 and 72999; 75*** is between 75000 and
  75999. Since 72999 < 75000, every permitted completion satisfies
  72*** < 75***. The first unequal known place is the thousands place.
- b) In ordinary positional notation *3*** has five places and *8* has
  three. More strongly, even allowing a zero in a leading masked position,
  *3*** >= 3000 and *8* <= 989. Thus *3*** > *8* for every
  completion. The known 3 alone contributes 3000, not 3.

about leading zeros, nor any assumption linking the erased digits.

## 169

Task: find every integer with last digit 5 strictly between 210 and 220.
Write the integer as 10t + 5. The endpoints give 205 < 10t < 215, so
20.5 < t < 21.5. The unique integer t is 21; the number is 215.
It satisfies 210 < 215 < 220 and its last digit is 5.

## 170

Task: find every three-digit integer ending in 1 and strictly greater than 981.
Three-digit numbers ending in 1 near the upper limit are 971, 981, 991.
981 is excluded by strictness; 1001 is not three-digit. Equivalently,
n = 10t + 1, 981 < n <= 999 implies 98 < t <= 99.8, hence t = 99.
The unique result is 991.

## 173

Task: compare the number of fish in A with the number of crucian carp in B.
Every crucian carp in the lake is a fish in that lake, so B is a subset of A.
For these finite collections, |A| >= |B|. If the lake contains at least one
non-crucian fish, |A| > |B|. If it contains only crucian carp (or no fish),
A = B and their counts are equal.

The prose does not assert that a non-crucian fish exists. Therefore a strict
answer "A contains more" is not established; B cannot contain more, and A may
contain either the same number or more. This source-level underdetermination is
not a missing-media blocker and must not be repaired by adding fish.
