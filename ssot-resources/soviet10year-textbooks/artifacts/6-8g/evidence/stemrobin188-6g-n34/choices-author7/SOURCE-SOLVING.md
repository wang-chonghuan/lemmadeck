## Definitions and Quantifiers

根据所提供的定义，集合 M 上的关系 R：

- 自反性要求每个 x 都满足 xRx。
- 对称性要求任意 x、y 满足 xRy 时都有 yRx。
- 传递性要求任意 x、y、z 满足 xRy 且 yRz 时都有 xRz。

定义中的变量可以相等；没有“两两不同”的附加条件。下文使用
“等价关系当且仅当关系同时具有自反性、对称性、传递性”作为术语定义，
不引入任何教材已解例题。线、线段和多边形采用通常的欧氏几何对象；
若关系的定义限制同一平面，这个条件也属于关系本身。

## Source 446

原题：在线段的集合上给定的全等关系是等价关系吗？

任务是检验线段全等关系，而不是仅判断某一对线段是否全等。
普通线段全等当且仅当长度相等。记长度为 l(x)，则：

1. l(x)=l(x)，所以每条线段都与自身全等。
2. l(x)=l(y) 蕴含 l(y)=l(x)，所以全等关系对称。
3. l(x)=l(y) 且 l(y)=l(z) 蕴含 l(x)=l(z)，所以全等关系传递。

因此全等关系具有三种性质，是等价关系。线段的位置、方向、端点名称
不影响长度，也不需要线段在原位置重合。此结论在任意线段子集上也成立。

概念区别：几何对象不必是同一个对象，也可以在指定关系下等价。
选择题能够检验完整判定及其依据，但不能证明学生独立写出了三段论证。

## Source 447

原题要求分别检验三个关系的自反性、对称性、传递性和等价性。
关系的普通论域是相应几何对象的全集，而不是为某个性质特选的子集。

### 447(1): 多边形面积相同

关系 L R L1 当且仅当 A(L)=A(L1)。面积是有限欧氏多边形的数值。
数值相等具有自反性、对称性和传递性，故该关系三种性质都有，是等价关系。
面积相等并不要求形状相同或全等；例如面积为 4 的正方形与 1 乘 4 的
矩形，面积相同而不全等。这个例子是此处独立构造，不是教材例题输入。

### 447(2): 线段关于固定中心 O 对称

把关于 O 的中心对称变换记作 C。点 P 的像满足 C(P)=2O-P；
线段的像是其两个端点的像所组成的线段。关系 xRy 意味着 y=C(x)。
固定中心很重要：两次用同一个中心作对称，C(C(x))=x。

- 不自反：一般线段不由 C 保持。取 O=(0,0)，
  x 的端点为 (1,0)、(2,0)，C(x) 的端点为 (-1,0)、(-2,0)，
  显然不是 x。非退化线段与自身关于 O 对称，当且仅当中点是 O；
  若允许退化线段，则只有位于 O 的退化线段也满足。
- 对称：y=C(x) 蕴含 C(y)=x，所以 yRx。
- 不传递：对上述不自对称的 x，取 y=C(x)、z=x。
  xRy 且 yRz 都成立，但 xRz 就是 xRx，不成立。
  此反例合法，因为定义不要求 x、y、z 两两不同。

完整性质是“不自反、对称、不传递”，不是等价关系。
如果人为把论域缩为全部中点为 O 的线段，这个关系会成为恒等关系，
从而是等价关系；原题未给这个限制，不能默默换成该子集。

### 447(3): 直线 a 和 b “有一个公共点”

原句无法唯一确定“至少一个”还是“恰好一个”。不得把它悄悄改读成
“相交于唯一一点”或“允许重合”并宣称这就是原题唯一解。

读法 I：aRb 当且仅当 a 与 b 至少有一个公共点，即交集非空。

- 自反：直线与自身的交集是整条直线，非空。
- 对称：a 交 b 非空与 b 交 a 非空相同。
- 不传递：在一个欧氏平面中取 a: y=0、b: x=0、c: y=1。
  a 与 b 交于 (0,0)，b 与 c 交于 (0,1)，但 a 与 c 无公共点。
- 因此性质是“自反、对称、不传递”，不是等价关系。

读法 II：aRb 当且仅当 a 与 b 恰好有一个公共点。

- 不自反：直线与自身有无穷多个公共点，并非恰好一个。
- 对称：交集恰好是一个点与次序无关。
- 不传递：上述同平面 a、b、c 的两次交点均唯一，但 a 与 c 无公共点。
- 因此性质是“不自反、对称、不传递”，不是等价关系。

这两个分支的等价性结论相同，但自反性不同。以上反例在同一平面内已经
成立；若考虑空间直线，也仍然是合法反例。原题未明说全部直线同平面。
派生可见题若采用同平面全集，必须明写该论域，并把两种量词分别明写。
这属于消歧后的新题条件，不是对原题歧义的“解决”。

447 的完整结果：

| 关系 | 自反 | 对称 | 传递 | 等价 |
| --- | --- | --- | --- | --- |
| 面积相同 | 是 | 是 | 是 | 是 |
| 关于固定 O 中心对称 | 否 | 是 | 否 | 否 |
| 至少一个公共点 | 是 | 是 | 否 | 否 |
| 恰好一个公共点 | 否 | 是 | 否 | 否 |

概念区别：交换对象与连续应用关系是两种不同的要求；可逆变换不自动
产生传递关系；存在量词与唯一量词改变自反性。
选择题不能替代独立寻找反例、证明各性质及自行识别原文歧义的过程。

## Source 448

原题：举出几个等价关系的例子。

这是开放构造任务，不给定唯一答案或例子的个数。以下独立给出多个关系，
每个都带明确论域，并证明其三种性质，而不是只举满足关系的一对对象：

1. 在整数集合上，xRy 当且仅当 x=y。等号的三种性质直接成立。
2. 在整数集合上，xRy 当且仅当 |x|=|y|。绝对值是一个数值函数，
   其函数值相等具有三种性质；例如 3 与 -3 可相关但不相等。
3. 在整数集合上，xRy 当且仅当 x-y 是偶数。x-x=0 是偶数；
   若 x-y=2k，则 y-x=-2k；若 x-y=2k、y-z=2m，
   则 x-z=2(k+m)。所以三种性质成立。
4. 在同一欧氏平面中所有圆的集合上，两个圆相关当且仅当半径相同。
   半径数值相等具有三种性质；圆心不必相同。

这些例子均满足原题，来源于本次推导，不是从任何已解概念例题抄录。
共同结构是“某个对象属性相等”或可证明等价的奇偶性分类。
开放任务的完整答案是合法关系及其论域，不是枚举一个有限正确名单。

转换损失：从提供的候选中选出合法例子，只能检验识别与性质核验，
不能证明学生自行构造了几个新例子、选择了论域或写出了三性质证明。
这个开放生成能力必须在 coverage 中明确列为未检验任务。

## Source 449

原题把关系描述为：直线 a、b 在一个平面上，并且没有公共点。
检验的是这个严格不相交关系本身，不用“平行方向相同且允许重合”的
另一种定义替换它。记 aSb 当且仅当 a、b 共面且 a 交 b 为空集。

- 不自反：a 与自身虽然共面，但交集是 a，不为空集，故 aSa 不成立。
- 对称：共面条件和交集为空条件都不依赖次序，因此 aSb 蕴含 bSa。
- 不传递：同一个欧氏平面内取 a: y=0、b: y=1、c=a。
  aSb 与 bSc 都成立；aSc 即 aSa，交集不为空，因此不成立。
  明确允许 c=a，正是三变量全称定义要求检查的情况。

如果只考虑两两不同的 a、b、c，平行于同一直线的 a 与 c 确会平行，
但这个受限论证遗漏 c=a，不足以证明关系的传递性。严格平行的完整性质
是“不自反、对称、不传递”，所以不是等价关系。仅不自反已足以否定
等价性；额外检验传递性是为了完整理解所定义的关系及变量量词。
若论域改为全部空间直线，反例仍共面而有效，结论仍相同。

概念区别：几何语言习惯中“不同的三条平行线”的结论，与关系定义中
允许对象重复的全称条件不等价。
选择完整判定和反例不能替代学生独立写出反例及其论证。
