# 24．二元线性方程

> 第三章　方程组 · §8．二元方程组的概念

$5x+2y=10$，$0x+3y=7.5$，$2x+0y=12$，这些方程都可以写成 $ax+by=c$ 的形式。

$ax+by=c$ 形式的方程（其中 $a$、$b$、$c$ 是数，$x$ 和 $y$ 是变量），叫做二元线性方程（或二元一次方程）。

我们来说明，当线性方程的系数 $a$ 和 $b$ 至少有一个不等于 0 时，它的图象是什么。

设已知方程是$5x+2y=10$。用变量 $x$ 表示 $y$，得$y=-2.5x+5$。

式 $y=kx+l$（其中 $k$ 和 $l$ 是数）表示的是线性函数。因此，方程 $y=-2.5x+5$，即方程 $5x+2y=10$，表示的是线性函数，它的图象是一条直线（图 97）。

在所讨论的方程 $ax+by=c$ 中，设系数 $b\ne0$。当 $b\ne0$时，由方程 $ax+by=c$ 得$y=-\frac{a}{b}x+\frac{c}{b}$。

这就是说，当 $b\ne0$ 时，不管 $a$取什么值（包括 $a=0$ 的情况），方程 $ax+by=c$ 表示的是线性函数，它的图象是直线。

满足方程 $2x+0y=12$ 的数对只能是所有这样的数对，$x$ 的值必须等于 6，而 $y$ 值是任意数，如 $(6,0.01)$，$(6,-18)$，$(6,1004)$。

在所讨论的方程 $ax+by=c$ 中，设 $b=0$，系数 $a\ne0$。当$b=0$ 和 $a\ne0$ 时，方程 $ax+by=c$ 的图象也是直线。

因此，线性方程 $ax+by=c$ 的系数 $a$ 和 $b$ 至少有一个不等于 0 时，它的图象是直线。

我们来作方程 $x+4y=12$ 的图象。

因为这个方程的系数 $a$ 和 $b$ 都不等于零，所以它的图象是直线。

两点确定一直线的位置。所以只要求出两点的坐标就可以作出图象。任意取 $x$ 的两个值并计算相应的 $y$ 值：取 $x=0$，得 $y=3$；取 $x=4$，得 $y=2$。在坐标平面上描出坐标为 $(0,3)$和 $(4,2)$ 的点，再过这两点作直线。这条直线就是求作的图象（图 99）。

如果线性方程 $ax+by=c$ 的系数 $a=b=0$，那么方程的图象不是直线。因为当 $c=0$ 时，方程变为 $0x+0y=0$，任何数对都是它的解，所以它的图象是整个坐标平面。当 $c\ne0$ 时，方程无解，它的图象是空集。
