# 29. 列方程组解应用题

> 第三章　方程组 · §9. 线性方程组

用方程组可以很方便地解答应用题。

举几个例子。

应用题 1. 俱乐部买了 $10$ 付国际象棋和 $16$ 付跳棋，共计 $110$ 卢布。已经知道 $3$ 付国际象棋比 $4$ 付跳棋要贵 $2$ 卢布$20$ 戈比，一付国际象棋和一付跳棋的价格是多少？

解：设一付国际象棋值 $x$ 卢布，一付跳棋值 $y$ 卢布。那么 $10$ 付国际象棋和 $16$ 付跳棋共值 $(10x+16y)$ 卢布。

根据本题的条件：$10x+16y=110$。　　(1)

由于 $3$ 付国际象棋比 $4$ 付跳棋要贵 $2.2$ 卢布，所以得到另一个方程$3x-4y=2.2$。　　(2)

$x$ 和 $y$ 的值应当同时满足方程（1）和（2），所以它们应当满足方程组：$\begin{cases}10x+16y=110,\\3x-4y=2.2.\end{cases}$

解这个方程组，得到：$x=5.4$，$y=3.5$。

根据题意，$x$ 和 $y$ 的值应当是正数，上面的解满足这个条件。

答：一付国际象棋的价格是 $5$ 卢布 $40$ 戈比，一付跳棋的价格是 $3$ 卢布 $50$ 戈比。

应用题 2. 有两个书架，每个书架上要放几本书才能满足下面的条件：如果从第一个书架拿出 $8$ 本放到第二个书架上，那么第二个书架上的书是第一个书架上的书的一倍半。如果从第二个书架拿出 $2$ 本放到第一个书架上，那么第一个书架上的书是第二个书架上的书的两倍。

解：设第一个书架上放了 $x$ 本书，第二个书架上是 $y$ 本。如果从第一个书架拿出 $8$ 本放到第二个书架上，那么第一个书架上是 $(x-8)$ 本，第二个书架上是 $(y+8)$ 本。

第二个书架上的书是第一个书架上的书的一倍半，所以有$1.5(x-8)=y+8$。

如果从第二个书架拿出 $2$ 本放到第一个书架上，那么第一个书架上是 $(x+2)$ 本，第二个书架上是 $(y-2)$ 本。根据已知条件有$x+2=2(y-2)$。

$x$ 和 $y$ 的值应满足方程组：$\begin{cases}1.5x-y=20,\\x-2y=-6.\end{cases}$

解方程组，得：$x=23$，$y=14.5$。

根据题意，$x$ 和 $y$ 的值应当是自然数，所以这个题无解。
