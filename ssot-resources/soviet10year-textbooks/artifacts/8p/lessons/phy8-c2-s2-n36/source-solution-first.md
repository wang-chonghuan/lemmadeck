# First Source Solution, 180-7

Author reasoning recorded before choice alternatives. Not independent approval.
Source: retained `8p` PDF, physical pages 157-159 (printed 145-147).
Physical 156 (printed 144) was viewed only to confirm the preceding definition
`G = 6.67 x 10^-11 N m^2 / kg^2`; no source/figure approval of n35 is inferred.
The five exercises belong to printed "练习 23", under n36 and before n37.

1. Gravity here means Earth's attractive force on the body, directed toward
   Earth's center. Near the surface its magnitude is `GMm/R^2`; equivalently
   its vector is `m g`. It is not the body's force on a support.
2. The reported polar and equatorial accelerations are 9.83 and 9.78 m/s^2.
   Their absolute difference is 0.05 m/s^2; the equatorial value is smaller.
   The fractional difference relative to the polar value is about 0.00509,
   but the source asks the difference, not a percentage.
3. Height is measured above the surface. `h = 3R` therefore means distance
   from Earth's center `r = R + h = 4R`. The inverse-square law gives
   `g(h)/g(0) = R^2/(4R)^2 = 1/16`, not 1/9. Using the lesson's idealized
   surface value 9.83 m/s^2 gives about 0.614 m/s^2.
4. For the same body, setting `GMm/(R+h)^2 = GMm/(2R^2)` gives
   `(R+h)^2 = 2R^2`. The nonnegative height is
   `h = (sqrt(2)-1)R`, about 0.414R. `sqrt(2)R` is the center distance,
   not the height. No unsourced numerical Earth radius is needed.
5. The given Mars mass is `6 x 10^23 kg` and its radius is 3300 km,
   i.e. `3.3 x 10^6 m`. With the preceding sourced value of G,
   `g = (6.67 x 10^-11)(6 x 10^23)/(3.3 x 10^6)^2`
   `= 3.674931... m/s^2`, about 3.7 m/s^2. The result is independent
   of the falling test body's mass. The source's rounded planet data,
   not current astronomical values, are authoritative for this exercise.

The prose retains the original idealizations: local surface frames are
approximately inertial for rough calculations, and constant near-surface
