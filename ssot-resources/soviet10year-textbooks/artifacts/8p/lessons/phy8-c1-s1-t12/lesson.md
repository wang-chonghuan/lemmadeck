# **第一章提要**

物体（质点）机械运动的现象，是物体相对于其他物体的位置，即它的坐标，随时间而改变.

为了求物体在任意时刻的坐标，需要知道物体的初始坐标和位移矢量. 物体坐标的变化量等于位移矢量在坐标轴上的投影.

最简单的运动形式，是匀速直线运动. 在这种运动中，需要确定的只是一个坐标，这是因为可以沿着物体运动的方向作为坐标轴. 根据公式$x=x_0+vt$，可以计算物体（质点）在任意时刻的坐标$x$；式中$x_0$是物体的初始坐标，而$v$是物体速度矢量在$X$轴上的投影. 根据上式计算时，式中各量的符号由习题的条件确定.

任何运动都是相对的. 这就是说，物体相对于彼此作相对运动的不同坐标系的位移和速度，是不同的.

静止也是相对的. 如果物体相对于某个坐标系是静止的，那么，还存在有物体相对于它是在运动的参照系.
