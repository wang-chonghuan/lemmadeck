# 39. 地球的质量

当然不能把地球放在天平上来测量它的质量. 但是，利用自由落体加速度的公式$|\vec{g}|=G\frac{M}{R^2}$，可以计算它.

由此我们得到地球质量的数值为$M=\frac{|\vec{g}|R^2}{G}$.

$|\vec{g}|$ 和 $G$ 的数值向来是用实验方法测定：$G=6.67\times10^{-11}\frac{\text{牛顿}\cdot\text{米}^2}{\text{千克}^2}$和$|\vec{g}|=9.8\frac{\text{米}}{\text{秒}^2}$.

地球的平均半径也是众所熟知的：$R=6370$ 千米 $=6.37\times10^6$ 米.

把 $|\vec{g}|$、$R$ 和 $G$ 的数值代入到 $M$ 的公式中，得$M=\frac{9.8\frac{\text{米}}{\text{秒}^2}\times(6.37\times10^6\text{ 米})^2}{6.67\times10^{-11}\frac{\text{牛顿}\cdot\text{米}^2}{\text{千克}^2}}\approx6\times10^{24}\text{ 千克}$.
