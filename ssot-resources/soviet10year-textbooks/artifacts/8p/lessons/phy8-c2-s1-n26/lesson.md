# 26. 月球的质量

作为根据物体相互作用时的加速度来确定物体质量的例子，我们根据月球和地球的相互作用来求月球的质量.

大家知道，地球影响着月球的运动. 在地球的作用下，月球绕着地球做圆周运动，其半径约为$384000$千米.

通常认为月球绕着地球转，地心是月球轨道的不动的中心. 然而，这是不可能的，因为当物体相互作用时，两个相互作用的物体都获得加速度. 事实上，月球也给地球作用，使地球做圆周运动，使地球具有向心加速度. 但是，绕着哪个中心运动呢？

天文观测指出：月球不是绕着地心，而是绕着某一点$P$转动(图$80$)，该点到地心的距离为$4700$千米(这一点是在地球的内部). 地心也绕着这一点$P$做圆周运动(图$81$). 这就是说，从$P$点分别连到地球中心和月球中心的两个半径以相同的角速度绕$P$点运动. 地球的中心做其半径$r_{\text{地}}\approx4700$千米的圆周运动，而月球的中心做半径$r_{\text{月}}\approx380000$千米的圆周运动. 地球和月球的行动，像在§23里所讨论的实验中铝和钢圆柱体一样. 我们曾看到：两个圆柱体的向心加速度的比值，等于它们沿以运动的圆周的半径的比值. 同样，月球加速度$\vec{a}_{\text{月}}$和地球加速度$\vec{a}_{\text{地}}$的大小的比值，等于半径$r_{\text{月}}$和$r_{\text{地}}$的比值：$\frac{|\vec{a}_{\text{月}}|}{|\vec{a}_{\text{地}}|}=\frac{\omega^2r_{\text{月}}}{\omega^2r_{\text{地}}}=\frac{r_{\text{月}}}{r_{\text{地}}}$.但是，正如我们知道的，相互作用物体的加速度的比值，等于它们质量的反比，因此，$\frac{r_{\text{月}}}{r_{\text{地}}}=\frac{m_{\text{地}}}{m_{\text{月}}}$.因为$r_{\text{月}}\approx380000$千米，而$r_{\text{地}}\approx4700$千米，所以$\frac{m_{\text{地}}}{m_{\text{月}}}\approx\frac{380000}{4700}\approx81$.因此；月球的质量是地球质量的$\frac{1}{81}$. 地球的质量是一定的，它等于$6\times10^{24}$千克. 于是$m_{\text{月}}\approx\frac{6\times10^{24}\text{ 千克}}{81}\approx7\times10^{22}$千克.
