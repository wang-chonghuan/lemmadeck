# 第六章提要

如果除了已知初始坐标和初速度之外，还知道物体所受的力，即如果知道力与坐标或速度的关系，则可以利用牛顿定律解任何力学问题. 此时，必须注意：*力或几个力的合力*，*确定的不是物体的速度*（*大小和方向*），*而是物体的加速度*. 因此，物体不一定是沿力的方向运动. 物体运动的轨迹不仅决定于物体所受的力，而且还决定于初始条件——物体初速度的大小和方向.

只有当物体平动时，才可以把物体的运动看作是质点的运动. 只有在所有力的合力的作用线通过物体的质心这个条件下，物体才作平动. 否则，物体除作平动之外，还要绕某个轴转动.

如果相对于非惯性系（相对于某个惯性系做加速运动的参照系）来讨论物体的运动，则牛顿力学定律是不正确的. 相对于非惯性系来说，物体的加速运动不是物体受力引起的，而当有力存在时，物体可以做匀速运动.
