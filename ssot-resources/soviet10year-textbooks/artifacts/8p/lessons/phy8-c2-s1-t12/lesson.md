# 第四章提要　牛顿定律的意义

实验和观察指出，改变物体运动的原因，即改变物体速度的原因，是另外的物体对它的作用。没有这个作用，物体的运动不可能改变，即不可能出现加速度。一个物体对另外物体的定量的作用，用力的量值来表示。

一个物体对另外物体的作用不是单方面的，物体间是彼此相互作用的。相互作用时物体的加速度决定于物体的固有属性，这个属性叫做惯性，用质量的量值来表示。

这些实验事实是牛顿力学的基础，如果选择适当的参照系来描写运动，则牛顿定律可以正确地描写物体的运动，并可以解决力学的主要问题。这些参照系叫做惯性系。

牛顿第一定律断定这种参照系是存在的，并且可以找到它们。

**存在有这样的参照系，如果作用在物体上的合力等于零，则相对于这种参照系来说，物体的速度不改变。**

牛顿第二定律建立了力和由它产生的加速度之间的联系。

**作用在物体上的力，与力的种类无关，等于物体的质量和它的加速度的乘积。**

牛顿第三定律表明，一个物体对另外物体的作用具有相互的特性。

**物体间彼此以同一种类的力相互作用，其绝对值相等，方向相反。**

牛顿定律在原则上可以解决力学的任何问题。如果物体所受的力是已知的，则可以求出物体在轨迹上任何点在任意时刻的加速度。

这样就完成了在第三章最后所谈到的“线索”：根据已知的力和物体的质量求得加速度，然后可以计算物体的速度和在任意时间间隔内的位移，最后可以计算出物体在任意时刻的坐标。为此，应当知道“初始条件”——物体的初始位置和初速度。

例如，指挥宇宙飞船飞行的学者，当然，必须预先知道飞船在任意时刻的位置。利用这个“线索”，他们可以知道它。他们已知飞船在起飞场地上的初始位置和飞船的初速度。他们还已知在轨迹上任何点作用在飞船上的力。利用这些数据，他们解决了应用到宇宙飞行上的力学问题。但是，因为作用在飞船上的力是随时改变的，所以计算是相当复杂的，必须用计算机进行计算。

我们经常说：力学的主要问题是确定运动的物体在任意时刻的位置。但是，不应该这样想：利用运动定律只能确定物体的位置。实际上，经常要求计算这些量，如物体的速度，加速度，作用在物体上的力，等等。当然，牛顿定律可以解决这些比较简单的问题。
