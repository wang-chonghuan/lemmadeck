# **第五章提要**

*自然界中所有已知的力，都是几种相互作用形式的表现.在力学中所讨论的力，总共是两种相互作用形式（电磁的和引力的）的表现.*

*弹性力和摩擦力是电磁相互作用的表现.*

*弹性力是由于物体的一部分相对于另一部分运动使物体形变时产生的，它由下列方程（胡克定律）来确定：$F=-kx$.*

*万有引力是引力的相互作用的表现.$|\vec{F}|=G\frac{m_1m_2}{r^2}$.*

*弹性力和引力都与相互作用物体的相互位置有关，即与坐标有关.*

*在地球表面附近，地球对物体的吸引力等于$m|\vec{g}|$，如果物体离地球表面的距离远小于地球的半径，则可以认为吸引力是一个恒量.*

*摩擦力是在静止的接触物体（静摩擦）或运动的接触物体（滑动摩擦）之间产生的. 摩擦力的方向是沿着接触物体的表面、与接触物体相对运动的方向相反. 摩擦力与一个物体相对于另一个物体的坐标无关，而与它们的相对速度有关.*
