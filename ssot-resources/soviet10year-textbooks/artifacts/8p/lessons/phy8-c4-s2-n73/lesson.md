# 73. 机械效率

在任何机器消耗能量做功时，都应当特别注意所做的总功中的所谓有用功.

有用功是利用机器完成工作的功. 例如，对于起重机来说，有用功是把重物举高的功，对于机床来说，有用功是克服加工件和车刀的摩擦力所做的功，等等.

但是，在任何机器和任何发动机中，有用功总是小于总功，因为总是存在着摩擦力，摩擦力所做的负功使机器或发动机的各个部分发热. 而发热不能认为是用来作机械功的机器的有用成果. 发热使得发动机的一部分能量不转换为机械能，而转换为通常不能用来做功的内能.

因此，任何机器、任何发动机或机械，都用一个专门的量来表征，表示有多少能量被有效地利用. 这个量叫做*机械效率*.

**有用功和所做的总功的比值**，**叫做机器或发动机的机械效率**.

也可以说由一种形式的能量转换为另一种形式能量的发电机的机械效率. 例如，由机械能转变为电流做功的直流发电机就是这种发电机. 由于摩擦力的功和一些其他原因，电流的功总是小于所消耗的汽轮机的机械能.

**所得到的有用功和消耗的能量的比值**，**叫做发电机的机械效率**.

机械效率在任何时候都不可能大于$1$. 在实际的机器、发动机或发电机中，由于摩擦力总是做负功而产生的不可避免的能量损失，其机械效率总是小于$1$. 但是，也还有其他非机械原因的能量损失.

我们再次强调：“损失”这个词并不是说能量消失. 它只是表示一部分能量并没有转换为有用的方面，而是浪费掉了.

机械效率是用百分数表示的. 如果用字母$\eta$表示机械效率，而用$A_{\text{有用}}$表示有用功（或能量），用$A_{\text{总}}$表示所做的总功（消耗的能量），则$\eta = \frac{A_{\text{有用}}}{A_{\text{总}}} \times 100\%$.

**例题** $1$. 起重机用$10$千瓦功率的发动机带动. 如果发动机的机械效率等于$75\%$，那么把质量为$2$吨的重物举高$50$米需要多长时间？

**解**：起重机应当做的有用功$A_{\text{有用}} = m|\vec{g}|h$. 总功由下式表示$A_{\text{总}} = Nt$，式中$N$——发动机的功率，而$t$——起重机工作的时间.

根据例题的条件，发动机所做的功只有$75\%$是有用的. 因此，$A_{\text{有用}} = 0.75Nt$. **由此得出**$t = \frac{A_{\text{有用}}}{0.75N} = \frac{m|\vec{g}|h}{0.75N}= \frac{2000\text{ 千克} \times 9.8\text{ 米}/\text{秒}^2 \times 50\text{ 米}}{0.75 \times 10^4\text{ 焦耳}/\text{秒}}\approx 130\text{ 秒}$.

**例题** $2$. 质量为$2$吨的汽车，制动后以恒定的速度沿着山路滑下，并通过一段路程，降下$80$米高. 在制动过程中消耗了多少能量$Q$？

**解**：假如不制动，则势能的减少等于动能的增加量. 但是，因为汽车是以恒定的速度运动，所以在滑下时动能并不增加. 因此，所有损失的势能都转换为内能，即$Q=m|\vec{g}|(h_1-h_2)$.

把已知数据代入，则得

$Q=2000$ 千克 $\times9.8$ 米/秒$^2$ $\times80$ 米 $\approx16\times10^6$焦耳.
