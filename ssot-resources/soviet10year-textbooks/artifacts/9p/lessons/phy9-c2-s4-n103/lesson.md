# 103. 被激放电和自激放电

> 第十章 各种介质中的电流

**被激放电** 为了研究在不同压强下的气体放电，利用带有两个金属电极的玻璃管（图198）比较方便.

设利用某种电离剂在单位时间内在气体中形成一定数目的带电粒子对：正离子和电子.如果管中两个电极的电势差等于零，则在管中建立了动态平衡，此时，重新形成离子对的数目平均将等于由于复合而消失的离子对的数目.

![图 198](../../figures/fig-198.svg)

*图 198*

当管中两个电极的电势差不大时，带正电的离子向负电极移动，而带负电的离子或电子向正电极移动. 结果，管中形成了电流，即发生气体放电.

不是所有形成的离子都到达电极上：它们的一部分结合在一起，形成气体分子. 随着管中电极电势差的增大，到达电极上的带电粒子也增多. 电路中的电流也增大. 最后可以达到这种情况：在气体中形成的所有带电粒子全部到达电极上. 此时，电流不再进一步增大（图199）. 正如平常所说的，电流达到饱和 如果电离剂停止作用，则放电也停止，因为没有其他的离子源. 由于这个原因，放电叫做**被激放电**.

**自激放电** 如果继续增大两个电极间的电势差，气体中将怎样进行放电呢？

似乎，当继续增大电势差时电流应当保持不变. 然而，实验表明，当逐渐增大电极间的电势差时，电流最初保持一定的

据公式(10-10)，这就是说电子在碰撞前的动能增大了，从而它的电离本领也增大了.

因此，最简单的是在低压下(十分之一毫米高水银柱)管中发生的自激放电. 为此，两电极间加几百(而有时还小些)伏特的电势差就够了. 在一定条件下，管中发生了所谓的**辉光放电**.

直接观察辉光放电表明：它是不均匀的. 如果不注意结构的细节，则可以分为三个区域：阴极暗区、均匀的辉光——**阳电辉区**、阳极区.

正离子轰击阴极和阴极原有的放电辐射，是辉光放电中阴极发射电子的主要原因.

在阴极区，向阴极运动的质量大的离子通过这个区域所用的时间，比轻的电子所用的时间要长很多. 由此，在阴极附近形成了正电荷云. 在很短的距离上，电势急剧地变化，从带负电的阴极的最小值到空间正电荷云区域的最大值. 在阴极附近的这种电势急剧降落叫做阴极电势降落（图 202）. 正是在这个区域里，正离子获得了使电子从阴极表面脱出所需要的**能量**. 存在阴极电势降落是辉光放电的最重要的特征.

![图 202](../../figures/fig-202.svg)

*图 202*

在阳电辉区，由于碰撞电离而出现了许多电子. 电离时**产生的电子**向阳极运动，而正离子向阴极运动，并从阴极打出电子.

阳电辉区的特征是：它的参量(带电粒子的密度、电场强度)在这个区域的整个长度上没有变化.

辉光放电应用于宣传用的霓虹灯中. 在管中充满氖气时发橙黄—红色，氩气管中的阳电辉区是兰—绿色. 在日光灯管中，利用的是水银蒸汽的放电. 辉光放电在不久前制成的**量子光源**——气体激光器中得到了最重要的应用.

**电晕放电** 大气压强下，在不均匀的强电场中，观察到的放电光区通常叫做电晕. 因此，把这种放电叫做电晕放电.

导体的曲率越大，它的电荷面密度越大. 在尖端电荷的**密度最大**. 因此，在尖端附近产生强电场. 当电场强度超过$3\times10^6$ 伏特/米时开始放电. 在这种强电场下，由于电子的碰**撞使大气电离**. 随着远离导体表面，电场强度迅速地减小. 因此，在空间的局部区域内，能够看到电离和与它有关的气体发光.

带电的雷雨云，使地面感应出相反符号的电荷. 在尖端处**聚集**的电荷特别多. 因此，在下雨前或下雨的时候，常常在**高大建筑物**的尖端和尖角的地方，闪烁着象毛笔那样形状的光锥. 很久以来，把这种发光叫做神圣的埃尔摩火.

登山运动员常常看到这种现象. 有时，甚至不仅在金属**物件**，而且**在头发的端点**，也会出现小的发光的现象. 登山运动员用的凿冰斧，常常发出象大丸花蜂的嗡嗡声.

跟高电压打交道时，必须注意电晕放电. 当存在有凸出部分或很细的导线时，可能出现电晕放电. 这将导致漏失电能. 高压线的电压越高，导线应当越粗.

**电弧** 当两个碳棒接触时，在它们接触点的地方，由于电阻很大，所以电流放出大量的热量. 温度能升得很高，达到能发射热电子. 因此，当碳电极分开时，在它们之间开始放电.在两个碳棒之间产生了明亮的气体光柱——**电弧**. 在大气压强下，这时气体的导电性很大，因为负电极发射出的**电子的数**目很大. 小的电弧的电流强度可达几个安培，而大的电弧，在电压只有 50 伏特时，电流强度就能达到几十安培.

电弧是俄国科学院院士 В. В. 彼得洛夫于 1802 年首先得到的.

点燃电弧时，阴极的高温是由轰击阴极的正离子来维持的. 电子和离子被电场加速，在中性分子与这些加速了的电子和离子发生碰撞时，电弧中的气体也被加热到很高的温度.这样就产生了气体的热电离.

电弧的正电极，在电子轰击下，形成一个凹坑，叫做陷口.在大气压强下，陷口处的温度可达 $4000^\circ\mathrm{C}$，而在 20 个大气压下，可高达 $7000^\circ\mathrm{C}$. 为了想象出这个温度有多高，可以记住太阳表面的温度约等于 $6000^\circ\mathrm{C}$.

电弧不仅可以在两个碳棒电极之间发生，而且在两个金属电极之间也能发生.

如果在辉光放电时增大电流强度，则由于离子的轰击，阴极的温度能够升高到发生电弧放电. 这样，为了产生弧光放电，不必事先把电极靠近.

电弧放电是一种大功率的光源，它用于探照灯(图 203а)、投影机和电影放映机中.

**火花放电** 在大气压强下，当两个电极间的电场强度很大时(约 $3\times10^6$ 伏特/米)，在空气中发生火花放电. 从外型来看，火花放电是从尖端状的电极发出的，明亮的曲折光束.光束很快地穿入火花间隙，逐渐消灭，然后又重新点燃起来.随着空气压强的增大，发生火花所需要的电场强度将要大于$3\times10^6$ 伏特/米.

当电源的功率不能够维持电弧放电和辉光放电时，才发生火花. 在击穿火花间隙之后，电极间的电压降落很快，因为在放电时产生了离子，气体的导电性剧增. 两极间电压降落的结果是放电停止. 然后，电压又重新升高，等等.

当增大电源的功率时，火花放电转变为电弧.

在形成火花放电中，除了电子的碰撞电离，火花本身的辐射对气体的电离过程也起着很大的作用.

**闪电** 巨大的火花放电的例子是闪电. 闪电发生在两块云之间，或云和地之间. 闪电中的电流强度达到 500000 安培，而云和地之间的电势差达到几十亿伏特. 闪电放电是很短暂的，总共大约百万分之一秒.

在大雷雨的时候，有时可以看到球状的闪电. 这是一个在空气中缓慢移动的明亮的光球（图 204）. 球状闪电的大小可以是不同的，它的直径大约在 10～20 厘米. 球状闪电延续存在的时间——从十分之一秒到几分钟. 分析它的本质和在实验室的条件下得到这种闪电的尝试，还没有完全成功.
