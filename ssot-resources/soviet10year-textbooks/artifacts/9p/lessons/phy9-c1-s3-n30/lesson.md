# 30. 分子运动论中的理想气体

> 第三章　理想气体分子运动论

**在分子运动论中，分子间的相互作用小到可以忽略不计的气体，叫做理想气体。**换句话说，理想气体分子的平均动能比它们的相互作用势能大很多倍。

如众周知，在热力学中，其状态方程是门捷列夫-克拉珀龙方程 $(2-19)$ 的气体，叫做理想气体。这两个定义彼此并不矛盾，因为理想气体的分子运动论可以导出状态方程 $(2-19)$。

当气体相当稀薄时，即当分子间的平均距离比分子的大小大很多倍时，真实气体与理想气体相似。在这种情况下，分子间的吸引力可以完全忽略不计。只有在分子间相互碰撞的极短时间内，才出现有排斥力。

在气体的简单模型中，把分子看作具有质量的很小的钢球。当然，利用这种模型能否解释稀薄气体中的所有过程，是毫无保证的。要知道，分子不仅在质量上不同，它们还具有复杂的结构。

但是现在我们提出和解决相当狭窄的问题：利用分子运动论计算气体的压强。对于这个问题来说，气体的简单模型是十分够用的了。它可以导出实验证实了的结果。
