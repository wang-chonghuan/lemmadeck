# 93. 电路 导体的串联和并联

> 第二编 电动力学基础 · 第九章　稳恒电流

能量可以沿着导线从电源传递到需要能量的装置：电灯、电动机、无线电接收机，等等. 为此，要连成复杂程度不同的电路. 电路是由能源、需要电能的装置和开关组成. 通常在电路中还连接有测量电流强度和电压的仪器：安培计和伏特计.

通常遇到的导体连接的最简单的类型是串联和并联.

导体的串联 串联时，电路没有支路. 所有的导体在电路中是一个接着一个的连接. 电阻分别为$R_1$和$R_2$的两个导体的串联，如图$173$所示. 这两个导体可以是两个灯泡、两个电动机绕组等等.

![图 173](../../figures/fig-173.svg)

*图 173*

通过两个导体的稳恒电流强度是相等的：$I_1=I_2=I$.　　　　　　　　　(9-6)因为在稳恒电流的情况下，在导体中没有电荷的聚集，并且，在一定的时间间隔内通过导体任意截面的电量是相等的.

所研究的一段电路两端的电压（或电势差）是第一个导体和第二个导体两端电压的总和：$V=V_1+V_2$.

把欧姆定律应用于整个一段电路，和分别应用于电阻为$R_1$和$R_2$的一段电路，可以证明出串联时的总电阻为$R=R_1+R_2$.　　　　　　　　　(9-7)这个公式适用于任意数目的串联导体.

导体的并联 两个电阻分别为$R_1$和$R_2$的导体并联，如图$174$所示. 在这种情况下，电流$I$分成两部分. 通过第一个导体和第二个导体的电流分别用$I_1$和$I_2$表示. 因为在点$a$——导体的分支点（这点叫做结点），电荷不可能聚集，所以，单位时间内移到结点的电量，应当等于单位时间内从结点移出的电量. 因此，$I=I_1+I_2$.　　　　　　　　　(9-8)

![图 174](../../figures/fig-174.svg)

*图 174*

并联的导体上的电压是相同的.

照明电路的电压是$220$伏特或$127$伏特. 根据这个电压来设计用电器. 因此，并联是各种用电器最普遍的连接方法.并且，在这种情况下，去掉一个用电器不影响其他用电器的工作，而在串联时，去掉一个用电器就切断了整个电路.

分别对电阻$R_1$和$R_2$这两段电路应用欧姆定律，可以证明：$ab$段总电阻的倒数等于各个导体的电阻的倒数之和：$\frac{1}{R}=\frac{1}{R_1}+\frac{1}{R_2}$.　　　　　　　　　(9-9)由此得出，$R=\frac{R_1R_2}{R_1+R_2}$.　　　　　　　　　(9-10)公式(9-8)和(9-9)可适用于任意数目导体的并联.

电流强度的测量 为了测量导体中的电流强度，把安培计与导体串联（图$175$）.

![图 175](../../figures/fig-175.svg)

*图 175*

但是，应当注意：安培计本身具有电阻$R_0$. 因此，接入安培计的一段电路的电阻增大了，从而根据欧姆定律(9-3)，当电压不变时电流强度减小了. 为了减小安培计对被测电流强度的影响，安培计的电阻应当很小，必须牢记这一点，并且在测量照明电路的电流强度时，永远不能把安培计接到插销座上. 否则将发生短路. 仪器的电阻很小时，电流强度将达到相当大的数值，会烧断安培计的线圈.

电压的测量 为了测量电阻为$R$的一段电路的电压，把伏特计与它并联. 伏特计上的电压与这段电路上的电压是一致的（图$176$）.

![图 176](../../figures/fig-176.svg)

*图 176*

如果伏特计的电阻为$R_0$，则把伏特计接入电路以后，这段电路的电阻就不是$R$，而是$R'=\frac{RR_0}{R+R_0}<R$. 因此，被测的这段电路的电压减小了（当总电流强度不变时）. 为了减小伏特计对被测电压的影响，伏特计的电阻应当比被测电路的电阻大很多. 只要伏特计的额定电压比被测电路的电压大，把伏特计接到电路中就没有危险.
