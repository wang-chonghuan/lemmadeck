# 31. 分子热运动

> 第三章　理想气体分子运动论

我们一开始就应当放弃研究组成气体的所有分子运动的尝试。分子数太多，并且由于彼此碰撞，它们的运动是很复杂的. 我们不需要知道每个分子怎样运动。我们只希望阐明所有分子总的运动导致什么结果。

从实验可以得知气体分子总体运动的特性（参阅第一章）。**分子做紊乱的（无秩序的）热运动。**这就是说，任意分子的速度可以很大，或者很小，而当它们彼此碰撞时，分子运动的方向不断地改变。

不能根据单个分子的运动是完全紊乱的论点，就得出对分子总体的运动，什么也不能说的结论。

分子运动的紊乱性首先表明，气体中分子的运动所有的方向是均等的，没有任何一个方向的运动是占优势的。平均沿着任一方向运动的分子数，与沿相反方向运动的分子数是相同的。

好象在相当长的时间间隔内，平均沿着城市街道向各个方向走的人数是相同的一样。当然，应当除去特殊情况，例如节日游行。

如果单个分子的速度可以是任意的数值，则它们速度的平均值是完全确定的数值。与此类似的，一个班级里学生的年龄是不等的，但是，年龄的平均值是一个确定的数值。为了求出这个平均值，应当把学生的年龄加在一起，再被学生人数除。

下面，我们求的不是速度本身的平均值，而是求与分子平均动能有关的速度平方的平均值。

用 $v_1$、$v_2$、$v_3$、……$v_n$ 分别表示各个分子的速度大小。速度平方的平均值由下列公式确定：$\overline{v^2}=\frac{v_1^2+v_2^2+v_3^2+\cdots+v_n^2}{n}.$　$(3-1)$

这里 $n$——气体中的分子数。

但是，速度矢量大小的平方等于速度在坐标轴 $Ox$、$Oy$、$Oz$ 上的投影的平方之总和①：$v^2=v_x^2+v_y^2+v_z^2.$　$(3-2)$

①　这个关系对任何矢量都是正确的。你们可以利用毕达哥拉斯定理自己证明它。

平均值 $\overline{v_x^2}$、$\overline{v_y^2}$ 和 $\overline{v_z^2}$，可以利用类似于公式 $(3-1)$ 的公式来确定。平均值 $\overline{v^2}$ 与投影平方的平均值之间，存在着象 $(3-2)$式那样的关系式：$\overline{v^2}=\overline{v_x^2}+\overline{v_y^2}+\overline{v_z^2}.$　$(3-3)$

因为方向 $Ox$、$Oy$ 和 $Oz$ 是等价的，所以，速度投影平方的平均值是彼此相等的：

$\overline{v_x^2}=\overline{v_y^2}=\overline{v_z^2}.$　$(3-4)$

考虑到关系式 $(3-4)$，用 $\overline{v_x^2}$ 代替 $\overline{v_y^2}$ 和 $\overline{v_z^2}$，代到公式 $(3-3)$中，则得速度投影平方的平均值

$\overline{v_x^2}=\frac{1}{3}\overline{v^2},$　$(3-5)$

即速度投影平方的平均值等于速度本身平方的平均值的$1/3$。由于三维空间，因此任意矢量都有三个投影，所以出现系数 $1/3$。
