# 29. 大量粒子的系统和力学定律

> 第三章　理想气体分子运动论

在第一章里所叙述的分子运动论的基本原理，可以说明为什么物质有固、液和气态，并且可以定性地解释热现象的许多特性。

但是，物理学是一门定量的科学。现在可以把分子运动论（或统计力学）说成是近代物理学的一部分，是因为建立了分子过程的定量理论。

为了建立这种理论，必须知道单个分子运动的规律。你们已经学习过了牛顿力学定律。它们描写宏观物体的运动。单个原子或分子的运动，是否遵循同样的定律，事先是不知道的。

我们假设：牛顿力学定律适用于描写分子的运动。如果从所作的假设导出的理论结果被实验证实，那么就证明所作的假设是正确的了。

任何物质的性质是由组成它的粒子运动的性质和特征所决定的。我们讨论气体的压强，作为用实验观察到的宏观物体的性质，可以用大量粒子的运动来解释的例子。

设气体处于密闭的容器中。压强计指示气体的压强为$p_0$。但是，这个压强是怎样产生的呢？每一个气体分子，在跟器壁碰撞时，在很短的时间间隔内给器壁以一定的力。由于跟器壁的无秩序碰撞，所有分子给器壁单位面积的力，即压强，是随着时间很快地变化，如图 $45$ 所示。然而，单个分子的碰撞所引起的效果是相当微弱的，压强计上不能反映出来。因此，压强计指出的是作用在它的膜片上的平均力。尽管压强有微小的变化，这个平均值 $p_0$ 实际上是完全确定的量值，因为跟器壁的碰撞是很多的。

利用简单的力学模型，可以说明产生气体压强的过程。取一个小圆盘（它起着压强计的膜片的作用），并把它这样地固定在细杆上，使得它竖直放置，并能绕竖直轴旋转（图 $46$）。利用斜槽将一束小砂粒流向小圆盘（小砂粒起着分子的作用）。由于砂粒对圆盘的多次碰撞，产生了某个平均力，这个力使细杆旋转，引起弹簧片 П 的弯曲，单个砂粒碰撞的效果是不明显的。

定性地解释为什么气体对器壁产生压强是很容易的。但是，计算平均压强的量值就不那么简单。压强与气体的所有分子的运动有关，而分子数是巨大的，确定所有分子的轨道是不可能的。

然而，根据物质结构的概念，可以解决研究大量粒子所组成的系统的问题。这种系统整体的行为表现有确定的规律性。但是，这是新的规律性，是分子运动论或统计力学的规律性。

为了描写我们用实验所观察到的宏观物体的性质和过程，不必知道单个粒子运动的特性。重要的不是知道单个分子的行为，而是知道分子的总的运动所导致的平均结果。利用分子运动论也可以推得这个结果。

在宏观物体中分子过程的定量理论是十分复杂的。今后我们不讨论液体和固体的定量的分子理论（液体和固体分子间的作用力是很大的），只讨论气体的分子运动论。
