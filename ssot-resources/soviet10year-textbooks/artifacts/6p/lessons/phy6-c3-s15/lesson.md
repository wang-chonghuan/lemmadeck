# 29. 力

> 运动和力

在 $20$ 节、$22$ 节中所研究的惯性现象和物体的相互作用现象表明，任何一个物体的运动速度都只有在其它物体的作用下才能改变. 这个结论还可以用新的实例来证明.

推一个斗车（图 50），可以使斗车开始运动. 在这里，斗车的速度是在人的作用下改变的.

置于浮在水中的软木上的铁块受到磁铁的吸引，就开始运动（图 51）. 在这里，磁铁是使铁块和软木的速度发生变化的物体.

当手作用于球时（图 52，а），弹簧被压缩，即弹簧的端点发生运动. 压缩的弹簧伸长时，使球发生运动（图 52，б）. 开始时人手是产生作用的物体——它使球和弹簧末端产生运动. 而后球在压缩弹簧的作用下产生运动，即改变了原有的速度.

![图 52](../../figures/fig-52.svg)

*图 52*

用手或网球拍可以使飞来的球停住或改变它的运动方向.

在上述各例中，物体都是在其它物体的作用下开始运动、停止运动或改变原有的运动方向. 换句话说，在所有的这些例子中，物体的速度都是在其它物体的作用下改变的.

在物理学中通常都不指明是哪一个物体作用于这个物体的，也不指明是如何作用的，而是说有一个力作用在这个物体上，或说对这个物体施了一个力. **力是使运动速度发生变化的原因.**

在力的作用下，不仅物体整体的速度可以发生变化，物体个别部分的速度也可以发生变化. 例如，当用网球拍打一个橡皮球的时候，就产生这种情况. 由于球各个部分的位移不同，球就被压缩，发生了形变（改变了原来的形状）（图 53）. 上面坐了一个人的木板发生形变（图 54），是因为木板的中间部分比它的两端移动了更大的距离.

要使不同物体的速度发生同样的变化，所需的力是不同的. 移动一辆汽车比移动一辆摩托车要难. 换句话说，使汽车产生运动比使摩托车产生运动所需的力大. 由此可见，力的数值有大小之分. **力是一个物理量.**
