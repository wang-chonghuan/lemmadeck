# 54. 流体静力学佯谬 帕斯卡实验

> 液体和气体的压强（液体与气体静力学）

液体要把它所受的压强向各个方向传递的这一性质，可用来解释在物理学以**流体静力学佯谬**$\text{\textcircled{1}}$为名而著称的一种现象. 我们现在就来研究这种现象.

$\text{\textcircled{1}}$ “佯谬”一词用来称谓那种出人预料的、与通常观念不符的现象.

图118所示的三个容器的形状各不相同，但它们的底面积却相等，其中所装的液体的深度也一样. 这样的三个容器中所装的液体的质量是彼此不同的，不过它们的底所受的压强却都相同. 这个压强可以根据公式：$p=g\rho h$计算出来.

![图 118](../../figures/fig-118.svg)

*图 118*

另外，由于各容器的底面积相同，故液体对各容器底所产生的压力就相同. 这个压力等于竖直液柱$abdc$的重量：$P=g\rho hS$，式中$S$—底面积，$hS$—液柱的体积，$\rho hS$—液柱的质量.

所谓佯谬就在于：尽管各容器中液体的质量不同，但它们对各容器底的压力却全是一样的.

让我们用实验来对这个结论进行检验. 图119所示的三个容器都是用一块橡皮膜当底的. 把各容器依次装在仪器上的支座里，并在容器中灌上水. 这时，容器的底就向外凸，其外凸的动作将传递给指针. 这个实验的结果表明，**若各容器****中水的深度相同，则指针就指着同一刻度**. 这就是说，**液体对****容器底的压力与容器的形状无关，它总是等于一个以容器的****底为底，以液体的深度为高的竖直液柱的重量**.

![图 119](../../figures/fig-119.svg)

*图 119*

尽管这个结论已被我们根据实验进行了验证，但它看起来依然使人觉得是难以置信的，怀疑是不是错了. 实际上，这个结论决没有任何似是而非之处，它完全可以由帕斯卡定律得到解释.

我们来看图120. 在容器底上用$mn$标出的那一块面积所受的压力等于液柱$kmnl$的重量. 这个液柱所产生的压强为$g\rho h$. 根据帕斯卡定律，这个压强要传递到面积$am$和$nb$上. 这样，整个容器底$ab$所受的压力就等于竖直液柱$abdc$的重量. 这个力大于容器3（图119）中液体的重量，小于容器2中液体的重量，而等于容器1中液体的重量.

设想把容器3的狭窄部分（图120）做得又细又长，则我们只需用很少量的水就可以对它的底产生很大的压强. 帕斯卡在1648年就用这样的实验使他的同时代人极为惊讶. 他把一根细长的管子插在一个封严了的、装满了水的、结实的大木桶里（图121）.然后站在二层楼的阳台上往管中倒了**一茶缸**水. 结果，由于水对桶壁的压强大大增加，竟使桶壁裂开，水从裂缝中喷了出来.
