# 70. 简单机械

> 功和功率、能量

自远古以来人们就使用各种各样的装置来做机械功.

每个人都知道，直接用手移不动的重物（石块、柜子、车床等）使用一根结实的长棒——杠杆来移，就容易移动（图176，а，б）.

三千年前古埃及修建金字塔时，就用杠杆来搬动沉重的大石块，并能把这些大石块搬到很高的高处（图177）.

人们还经常使用斜面来把重物滚到或拉到高处，而不是直接把重物搬上去（图178）. 有时也用滑轮来提高重物（图179）.

**用来改变力的装置叫做简单机械.**

杠杆及其变形——滑轮、绞车；斜面及其变形——劈、螺旋等都是简单机械.
