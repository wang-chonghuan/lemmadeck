# 57. 地球大气层的形成

> 液体和气体的压强（液体与气体静力学）

和所有的物体一样，组成地球空气层的各种气体的分子也都要受到地球的吸引.

既然如此，那么它们为什么不都落到地球的表面上来呢？地球的空气层，即地球的大气是怎样保持住的呢？要弄清楚这个问题，就需要考虑到组成大气的各种气体的分子总是处于不停顿的无规则运动状态. 但这样就又产生了另一个问题：为什么这些分子不飞散到宇宙空间中去呢？原来和宇宙飞船或宇宙火箭一样，分子要完全离开地球也必须具有不小于$11.2$千米/秒的速度. 这个速度就是所谓的*第二宇宙速度*. 而地球空气层分子的平均速度则大大地小于这一宇宙速度. 所以绝大多数的空气分子都被重力“束缚”在地球上了.

分子的无规则运动和作用在分子上的重力使得气体分子只能在地球附近的空间中活动，形成自由空气层，即大气.

测量表明，空气的密度随着高度的增加而迅速地减小. 例如在地球表面上方$5.4$千米高度处的空气密度是地球表面处空气密度的$\frac{1}{2}$，而在$11$千米高度处则是$\frac{1}{4}$，等等，越高的地方空气越稀薄. 而在最上层（地球上方几百千米或几千千米处），大气逐渐过渡为真空. 大气是没有明显界线的. 图142所示的是地球大气中气体分子分布的图景.

严格地说来，由于重力的作用，在任何密闭的容器中气体密度的分布都是不均匀的. 容器底部气体的密度大于上部的密度. 因此，容器中的压强也不处处相同，底部的压强大于上部的压强. 但是，保存在容器中的气体在密度和压强方面的这种差别是非常小的，以致在很多情况下完全可以不予考虑. 但是对于分布在数千千米高度范围内的大气而言，这种差别就很重要了.
