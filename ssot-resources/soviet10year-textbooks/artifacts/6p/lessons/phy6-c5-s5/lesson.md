# 72. 杠杆在工程技术及日常生活中的应用

> 功和功率、能量

工程技术和日常生活中所用的各种省力的工具和机构都是以杠杆平衡的规律为根据的.

我们用剪刀干活是可以省力的，而剪刀就是由杠杆构成的（图182），杠杆的转动轴通过把两半剪刀联结在一起的剪刀轴. 动力$F_1$（图182）就是人手捏剪刀的肌肉力；阻力$F_2$就是被剪裁的材料的阻力. 用处不同的剪刀，结构也不一样. 办公室用的剪纸的剪刀（图182）的锋刃较长，几乎和柄一样长.这是因为剪纸并不需要用多大的力，而锋刃长则便于把纸剪得整齐. 剪金属片用的剪刀（图183）的柄要比锋刃长得多. 这是由于金属片的阻力太大了，所以要平衡它就不得不大大增加动力的力臂. 用于剪断铁丝的剪线钳（图184），其钳口到转动轴线的距离与其柄长相比，相差特别大.

很多机器中都包含有各种类型的杠杆. 自行车上的脚蹬子及手闸、汽车和拖拉机的刹车踏板、打字机的按键和钢琴的琴键等都是杠杆在这些机器或用具中应用的实例.

在学校的车间里我们也能找到使用杠杆的例子. 台虎钳的紧固手柄、钻床的送进手柄等都是杠杆.

$\textcircled{1}$ 安全阀是一种特殊的安全装置. 例如当蒸汽锅炉内的蒸汽压超过正常值时，安全阀就会把锅炉的排汽孔打开.
