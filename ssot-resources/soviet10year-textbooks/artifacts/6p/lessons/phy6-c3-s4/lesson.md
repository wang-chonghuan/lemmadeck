# 18. 变速运动的平均速度

> 运动和力

物体做变速运动时，在相等的时间间隔内通过的路程不等. 这种运动的速度是变化的.

尽管人们知道，火车或汽车停止时的速度为零，开动后速度逐渐增加，而在接近下一次停车时速度又逐渐减小，但还是经常说火车具有一个什么样的速度、汽车的速度等. 那么当说到火车的速度是 60 千米/小时的时候，到底应把这个速度理解为什么速度呢？

当谈到变速运动的速度时，所指的是在运动的某一段给定的路程上或在运动中的某一给定的时间间隔内的平均速度. 要计算平均速度，就用所通过的路程除以运动的时间，也就是说象计算匀速运动的速度那样来处理.

我们来看一个例题. 莫斯科与诺沃西比尔斯克之间的距离是 3200 千米. 快车做变速运动通过这段距离所用的时间为 64 小时. 现在我们假设这列快车改做匀速运动时通过这段距离也同样用 64 小时.

这样，这个匀速运动的速度就是：

$v=\frac{s}{t}$，$v=\frac{3200\text{千米}}{64\text{小时}}=50\text{千米/小时}$.

这也就是快车做变速运动的平均速度.

$\text{平均速度}=\frac{\text{路程}}{\text{时间}}$，或 $v_{\text{平均}}=\frac{s}{t}$.
