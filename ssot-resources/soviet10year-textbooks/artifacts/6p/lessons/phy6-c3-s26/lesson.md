# 40. 静摩擦

> 运动和力

我们已经知道了一个物体在另一个物体表面上运动时所产生的摩擦力. 但是，当两个互相接触的固体处于静止状态的时候，能不能谈它们之间的摩擦力呢？

当一个物体静止在斜面上的时候，它是靠着摩擦力的作用而停在那里的. 实际上，如果没有摩擦力，则物体在重力的作用下就要沿着斜面滑下来. 我们再针对物体在水平面上静止的情况，来研究这个问题. 例如，设地板上放着一张桌子，我们要把桌子挪开. 如果用较小的力推桌子，桌子将不移动. 这是为什么呢？原来这时推桌子的力被桌腿与地板间的摩擦力平衡了. 由于这个摩擦力阻止物体开始运动，故把它叫做**静摩擦力**.

静摩擦力的方向与可能发生的运动的方向相反. 因此，静摩擦力发生在要使物体脱离静止状态的时候. **最大的静摩擦力就等于使物体脱离静止状态时的作用力.**
