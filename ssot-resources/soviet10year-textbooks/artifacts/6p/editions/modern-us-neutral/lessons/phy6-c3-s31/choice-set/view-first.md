| B | 真 | 相同对地压力、更大履带实际支承面，\(F/S\) 减小；图87履带而非内部小滚轮是相关地面支承结构。 |
| C | 真 | 同载荷且选项明确实际土壤接触面积增大，平均压强减小，较少陷入软土的倾向符合本课简化机制；不推断机器重量因此减少。 |

| 项 | 真伪 | 独立证据 |
| --- | --- | --- |
| A | 真 | 窄刃b的有效接触面积较小且夹力相同，所以 \(F/S_b\) 较大；图88的两完整钳口及子标观察已在source-first冻结。 |
| B | 假 | a面积较大，固定夹力下压强应较小；该项把面积与压强的反比关系反转。 |
| C | 真 | 固定压力比较中，刃/针尖接触面积较小便使压强较大，不必为此增大F；与概念11“不大的压力”亦可产生大压强一致。 |
| D | 假 | 相同F不充分推出相同p，还须相同有效面积；本题恰在比较不同面积。 |

### q3 — 配重与耙齿

刚开始压入时比较同一有效接触面积。配重增加总重力及耙齿向下压力，故 \(p_{\rm 后}>p_{\rm 前}\)，有利于压入。

| 项 | 真伪 | 独立证据 |
| --- | --- | --- |
| A | 真 | F增加、S近似不变，\(F/S\) 增大，完整因果方向一致。 |
| B | 假 | 配重的质量增加会增加相应重力和向下压力；“只增质量不增压力”使后续不变结论失去依据。 |
| C | 假 | F增加、S不变应使p增加，该项却推成减小；末尾“利于进入”不挽救错误因果。 |
| D | 假 | 平均压强同时由F和S决定；固定S并不允许忽略F变化。 |

### q4 — 双脚/单脚面积与总压力

设F、s为本题正的压力和面积。站立总支承面2s、单脚阶段s；两状态总压力都为F，所以 \(p_{\rm stand}=F/(2s)\)、\(p_{\rm run}=F/s=2p_{\rm stand}\)。比例来自题内新增明确的同面积条件，不外推其他奔跑时刻。

| 项 | 真伪 | 独立证据 |
| --- | --- | --- |
| A | 假 | 面积2s/s正确，但固定F下p与S反比；站立应为单脚阶段的一半，不是2倍。 |
| B | 假 | 总压力相同但总面积不同，\(F/(2s)\ne F/s\)。 |
| C | 真 | 两个式、阶段和2倍关系均直接由题内同F及每脚s推出。 |
| D | 假 | 把双脚时可能的分担错误移到唯一支撑脚；题干已规定单脚状态总压力F，不是F/2，因此单脚值应为F/s。 |

### q5 — 格数估算、单位与两个压强

分别定义 \(N_w=n_w+k_w/2\)、\(N_s=n_s+k_s/2\)。正确面积为 \(S_i=N_i(1/4)10^{-4}\,{\rm m^2}\)，压力 \(mg\) 的单位N，平均压强 \(mg/S_i\) 为Pa。\(n_s,k_s\) 已是双脚全部轮廓合计，**不能再次乘2**；各状态实际计数独立，不能无根据设 \(S_s=2S_w\) 或固定压强比。

| 项 | 真伪 | 独立证据 |
| --- | --- | --- |
| A | 假 | \(N_i/4\) 是以cm²计的数值，却直接标成m²，漏乘 \(10^{-4}\)；面积错误放大 \(10^4\) 倍，所得压强错误缩小 \(10^4\) 倍。整/边格组合与mg子式正确不挽救单位错误。 |
| B | 真 | 两状态均采用整格＋半边格、每格1/4cm²及平方厘米到平方米换算，分别以mg除以各自面积，结果均为Pa。 |
| C | 假 | 将所有不完整格都算作整格，替代源规定的半格估算；因两项k均为正，两状态面积都严格过估、压强低估，不存在k=0使方案退化等价的情形。 |
| D | 假 | 面积正确但以质量m代替压力mg；m/S单位kg/m²，不是Pa，缺少g这一物理换算。 |

这只是符合原近似规则的方案，不声称半边格法为每个任意轮廓的精确面积，也没有从图89示意轮廓虚造本人的数值。

### q6 — 砖体积、重量与三底面

均匀长方体 \(V=lwh\)、\(m_{\rm 砖}=\rho lwh\)、\(F=m_{\rm 砖}g\)。静止水平面法向压力为重量F；三个支承面依题干为lw、lh、wh，故压强依次 \((\rho gh,\rho gw,\rho gl)\)，单位均Pa。**题干只给三尺寸正，没有给 \(l\ge w\ge h\)**，因此不附加三压强的固定大小顺序；“平/侧/竖”按明确底面映射理解。

| 项 | 真伪 | 独立证据 |
| --- | --- | --- |
| A | 假 | V和F正确，但只有实际接触水平面的那一面支承；六面总面积不是支持面积。正尺寸下 \(2(lw+lh+wh)\) 大于任一实际底面，三值均偏低，即使砖为立方体也不成立。 |
| B | 假 | \(\rho lwh\) 是质量kg，不是重量N；三个结果\(\rho h/\rho w/\rho l\)也为kg/m²而非Pa，系统漏乘g。 |
| C | 假 | 把体积误作lw而漏高度h，lw只有m²；因此所写F为N/m、三式为N/m³，不能称重量/压强。由这个错误F再除三底面恰会生成该三元组，错误根源是V少一个尺寸。 |
| D | 真 | V包含三个尺寸，F由密度×体积×g得到；分别除指定的lw/lh/wh后正确约去相应两尺寸，三元组与单位均一致，不需新增尺寸大小排序或密度数值。 |
