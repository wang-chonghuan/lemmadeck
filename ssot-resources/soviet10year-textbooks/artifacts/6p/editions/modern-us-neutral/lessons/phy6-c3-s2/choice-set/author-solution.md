# 源题先解

在构造任何选项之前，仅从本课题面和定义求解。

1. 匀速运动要求在任何相等的时间间隔内通过相等路程；一组较长区间的平均路程相同不充分。
2. 近似匀速的实例有地球自转、正常运行表针；规定匀速的直线运动也符合。出站加速或进站减速不符合。
3. 小车搭载滴液瓶，在纸带上留下等时间间隔的滴痕；比较相邻滴痕距离，等距表示相应观察尺度上的匀速运动。按课文加快滴落频率、保持新频率固定后，也应保持各间距相等；在同一车速下，频率加大才使间距变小，不能把滴落频率误作车速。
4. 加速出站火车、减速进站火车，以及等路程用时不同的滑冰运动均为变速。
5. 变速运动在相等时间间隔内通过的路程不相等；可以加速也可以减速，不等于只会越走越快。

响应单位：定义1/5合成一题区分量词和加减速；例子2/4合成一题判断情境；实验3单独判断有效证据。选择题不能证明学生独立表述、举例或搭建实验，原书书写题全部保留。
