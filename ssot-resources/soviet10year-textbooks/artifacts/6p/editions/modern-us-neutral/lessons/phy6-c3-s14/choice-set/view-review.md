## 第二关：全部选项独立求解

令 `M` 为总质量，`V` 为总体积，`N` 为总分子数，`n=N/V` 为数密度。对同种分子有 `M=N m_0`，所以 `ρ=m_0 n`。这些是审查者推导记号，不是新给定数据。

### molecular-density-relations

**independent_solution：** 正向关系为 `ρ=m_0 n`；反求 `n=ρ/m_0`，所以 `1 米³` 内 `N_1=ρ(1 米³)/m_0`。密度只有质量/体积信息，缺少单分子质量不能确定总分子数。

| 选项 | 独立真值 | 证据 |
| --- | --- | --- |
| A | true | 单位体积的质量是每个分子的质量乘以该体积分子数；`kg × m⁻³ = kg/m³`，故 `ρ=m_0 n`。 |
| B | true | `ρ(1 米³)` 是这份物质的总质量，除以 `m_0` 得分子总数，量纲无单位；不是把数密度直接当总数。 |
| C | false | 固定 `ρ` 而取不同未知 `m_0` 会得到不同的 `ρ(1 米³)/m_0`，所以仅密度不充分。 |
| D | false | 反求必须是 `n=ρ/m_0`。`ρ m_0` 的单位为 `kg²/m³`，不是数密度的 `m⁻³`。 |

**完整真集：`["A","B"]`。** 与 `multiple` 模式相容；其他两个选项均已独立排除。

### phase-density

**independent_solution：** 同种物质两物态中的单分子质量相同，密度比等于同体积分子数比。气态间距较大、数密度较小，密度差不是单分子质量变化造成的。

仅用 seed 给定量核算：

`958/0.598 = 479000/299 = 1602.006688963…`；

`80/0.09 = 8000/9 = 888.888888889…`。

因此“约 1600 倍”“约 890 倍”均是合理近似；无需单分子质量的绝对值，也未引入氧或其他物质的密度数据。

| 选项 | 独立真值 | 证据 |
| --- | --- | --- |
| A | true | 在题干的同种物质/本课模型比较中，气态间距较大，单位体积分子少；改变物态不把单个分子质量变小。 |
| B | true | 水的数密度比为 `958/0.598≈1602.01`，固态氢/氢气的数密度比为 `80/0.09≈888.89`；两项合取都成立，方向与对象正确。 |
| C | false | 水和蒸汽中是同样的水分子，单分子质量比为 `1`，不是 `1/1600`；该近似倍率应归于同体积分子数量。 |
| D | false | 氢气/固态氢的数密度比为 `0.09/80=0.001125≈1/888.89`，不是 `890`；气态间距也应更大而非更小。两个子断言都错误。 |

**完整真集：`["A","B"]`。** 与 `multiple` 模式相容；B 必须同时检查两个材料，不能只验证其中一个。

### fixed-mass-compression

**independent_solution：** 由无进出和无化学变化，`N'=N`；本课模型中 `m_0'=m_0`，且题干明确 `M'=M`。`V'<V`，故 `n'=N/V'>N/V`，`ρ'=M/V'>M/V`。压缩不创造分子，不增加每个分子的质量。

| 选项 | 独立真值 | 证据 |
| --- | --- | --- |
| A | true | 固定 `N` 的总体积缩小使数密度增大；`m_0` 不变，由 `ρ=m_0 n` 得密度增大。 |
| B | false | `N` 固定而 `V` 减小，数密度不能不变；单分子质量也不因该过程增大。虽然最后的密度增大正确，整项解释为假。 |
| C | false | 数密度应增加而非减少，密度应增大而非减小；单分子质量不变这一分句不能救整项。 |
| D | false | 前两项变化正确，但数密度增大且单分子质量不变必使密度增大，不可能密度不变；也直接违反 `M/V`。 |

**完整真集：`["A"]`。** 与 `single` 模式相容；B、C、D 中混有正确分句不使整个合取成为真。
