## Source1: Useful and Total Work

Task: define both work categories, not just their numerical inequality.

Useful work is the work accomplishing the selected purpose, such as raising the target heavy object or overcoming the intended external resistance. Total work is all the work supplied by the applied effort to the machine for that operation. For the actual machines described here, total work includes useful work plus the additional work needed for internal friction and motion of machine parts. The target matters: the internal-friction work is not automatically useful merely because it is required to operate the apparatus.

Using auxiliary notation only to make the partition explicit, A=A_useful+A_extra. This is a restatement of concepts1..3, not a newly measured amount. A, A_useful and A_extra are work quantities with matching units, not forces, powers or durations.

Conditions: compare the same operation and stated target. In the ideal lever model of concept0, ignored friction/lever weight eliminates the specified extra work and total equals useful work. Definitions do not reverse in that limit.

## Source2: Why Actual Work Categories Differ

Task: explain the cause of non-equality when a real machine raises a target object or overcomes the intended resistance.

Concepts1..3 state that some input work must overcome machine friction or move machine components. In the movable-pulley illustration, lifting the pulley itself and rope, and overcoming axle friction, are additional to raising the target object. Thus the actual operation has A_extra>0 and A>A_useful. The difference has identified work destinations; it has not simply ceased to exist. Lifting the machine/rope can change their potential energy, so all extra work must not be universally described as frictional dissipation.

Conditions: this is the actual-mechanical case described by the lesson, not the no-friction/no-component-weight idealization. It does not say every form of resistance is unwanted: the external resistance constituting the stated target belongs to useful work.

Open-production loss if converted: recognizing a complete causal account does not prove that the learner can independently write the explanation or supply a new physical example.

## Source3: Mechanical Efficiency

Task: define mechanical efficiency with the correct numerator/denominator and representation.

For a positive total input work A, the ratio is K=A_useful/A. It measures the share of total work assigned to the useful purpose. Since the work units match, K is dimensionless. Its percent representation is (A_useful/A) times100%; these are two representations of one efficiency, not two different physical magnitudes. The reciprocal A/A_useful is not this lesson's definition; (A-A_useful)/A would instead be the fraction of additional work.

Conditions: denominator A>0 and the same work-accounting boundary/operation. No numerical efficiency, g, density, force or experimental observation is supplied or inferred.

Open-production loss if converted: selection does not demonstrate independently producing the verbal definition or writing/using its formula on an unprompted task.

## Source4: Upper Bound and Reason

Task: answer whether the ratio-form mechanical efficiency can exceed1 and justify it.

For the described operation, A=A_useful+A_extra with A>0 and A_extra>=0. Therefore K=A_useful/A=1-A_extra/A<=1. For the book's actual machines with positive useful work and positive additional work, 0<K<1. In the ideal model in concept0, A_extra=0, so K=1. Efficiency does not exceed1; ideal equality is not an exception allowing greater-than-one efficiency.

In percent form the upper bound is100%, not a numerical threshold of1 on the number before the percent sign. Writing a percent number above1 does not itself mean useful work exceeds total work: the conversion must be applied first.

Conditions: positive total input work for the same operation; this is not a zero-denominator process, negative-work convention or an unaccounted release of previously stored energy. No such alternatives are declared as source facts. The inequality for the book's actual machinery is not silently extended to exclude its explicit ideal equality.

Open-production loss if converted: selection of a bounded-ratio argument cannot establish independently writing the proof or distinguishing new accounting conventions.
