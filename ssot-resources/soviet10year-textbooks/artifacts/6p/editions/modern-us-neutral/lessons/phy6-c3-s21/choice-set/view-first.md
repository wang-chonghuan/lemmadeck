## A. 先判可见任务与语义

下列源对应是审者按冻结原题与可见内容辨认的内部对应，
不是读取作者coverage得来，不授权向学习者展示源映射。

### Q1 s21-controlled-effects

mode multiple，4项；对应源1的大小、方向、作用点三个作用效果例证。
Task fidelity PASS：同一弹簧的弹性伸长比较大小；同车、同点、
等力而东/西比较方向；同门、同力同向而不同位置比较作用点，
三个因素均保留，没有把换物体材料等混杂条件当作作用点变化。
Redundancy PASS：三种控制条件的比较各考不同因素；反向推同门
检验不能只看大小/作用点而忽略方向，不是重复同一句结论。
Leakage PASS：每项的“这是在比较……”本身也是待判断命题，
没有正确标记或作者解释。标签不保证叙述物理关系成立。
损失：判断已给例子不证明能够自行举出三个例子或说明控制条件。

### Q2 s21-vector-reason

mode single，4项；对应源2为什么力是矢量。
Task fidelity PASS：可见新增12N同大小、东/西不同方向用于实例化
源定义，未替换任何原数值题；要求区分大小与方向以及矢量定义，
不能以作用点或运动状态代替它。
Redundancy PASS：仅数值/单位、仅作用点、混淆速度与力是不同错误。
Leakage PASS：题干只给两力的大小与方向，不给“何者是正确解释”；
仍须依据矢量定义作判断。
损失：识别完整定义解释不证明无备选项能自主说理。

### Q3 s21-force-diagram-rule

mode single，4项；对应源3的力图示，引用实际fig68。
Task fidelity PASS：保留箭头方向、长度与声明比例的大小关系，
并正面检验图没有比例时不能由像素/厘米直接读出牛顿数。
Redundancy PASS：箭头反向、把线粗当大小、无比例直接读牛顿数
是三个不同错误，既非同义句，也不是把图像任意长短作校准。
Leakage PASS：图的A和方向是本题读图输入，不是正确项标记，
图没有数值尺可直接抄某个力值。

**共同首句无判别力：** 四项都说A是始端和作用点，
因此单凭选对本题不能证明学生独立认定A的位置/作用点。

整包Q4/Q6另有受力对象/始端辨析，但它们也不能补称本题已检验
无提示定位A或自主画图。方向和标度判断仍真实存在，
按当前choice标准不因这一具体识别损失自动把整个图示任务判失败。
