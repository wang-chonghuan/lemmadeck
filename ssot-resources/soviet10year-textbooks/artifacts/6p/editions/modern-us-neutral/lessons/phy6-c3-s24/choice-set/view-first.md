## 独立完整真集与逐项证据

### q01 multiple：{A, B}

- A 正确：水平面上松手后仍滑动而减速，在题干排除非接触阻力的条件下，接触面对相对滑动有阻碍作用；不是惯性导致停止。
- B 正确：同一木块、载荷与初速度，两水平面重复比较，给定一面总较早停止的结果支持接触表面影响摩擦。结论仅支持该实验的接触差异，不外推粗糙度的普遍单调定律。
- C 错误：未记录/控制起始速度就不能排除初速度不同导致停止条件不同；“已经排除”与现有记录矛盾。
- D 错误：滑出桌面后已经失去与桌面的接触，桌面不再对它产生滑动摩擦；先前摩擦不会隔空持续。

### q02 single：{C}

设向右为正，题干给出 0 < v木块 < v桌板，故 v木块相对桌板 = v木块 - v桌板 < 0，木块相对桌板向左滑，桌板施加的滑动摩擦向右。只是符号推理，没有补数值。

- A 错误：以相对地面向右为判据得到向左，选错参照接触面；本题接触表面也在运动。
- B 错误：同向不等于同速，速度差非零，不能由同向推出无相对滑动或摩擦为零。
- C 正确：向右与相对桌板向左滑动这两部分一致，摩擦阻碍接触处相对滑动。
- D 错误：下压/载荷与滑动阻碍方向不同；水平面的滑动摩擦沿接触面，不由木块向下压推出向下摩擦。

### q03 multiple：{A, D}

- A 正确：粗糙表面凸起与划痕的嵌合阻碍相对滑动，符合概念 5。
- B 错误：消除可见凸起既不证明不存在微观不平，也不排除概念 8/9 的分子引力，故不能证明摩擦为零。
- C 错误：存在分子引力不消除粗糙表面嵌合机制；概念 9 明说粗糙时第一原因主要，不能把两因当互斥选项。
- D 正确：光滑接触的部分分子靠得很近，分子引力可显著表现并参与摩擦，符合概念 8/9；不声称摩擦大小或引力唯一性。

### q04 single：{B}

在概念 10 的润滑模型内，b 的液层隔开直接固体接触，把原固体表面滑动换为阻碍较小但不为零的液层滑动。预测减小不等于消失。

- A 错误：虽然减小的预测与课内结论相符，但润滑液隔开表面不等于永久磨平凸起；预测与解释的合取为假。
- B 正确：减小符合课内液层阻碍较小的前提，隔层及液层仍有摩擦均成立。选项不是完整自主解释的产物，已在上方记明这种表达损失。
- C 错误：由“不直接固体接触”推出液层也无摩擦、总阻力消失，删除了液层之间的摩擦。
- D 错误：把新增液层当作增加同样一次固体表面接触阻碍，违背 b 中固体被隔开及本课液层摩擦较小的模型。

### q05 multiple：{B, D}

- A 错误：停止转动而向前拖滑的车轮在地面接触处是滑动；轮子外形圆不决定当前接触运动方式。
- B 正确：木桶在地面实际滚动且不打滑，属于本课滚动摩擦情境。不把“不打滑”外推为滚动阻力零。
- C 错误：木桶离地，没有与地面接触；自身悬空旋转不是物体在另一表面上滚动，不能称这里有滚动摩擦。
- D 正确：雪橇相对雪面滑行，符合源 6 和概念 11 的滑动摩擦条件。
