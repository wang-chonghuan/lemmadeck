## 原始任务 1

题目：在物理学中，“物体”一词应如何理解？

独立解：本节将物理学研究的具体对象称为物体，不局限于人或动物的躯体。房屋、拖拉机、月亮、沙粒、铅笔、水龙头、一滴水、气球都是本节给出的物体例子；物体有形状并占有一定体积。
证据：block 0 说明日常“体”与物理术语的区别并列出对象；block 7 说明形状和体积。
关键任务：辨认术语意义。不能把“物体”缩成“人体”“固体”或“人造用品”，也不能把所有抽象研究概念都由“一切研究对象”这句话推成有体积的物体。
边界：这里的“有形状”并未说形状固定不变；水滴这一源内例子已排除“只有固体才是物体”的解释。

## 原始任务 2

题目：什么叫做实物？举出几个物体和实物的例子来。

独立解：依本节专门定义，实物是物质的一种形式，是构成物体的东西。铁、水、盐、空气、铝是实物的例子；一滴水和铝匙是具体物体的例子。可用源内配对说明：水构成一滴水，铝构成铝匙；前者说材料，后者说具体对象。
证据：block 7 直接给出定义、实物列表以及“水/一滴水”“铝/铝匙”的对照；block 0 提供其他物体例子。
关键任务：本题同时要求定义实物、列举物体、列举实物并区分两者，不能只覆盖其中一项。材料与具体对象的描述层次不同，不表示物体不由物质组成。
边界：本节“实物”不是日常“真实物件”的泛称，不能用后者替换专门定义；也不等于“物质”的全部范围。空气在源内明确是实物，实物不限于固态材料。“水”和“一滴水”的分类依赖题中是否把它说成材料或具体对象，不能删去限定后仍强迫互斥分类。
