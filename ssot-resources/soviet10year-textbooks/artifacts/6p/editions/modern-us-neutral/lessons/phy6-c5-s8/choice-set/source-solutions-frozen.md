## Nine Source Solutions

1. Source 1: Balance requires equal opposite moments about O: F1*l1 = F2*l2, where each arm is the perpendicular distance from O to the corresponding force line. Thus F1/F2 = l2/l1. Figure 181 has A and F1 on the longer right arm and B and F2 on the shorter left arm; its tick segments give l1/l2 = 2, hence F2/F1 = 2. Arm dimensions are metres and moment dimensions are N*m; equal forces are not required.

2. Source 2: A rigid lever turning through a common angle theta gives endpoint paths s1 = r1*theta and s2 = r2*theta. Under the stated ideal slow model and corresponding effective arms, their path ratio is inversely related to the force ratio: s1/s2 = F2/F1, equivalently F1*s1 = F2*s2 in the textbook's paired travel model. Figure 195 uses its own numbering: l1 is the short left arm and l2 the long right arm. Its right endpoint travels farther and its corresponding force is smaller. This is not permission to multiply an arbitrary curved path length by a fixed force with an unrelated direction; actual work uses the component along displacement, or its integral when the force direction varies.

3. Source 3: Yes. Apply the input force on the longer arm so the required input force is smaller than the load force. A factor-k force advantage requires factor-k input travel relative to load travel. This exchange preserves ideal input/output work; it does not save both force and distance.

4. Source 4: In figure 196 the moving pulley/load is supported by two segments of one inextensible rope, one end fixed. A load rise h shortens each supporting segment by h. The free end therefore travels 2h; slow balance gives 2T = G, so rope input F = T = G/2. Friction, rope/pulley weight, acceleration and rope stretch are excluded.

5. Source 5: For an ideal machine, saving force by a factor k requires k times the force-direction travel. Input work equals useful output work. A real machine additionally consumes work in friction, lifting its own parts or other losses, so its total input work is not unconditionally equal to useful output work and is never smaller merely because it saves force.

6. Source g2-1: s = 2h = 2*(1.5 m) = 3.0 m for the normal free-end input of the specified moving pulley.

7. Source g2-2: Rope input force is 160 N. At h = 7 m, rope travel s = 14 m and input W = 160 N * 14 m = 2240 J. At h = 5 m, s = 10 m and W = 160 N * 10 m = 1600 J. The ideal inferred load is 320 N, giving the same output work in either case. Do not use load height directly as rope input distance, and do not multiply the stated rope force by another factor of two as well as doubling travel.

8. Source g2-3: Reverse the normal machine's input and output. Keep the fixed rope end anchored, use the pulley axle as the driven input, and attach the load to the former free rope end. Raising the axle a distance d makes the rope-end load rise 2d. If load force is G, each supporting segment has tension G and the axle input must supply 2G. This saves input distance, not force: (2G)*d = G*(2d). Merely pulling the normal free end harder, or using the same normal load-on-axle arrangement, does not reverse the travel ratio.

9. Source q1: Let piston areas S1,S2 > 0 and displacement magnitudes h1,h2 correspond to the downward small-piston input and upward large-piston output. Equal displaced liquid volume gives S1*h1 = S2*h2. Equal pressure under the stated lossless, incompressible, no-leak, negligible-fluid-weight, frictionless slow model gives F1/S1 = F2/S2. Multiplying equal-pressure and equal-volume relations gives F1*h1 = F2*h2. Thus W_in = W_out. If S2 = k*S1, then F2 = k*F1 and h1 = k*h2, not h2 = k*h1. Pressure units are N/m^2, displaced volume is m^3, and work is J. Figure 100's downward F2 denotes the opposing load force; output work above is useful work received by that load as the large piston rises, not signed work of the downward resistance on an upward-moving piston.
