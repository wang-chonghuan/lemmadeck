## Conditions

Lever: quasistatic motion, negligible friction and lever selfweight, fixed fulcrum; the displayed forces are vertical. Moment arms are perpendicular distances to the force lines. For the straight lever with parallel forces, both moment arms acquire the same angular factor, so their ratio stays equal to the endpoint-radius ratio. Path lengths have that radius ratio; vertical displacement magnitudes also have it. Work uses displacement along the force, not arbitrary arc length.

Pulley: quasistatic motion, negligible friction and pulley/rope selfweight, inextensible rope, one fixed rope end and two supporting segments. Load is on the axle unless the reverse-use task explicitly changes that attachment.

Hydraulics: quasistatic motion, incompressible nonleaking liquid, negligible piston friction, piston selfweight, fluid selfweight and other losses. Both piston exteriors have the same reference pressure p0. F1 and F2 are the applied effort and resisting load magnitudes relative to that common reference pressure, not unequal absolute-pressure forces.

## Nine Written Tasks

- 1: Zero net moment about O gives F1*l1 = F2*l2. Fig-181 has A on the longer right arm and B on the shorter left arm, so F1 < F2. No numerical length is inferred from image scale.
- 2: Equal small angular motion gives s1/s2 = r1/r2. With the same vertical-force geometry, l1/l2 = r1/r2 and equilibrium gives s1/s2 = F2/F1. This statement compares path magnitudes; work instead uses the corresponding vertical displacement magnitudes.
- 3: Apply effort at the longer arm to reduce its force. A force reduction by factor n costs a factor n in effort travel. Ideal input and useful output work magnitudes are equal, so the same load raised through the same height does not cost less work.
- 4: When the axle rises h, each of two supporting segments shortens h. The free end must supply 2h of rope travel. Equal segment tension T and axle balance give 2T = G.
- g2-1: Free-end travel is 2*1.5 m = 3 m.
- g2-2: For 7 m, free-end travel is 14 m and work is 160 N * 14 m = 2240 J. For 5 m with the same 160 N pull, travel is 10 m and work is 160 N * 10 m = 1600 J. As a second derivation, G = 2*160 N = 320 N, and G*h gives those same two results.
- g2-3: Fix one end; attach the load to the other end, and apply effort to the pulley axle. For axle rise x and free-end/load rise y, constant rope length gives 2x-y = 0, hence y = 2x. Load balance gives T = G; axle effort must be 2T = 2G. The effort travels half the load distance but is twice its weight, with equal work. This is a reasoned arrangement, not evidence that a learner built or operated it.
- 5: In an ideal passive machine, reducing effort by factor n requires increasing effort travel by n for the same useful output. Input work equals useful output work; time taken does not change that equality. With a positive friction loss and the same quasistatic lift, actual input work exceeds useful output work by the dissipated energy.
- q1: Volume conservation gives S1*h1 = S2*h2. Equal reference external pressures and negligible fluid weight give p0+F1/S1 = p0+F2/S2, hence F1/S1 = F2/S2. Therefore F1*h1 = (F1/S1)(S1*h1) = (F2/S2)(S2*h2) = F2*h2. Large area gains force and reduces piston travel. Recognition of this complete proof cannot verify generating it unaided.
