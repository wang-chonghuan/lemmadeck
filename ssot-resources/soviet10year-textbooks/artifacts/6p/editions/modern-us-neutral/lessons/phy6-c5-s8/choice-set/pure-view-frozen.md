## lever-golden-judgments

Native multiple; independently complete true set: A, C, E.

- A correct: opposing moment balance is F1*l1 = F2*l2. On the longer arm the force magnitude must be smaller. N*m is a moment, not a force or distance.
- B incorrect: l1 = 2*l2 gives F1 = F2/2, not 2*F2. Its wrong procedure preserves the arm ratio in the force ratio instead of taking the reciprocal.
- C correct: for a rigid straight lever the two endpoint radii have ratio r1/r2; common rotation gives s1/s2 = r1/r2. Under vertical forces at a nondegenerate orientation, l1/l2 = r1/r2 as the same projection factor applies to both arms. Moment balance then gives s1/s2 = F2/F1. This path-ratio statement does not use arbitrary arc length as work distance.
- D incorrect: simultaneously taking input force and input travel to 1/n would give only 1/n^2 of the same required output work, contrary to the stipulated equal task, endpoints and ideal slow conditions. It mistakes force saving for work/distance saving.
- E correct: input force reduced by n requires corresponding input travel multiplied by n; their product is unchanged. The explicit ideal/no-other-loss conditions keep this from claiming lossless operation of real machines.
