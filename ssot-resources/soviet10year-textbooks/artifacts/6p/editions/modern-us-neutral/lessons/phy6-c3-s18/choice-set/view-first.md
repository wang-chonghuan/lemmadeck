## B. 后解完整可见选项

不看作者keys，按实际stem和冻结seed定义独立解：
地球对右侧物体施重力，物体因地球吸引对悬挂物施重量。
竖直悬挂、静止情形下，物体对悬挂物的作用向下；
悬挂物对物体的承载作用向上，但后者不是“物体的重量”。

| option | truth | 独立依据 |
| --- | --- | --- |
| A | true | 重力由地球施加，受力对象是该物体；在此情形方向竖直向下。施力者、受力对象、方向三项均正确。 |
| B | false | 悬挂物对物体的向上承载力是反向作用关系，不是本课定义的该物体对悬挂物施加的重量；方向为向上不能挽救名称和施受关系错误。 |
| C | true | 该物体因地球吸引而对悬挂物施力，是物体的重量；竖直静止悬挂时作用在悬挂物上的方向向下。 |
| D | false | 地球对物体施加的是重力；重量由物体施加在支承物/悬挂物上。把两力都说成地球对物体的力，丢失重量的施受对象。 |
| E | true | 放在水平桌面时，物体因地球吸引对桌面施加的力符合定义的支承物分支，也叫重量；不需要把定义限为悬挂物。 |

完整true set：`{A,C,E}`。
完整false set：`{B,D}`。
