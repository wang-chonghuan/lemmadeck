# 48. 有理分式函数的导数

定理. 以整数$n$为指数的幂函数$x\to x^n$，它的导数等于指数$n$和幂函数$x^{n-1}$的积，即$(x^n)'=nx^{n-1}$　(1)当$n\geqslant2$时对一切$x$成立，而当$n\leqslant1$时只对$x\ne0$成立.

证明　当$n>1$时，公式在第46小节已经得到证明.如果$n=1$，那么当$x\ne0$时，有$(x)'=1=1\cdot x^{1-1}$，因此，定理对$n=1$成立. 当$n=0$，公式(1)也成立：当$x\ne0$，有$x^0=1$，且$(1)'=0=0\cdot x^{0-1}$. 如果$n$是负整数，那么设$n=-m$，其中$m$是正整数. 利用商的导数定理，当$x\ne0$时，得到$(x^n)'=(x^{-m})'=\left(\frac{1}{x^m}\right)'=\frac{(1)'x^m-(x^m)'}{x^{2m}}=\frac{-mx^{m-1}}{x^{2m}}=-mx^{-m-1}=nx^{n-1}$.

定理证毕.

特别是，$\left(\frac{1}{x}\right)'=(x^{-1})'=(-1)\cdot x^{-2}=-\frac{1}{x^2}$.

于是，$\left(\frac{1}{x}\right)'=-\frac{1}{x^2}$.

因为有理分式函数可以表示为两个多项式的商，所以由上述定理得到一个重要的结论：有理分式函数在它的整个定义域上可微.

例 1. $(x^{-5})'=-5x^{-6}$.

例 2. $\left(3x^4-\frac{7}{x^3}\right)'=12x^3+\frac{21}{x^4}$.

当 $x>0$，公式(1)对任何有理指数 $r$ 都成立(这一点将在十年级给予证明)：

$(x^r)'=rx^{r-1}$.

特别是，当 $r=\frac{1}{2}$ 时，$(x^{\frac{1}{2}})'=\frac{1}{2}x^{-\frac{1}{2}}$ (在第 43 小节的第 354 题中曾经得到这个结果)，因此

$(\sqrt{x})'=\frac{1}{2\sqrt{x}}$.

例 3. $(\sqrt[3]{x^4})'=(x^{\frac{4}{3}})'=\frac{4}{3}x^{\frac{1}{3}}=\frac{4}{3}\sqrt[3]{x}$ $(x>0)$.

例 4. $\left(\frac{1}{\sqrt{x^3}}\right)'=(x^{-\frac{3}{2}})'=-\frac{3}{2}x^{-\frac{5}{2}}=-\frac{3}{2\sqrt{x^5}}=-\frac{3}{2x^2\sqrt{x}}$ $(x>0)$.
