Use four native `single` questions, each selecting one complete derivative
result row. The count follows four independently specified functions, not a
quota or the number of requested slots. There are fourteen requested derivative
expressions/evaluations but only four response units.

- 380: one triple judges the nonconstant quotient-rule numerator together with

- 381: one universally valid conditional quadruple captures symbolic parameter

  The visible stem supplies a common natural-domain reading convention so that

`single` is native to selecting one internally coherent complete result.
`multiple` would require separately judged statements or extra parameter claims
not needed to solve these written result requests. No such expansion is made.
The parameter task is retained despite overlapping quotient-rule algebra
because it requires a universal identity and conditional evaluations rather
than one fixed numerical function.

All fourteen requested mathematical outputs are represented. No drawing task
exists. Lost capacities are generating the derivation and result expressions
without candidates, independently performing the substitutions, and, for 381,
discovering the denominator conditions without being given the common reading
convention. These losses will be explicit in both intent and coverage.

The cold semantic reviewer will assess actual task fidelity, redundancy,
leakage and mathematical truth. This author decision is not a semantic review.
