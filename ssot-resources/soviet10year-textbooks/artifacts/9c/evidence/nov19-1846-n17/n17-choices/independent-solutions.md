## 134：距离公式的完整证明

任务：证明坐标轴上任意两点的线段长度满足 $|AB|=|x_B-x_A|$，不能只验证某一组坐标。

设原点为 $O$。交换两点不改变距离，也不改变坐标差的绝对值，因此不妨令 $x_A\leqslant x_B$。

1. 若 $0\leqslant x_A\leqslant x_B$，则 $|AB|=|OB|-|OA|=x_B-x_A$。
2. 若 $x_A\leqslant x_B\leqslant0$，则 $|AB|=|OA|-|OB|=(-x_A)-(-x_B)=x_B-x_A$。
3. 若 $x_A\leqslant0\leqslant x_B$，则 $|AB|=|AO|+|OB|=-x_A+x_B=x_B-x_A$。

这些情况包含原点为端点的情况；若两点重合，则两边都为零。因 $x_B-x_A\geqslant0$，得到 $|AB|=|x_B-x_A|$。交换后的次序由 $|x_A-x_B|=|x_B-x_A|$ 覆盖。

区分：有向坐标差与非负距离；同侧取长度之差、异侧取长度之和；证明的全称性。

## 135：一正一负的小数坐标

任务：求 $M(1.5)$ 与 $M(-2)$ 的距离。

$d=|(-2)-1.5|=|-3.5|=3.5=\frac72$。两点在原点两侧，也可算 $1.5+2=3.5$。

区分：负坐标参与相减，并不使距离为负。

## 136：另一组异侧坐标

任务：求 $M(-10.3)$ 与 $M(6.2)$ 的距离。

$d=|6.2-(-10.3)|=16.5=\frac{33}{2}$。

区分：减负数须加上对应正数；异侧长度相加。

## 137：原点为端点

任务：求 $M(-3.6)$ 与 $M(0)$ 的距离。

$d=|0-(-3.6)|=3.6=\frac{18}{5}$。

区分：到原点的距离是坐标的绝对值，而非坐标本身。

## 138：两点都在原点左侧

任务：求 $M(-5.7)$ 与 $M(-7.1)$ 的距离。

$d=|-7.1-(-5.7)|=|-1.4|=1.4=\frac75$。也可算 $7.1-5.7=1.4$。

区分：同侧两点的距离不是各自到原点距离的和。

## 139：原点中心的等距点与内部区间

任务分别为求 $|x|=5$ 与 $|x|<5$ 的完整解集。

等式分两支：$x=5$ 或 $x=-5$，解集为 $\{-5,5\}$。

严格不等式等价于 $-5<x<5$，解集为 $]-5,5[$。两个端点到原点的距离恰为 $5$，因此不属于此解集。

区分：恰好等距只有两个点；小于给定距离是开区间，包含零但不含端点。

## 140：平移中心与非严格内部区间

任务分别为求 $|x-10|=4$ 与 $|x-10|\leqslant4$ 的完整解集。

等式为 $x-10=\pm4$，故 $x=6$ 或 $x=14$，解集为 $\{6,14\}$。

不等式为 $-4\leqslant x-10\leqslant4$，两侧加 $10$ 得 $6\leqslant x\leqslant14$，解集为 $[6,14]$。

区分：中心是 $10$ 而非 $-10$；不大于给定距离含两个边界点。

## 141：外部射线与端点

任务分别为求 $|x|\geqslant5$ 与 $|x-10|>4$ 的完整解集。

第一式等价于 $x\leqslant-5$ 或 $x\geqslant5$，解集为 $]-\infty,-5]\cup[5,+\infty[$。这是两条闭起点射线的并集，不是中间区间，也不是两个条件的交集。

第二式等价于 $x-10<-4$ 或 $x-10>4$，即 $x<6$ 或 $x>14$，解集为 $]-\infty,6[\cup]14,+\infty[$。两个边界点的距离恰为 $4$，均须排除。

区分：距离下界产生外部的并集；严格与非严格比较决定端点。

## 142：从等距命题建模

任务：将 $M(x)$ 与 $M(5)$ 的距离等于 $2$ 写成方程，并给出解集。

方程为 $|x-5|=2$。由 $x-5=\pm2$ 得 $x=3$ 或 $x=7$，解集为 $\{3,7\}$。

区分：距离必须绝对值化，且须保留中心两侧的两种可能。

## 143：负中心的严格距离上界

任务：将 $M(a)$ 与 $M(-1)$ 的距离小于 $3.5$ 写成不等式，并求解。

$|a-(-1)|=|a+1|<3.5=\frac72$。于是 $-\frac72<a+1<\frac72$，减 $1$ 得 $-\frac92<a<\frac52$。解集为 $]-4.5,2.5[$。

区分：减去负坐标后出现加号；严格比较不含端点。

## 144：小数半径与非严格比较

任务：将 $M(-4.5)$ 与 $M(y)$ 的距离不大于 $0.2$ 写成不等式，并求解。

$|y+4.5|\leqslant0.2$，即 $-0.2\leqslant y+4.5\leqslant0.2$，故 $-4.7\leqslant y\leqslant-4.3$。解集为 $[-4.7,-4.3]=[-\frac{47}{10},-\frac{43}{10}]$。

区分：负中心与很小半径；“不大于”包含两端。

## 145：坐标为变量的相反数

任务：将 $M(-12)$ 与 $M(-b)$ 的距离不小于 $\frac1{48}$ 写成不等式，并求解。

距离为 $|(-b)-(-12)|=|12-b|=|b-12|$，因此 $|b-12|\geqslant\frac1{48}$。

分两支得 $b-12\leqslant-\frac1{48}$ 或 $b-12\geqslant\frac1{48}$，即
$b\leqslant\frac{575}{48}$ 或 $b\geqslant\frac{577}{48}$。
完整解集为 $]-\infty,\frac{575}{48}]\cup[\frac{577}{48},+\infty[$。

也可先对点的坐标求解：$-b\leqslant-\frac{577}{48}$ 或 $-b\geqslant-\frac{575}{48}$，乘以 $-1$ 时方向反转，得到同一解集。两个端点的距离都恰为 $\frac1{48}$，均包含。

区分：变量 $b$ 与点坐标 $-b$ 不相同；距离下界产生外部并集；分数端点精确且包含。

## 146：两个本质不同的平面点集

任务包括完整几何描述和在坐标平面上作图。

第一集合：$(x-2)(y+3)=0$ 当且仅当 $x=2$ 或 $y=-3$。它是竖直直线 $x=2$ 与水平直线 $y=-3$ 的并集，交点为 $(2,-3)$。两条直线上的所有点都在集合中。作图应画两条完整实线，包括交点；不是只有交点，也不是一个半平面或整个平面。

第二集合：$\frac{y-x}{x-1}=0$ 首先要求分母不为零，即 $x\ne1$；在此前提下必须 $y-x=0$，即 $y=x$。它是直线 $y=x$ 除去点 $(1,1)$ 后的集合。作图应画经过原点、斜率为 $1$ 的完整直线，并在 $(1,1)$ 标空心点；该点处分式无定义，不能因分子也为零而保留。没有其他被删除的点。

区分：零乘积对应并集；零分式需兼顾分子为零和分母非零。两个任务分别依赖不同逻辑，不按印刷子题编号机械拆分。

能力损失：零图像预算下只编写几何关系的文字识别题；不提供候选图，也不检验自主画出两直线或带缺口直线的能力。这不妨碍完整解出点集及描述正确绘法。

## 147：两个半平面的交集

任务包括完整几何描述和在坐标平面上表示集合。

条件须同时满足：$x<0$ 表示纵轴严格左侧的开半平面；$y\geqslant-1$ 表示水平直线 $y=-1$ 上方、包含该直线的闭半平面。所求是两者的交集。

集合包含 $y=-1$ 上所有 $x<0$ 的点，不包含纵轴上的任何点，尤其不包含 $(0,-1)$。它向左、向上无限延伸。表示时，应画不包含的竖直边界 $x=0$、包含的水平边界 $y=-1$，并只涂左上公共区域；水平边界的左侧射线包含，端点 $(0,-1)$ 不包含。竖直边界在 $y\geqslant-1$ 的部分仍不包含。

区分：多个条件是交集，不是并集；两个不同边界的取舍不能混同。

能力损失：只检验几何区域及边界的文字判断，不能检验自主作图、涂区域、用虚实线或空心点表达边界。
