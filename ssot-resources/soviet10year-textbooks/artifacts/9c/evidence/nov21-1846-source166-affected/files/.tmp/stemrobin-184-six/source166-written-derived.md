## 374а: y=x+1/x

Domain: R without0. Odd function. No x- or y-axis intersection.
Derivative1-1/x^2: increasing(-infinity,-1) and(1,infinity);
decreasing(-1,0) and(0,1). Local maximum(-1,-2), local minimum(1,2).
The negative branch lies below y=x; the positive branch lies above y=x.
Vertical asymptote x=0; oblique asymptote y=x at both infinities.
Limits:0- -> -infinity,0+ -> +infinity.
Range:(-infinity,-2] union[2,infinity).
Sketch anchors:(-2,-5/2),(-1,-2),(-1/2,-5/2),
(1/2,5/2),(1,2),(2,5/2). Keep the two branches separate at0.
Second derivative2/x^3 is negative on the left branch and positive on the right.

## 374б: y=x^2+2/x

Domain: R without0. Derivative2x-2/x^2=2(x^3-1)/x^2.
Strictly decreasing on(-infinity,0) and(0,1), increasing on(1,infinity).
Only stationary point:(1,3), a local minimum and the positive branch's minimum,
not a global minimum on the full domain. Negative branch takes every real value.
x-intersection:(-cuberoot(2),0); no y-intersection.
Vertical asymptote x=0. As x tends to either infinity,y-x^2=2/x tends to0,
so the curve approaches the parabola y=x^2; there is no oblique straight-line
asymptote. Negative branch lies below the parabola; positive branch above it.
Limits:0- -> -infinity,0+ -> +infinity; both infinity ends -> +infinity.
Full range:R; positive-branch range:[3,infinity).
Sketch anchors:(-2,3),(-1,-1),(-1/2,-15/4),
(1/2,17/4),(1,3),(2,5). Both branches are unbounded near0.
Second derivative2+4/x^3 changes sign at x=-cuberoot(2), giving inflection
point(-cuberoot(2),0). Concavity is positive before that point, negative from
that point to0, and positive on the positive branch.
