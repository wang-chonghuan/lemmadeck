and the new coefficient is 4. Basis: source 375(a), blocks 0, 3 and 4.

### 375(b): `g(x) = x^3`

### 375(c): `h(x) = (x-4)^4`

Source mathematical task: differentiate the shifted fourth power while preserving
the translation. This is a function of x, not a constant fourth power.

Expand independently:
`h(x) = x^4 - 16*x^3 + 96*x^2 - 256*x + 256`.
Termwise differentiation gives
`h'(x) = 4*x^3 - 48*x^2 + 192*x - 256 = 4*(x-4)^3`.
This derivation needs only the selected polynomial rules; it does not assume an
unread chain-rule definition. Equivalently the affine inner derivative is 1.
The result holds for every real x. Basis: source 375(c), blocks 0, 3 and 4.
