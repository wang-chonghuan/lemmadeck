# 8. 二元方程组

> 第二章　二元方程和二元不等式 · §3. 二元方程和二元方程组

我们来看解两个二元方程组成的方程组的例子，其中一个方程是二次方程，另一个方程是一次方程.

解二元方程组，就是要找出使方程组的每一个方程成为真等式的变量取值数对的集合.

换句话说，解方程组就是要找出这个方程组中各方程的解集合的交集.

例1　解方程组$\begin{cases}x^2+y^2=100,\\x+y=-2.\end{cases}$　　　　　　　　　（1）

我们用图解法解这个方程组. 为此在同一个坐标系上作出方程$x^2+y^2=100$和$x+y=-2$的图象（图16）.

![图 16](../../figures/fig-16.svg)

*图16*

圆周和直线相交于点$A(-8,6)$和$B(6,-8)$. 每一个交点的坐标既是方程组的第一个方程的解，又是第二个方程的解，也就是方程组的解.

因此，方程组（1）有两个解：$(-8,6)$和$(6,-8)$.

现在我们不用图解法来解同一个方程组.

在第二个方程中，用变量$y$表示变量$x$后，得到：$x=-2-y$.

把表示式$-2-y$代入第一个方程替换变量$x$：$\begin{cases}(-2-y)^2+y^2=100,\\x=-2-y.\end{cases}$

由方程$(-2-y)^2+y^2=100$求得$y=-8$或$y=6$.

因此方程组（1）和下列命题等价：$\begin{cases}x=-2-y,\\y=-8\end{cases}$或$\begin{cases}x=-2-y,\\y=6.\end{cases}$

由此得$\begin{cases}x=6,\\y=-8\end{cases}$。或$\begin{cases}x=-8,\\y=6.\end{cases}$

答：$\{(6,-8),(-8,6)\}$.

我们所采用的这个解方程组的方法叫做代入消元法. 利用这个方法可以解两个二元方程的任何方程组，其中一个方程是二次方程，另一个方程是一次方程.

例2　解方程组$\begin{cases}x^2-3xy-2y^2+5x-7y+10=0,\\x+2y=1.\end{cases}$

利用图解法解这个方程组很困难，因为我们不知道方程组的第一个方程的图象是怎样的. 而利用代入消元法解这个方程组就很简单.

在一次方程$x+2y=1$中，用$y$表示变量$x$并把表示式$1-2y$代入方程组的第一个方程替换$x$后，得到和原方程组同解的方程组：$\begin{cases}(1-2y)^2-3(1-2y)y-2y^2+5(1-2y)-7y+10=0,\\x=1-2y.\end{cases}$

化简第一个方程后，方程组具有下列形式：$\begin{cases}y^2-3y+2=0,\\x=1-2y.\end{cases}$

由二次方程$y^2-3y+2=0$得出$y=1$或$y=2$.

因此，$\begin{cases}y=1,\\x=1-2y\end{cases}$　或　$\begin{cases}y=2,\\x=1-2y.\end{cases}$

于是，$\begin{cases}x=-1,\\y=1\end{cases}$　或　$\begin{cases}x=-3,\\y=2.\end{cases}$

答：$\{(-1,1),(-3,2)\}$.

代入消元法和图解法、加减消元法一样，也可以用来解二元线性方程组.

如果方程组是由两个二次方程组成的，那么只有在特殊情况下，才能给出它的简单解法.

我们来看例子.

解方程组$\begin{cases}x^2-3y^2=22,\\xy=21.\end{cases}$

在方程组的第二个方程中，用$y$表示变量$x$并将所得到的式子代入第一个方程，得到方程组$\begin{cases}x^2-3\cdot\left(\frac{21}{x}\right)^2=22,\\y=\frac{21}{x}.\end{cases}$

解第一个方程，得到$x=-7$或$x=7$. 再由方程$y=\frac{21}{x}$求出对应的$y$值.

如果$x=-7$，那么$y=-3$；如果$x=7$，那么$y=3$.

答：$\{(-7,-3),(7,3)\}$.
