## 最小修订

1. **R01 / P2 / n4 `lesson.template.json:358`，`prose[20]`**
   反向段仍只量化 Phi 上的点，新增平移互逆和原象唯一不证明任意 Phi' 点的逆像属于 Phi。
   `prose[21]` 的“由两个方向的对应”因此缺一向。
   最小仅替换反向段：任取 Phi' 上的点 Q(u,v)，由
   `v=(u-8)^2/2+3` 得 `v-3=(u-8)^2/2`，
   因此逆移得到的 `(u-8,v-3)` 属于 Phi，且由互逆性，原象唯一。
   原数字、方程及后一段结论不用改。
2. **R02 / P2 / n3 `exercises.template.json:218`，原题20**
   仍问“这个图象在哪个象限内”，没有处理源 A03。
   该函数的非原点图象经过两个象限，不能要求唯一象限。
   最小改问“图象除坐标轴上的点外位于哪些象限？”；
   不提供象限答案，不删作图、对称轴或最大值任务。
3. **R03 / P3 / n3 `lesson.template.json:142`，`prose[7]`**
   “下面通过几个例子应用恒等式（1）的例子”重复“例子”。
   最小删句末“的例子”，成为“下面通过几个例子应用恒等式（1）。”

R01、R02 是继承来源疑义的现代文本澄清建议，不宣告 RAW 印刷错误，
也不授权源勘误、数学 token 修改或勘误管线执行。这里只提出修改，没有执行。
